# 이용 근거 관리 연결과 해결되지 않은 범위

기준일: 2026-10-19. 모든 학습 기능과 기존 25개 대상을 유지한다.

## 해결한 내부 연결 문제

- 기존에는 승인 기록을 입력해도 검토표에는 항상 '미확인'이 표시됐다.
  네 목적별 실제 기록이 검토표 JSON·문서·화면에 반영되도록 연결했다.
- 저장·화면 표시 목적은 함수에만 추가돼 있고 관리 명령에는 없었다.
  `storage_display`를 관리 명령에도 연결했다.
- 승인을 입력할 때 근거 확인을 명시하도록 `--confirm-evidence`를 추가했다.
  이 옵션을 지정하는 행위 자체가 실제 허가를 만들어 주는 것은 아니다.
- 승인 기록을 등록 시점의 출처 URL에 연결한다. 출처를 교체하면 예전 기관의
  승인을 새 기관의 자료에 자동 적용하지 않고 재확인을 요구한다.
- 기존에 출처와 연결되지 않은 승인 기록은 삭제하지 않고 재확인 상태로 읽는다.
  승인 철회와 관리자 이용 제한도 즉시 AI 사용 판단과 검토표에 반영한다.
- 개인 메모나 허가 문서 본문을 공개 검토표에 노출하지 않는다.

## 관리자 확인 방법

```powershell
# 원문 수집·외부 AI 호출 없이 네 목적별 현재 확인 상태 보기
python -m culturebridge.manage_sources permissions
```

실제로 문서로 확인한 해당 출처·목적만 다음과 같이 기록한다.
아래는 사용 방법이며 실제 자료를 승인하는 실행 기록이 아니다.

```powershell
python -m culturebridge.manage_sources permission <등록ID> --purpose storage_display --status approved --confirm-evidence --note "실제 근거 문서·이용 범위·확인자·확인일"
```

목적은 `storage_display`, `translation`, `ai`, `redistribution`을 각각 사용한다.
한 목적의 승인은 다른 목적을 승인하지 않는다. 철회는 `--status denied`로 기록한다.
관리 명령은 로컬 관리자용이며 공개 쓰기 API를 추가하지 않았다.
실제 허가 문서는 로컬에서 관리하고 개인정보·서신 본문을 GitHub에 올리지 않는다.

## 여전히 외부 근거가 필요한 사항

원래 25개 출처에 대해 네 목적을 모두 포괄하는 허가·공개 라이선스 또는 적용 가능한
예외 근거를 확보한 것은 아니다. 개인·교육용이라는 프로젝트의 성격만으로 기관이
정한 허가 요구를 자동 해제하거나 저작권 예외의 적용을 확정할 수는 없다.

프랑스 문화부 공개 기록 두 건은 연결했으나 일부 내용이 짧고 프랑스어이므로 기존
25개 설명·비교·퀴즈 전체를 대체했다고 표시하지 않는다. 해당 기록의 공개 라이선스를
다른 기관 원문에 적용하지 않는다.

현재는 외부 AI 제한이 있고 원문 읽기·로컬 학습은 유지되는 구현 상태다.
이는 기존 저장·표시·가공·재배포의 적법성이 확정됐다는 의미가 아니다.
기능을 임의로 제거하거나 기존 원문·학습 기록을 삭제하지 않았다.

완전한 해결에는 충분한 허용 공식 자료로 실제 근거를 교체하거나, 필요한 기관에
구체적인 사용 범위의 허가를 받아야 한다. 자동화 도구로 권리자의 결정을 대신할 수 없다.
이번 작업은 기관 문의를 발송하거나 프로젝트 팀을 대신해 이용 계약에 동의한 것이 아니다.
WBS의 해당 항목을 완료로 변경하지 않는다.

실제 로컬 DB의 상태를 집계한 결과 25개 자료 × 4개 목적 = 100개 항목 모두
허가 근거 미등록 상태였다. 테스트용 가짜 승인은 격리 DB에서만 사용했으며 실제
DB에는 입력하지 않았다. 이 숫자를 모두 허가가 필요하다는 법적 판단으로 해석하지 않는다.

## 검증 결과

- Python 3.13 전체 테스트 496개 통과(151.77초).
- Python 3.12 전체 테스트 496개 통과(145.07초).
- 소스·테스트 Ruff 검사 통과.
- 실행 서버에서 25개 자료 모두 네 목적별 실제 기록 상태를 제공하고,
  상태 확인 API와 서버 상태 API가 정상 응답함을 확인했다.
- GitHub 업로드 대상에서 `.env`, DB, 로그, 로컬 점검 산출물을 제외했고
  알려진 키 패턴을 검사했다. 이것이 모든 형태의 비밀 정보가 없다는 완전한 보증은 아니다.
