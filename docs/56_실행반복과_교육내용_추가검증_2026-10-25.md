점검일: 2026-10-25, 한국 시간. API 한도·키·과금 설정 및 운영 학습 기록은 변경하지 않았다.

45개 흐름 모두 정답표대로 제출하면 5점, 의도적으로 모두 틀리게 제출하면 0점이고
각각 5개 오답 복습 항목이 생성됐다. 학습 보고서의 점수·정답 비노출·원문 보존도 확인했다.
이는 45개 조건부 실행의 관찰이며 기업 서비스의 성공률이나 실제 교육 효과로 일반화하지 않는다.

## 원문 대조에서 찾아 수정한 내용

1. **부분 범위:** 후마윤 묘 자료의 `octagonal chamber`는 방의 모양으로 표시한다.
   건물 전체·정원의 모양으로 넓혀 읽지 않는다.
2. **돔과 지붕:** 불탑의 `dome`을 모두 지붕으로 바꾸지 않고 중립적인 돔 표현을 사용한다.
   반구형이라는 모양도 돔에 관한 설명임을 연결한다.
3. **연대 사건:** 공사 시작·완공·재건을 구분하고, 현재 남은 탑의 건립을 사찰 최초 창건으로
   확대하지 않는다. `from 1565`의 시작 범위와 여러 단계 건립도 보존한다.
4. **초급 문항:** ‘층수 표현은?’ 대신 ‘몇 층으로 설명되어 있나요?’처럼 직접 질문한다.
   ‘쉽게 설명해 달라’는 요청 뒤 확인 질문도 개념별로 짧게 바꿨다.
5. **오답 복습:** 항목마다 같은 주의 문구를 반복하기보다 재료·부분, 연대·사건,
   구조·배치, 종교·쓰임을 연결해 다시 읽도록 안내한다.
6. **목표 유지:** 기준 유산이 아직 검색되지 않았으면 계획 모델에 비교·후보 탐색 도구를
   노출하지 않는다. 확인한 뒤에는 그 대상과 필수 항목을 유지한다.
7. **점검 도구:** 캐시에 자료가 없으면 검토 스크립트가 종료되던 오류를 고쳤다.
   생성하지 못한 설명을 75개 검토·원문 보존 성공으로 계산하지 않는다.

## 이해도 평가 벤치마크

`src/culturebridge/data/assessment_benchmark.py`에 20개 합성 응답을 정의했다.
지붕과 건물 전체의 재료 혼동, 약 1130년의 확정화, 현재 탑과 사찰 창건 혼동,
금박과 전체 금 재료 혼동, 팔각형 방과 건물 전체 혼동, 착공과 완공 혼동,
재건 시작 연도, 여러 단계 건립, 조각과 전체 궁전 재료를 다룬다.
‘모르겠다’와 다른 주제 요청을 이해도 오답으로 잘못 평가하지 않는지도 포함한다.

현재 공식 자료 스냅샷과 20개 응답의 문맥·인용 위치가 맞는 것을 확인했다.
실제 모델을 실행하지 않은 상태의 평가 일치율은 `null`로 남겼다.

```powershell
# 외부 AI 호출 없는 자료·기준 사례 준비 상태 점검
.venv313/Scripts/python.exe scripts/check_assessment_quality.py --db outputs/education-final-repeat-1-20261025.db --output outputs/assessment-new.json

# 호출 가능할 때 선택 사례만 실제 평가. API 사용량 발생, 권한 미확인 자료는 전송하지 않음
.venv313/Scripts/python.exe scripts/check_assessment_quality.py --db outputs/education-final-repeat-1-20261025.db --output outputs/assessment-live-new.json --live --case roof-material --case approximate-year --max-calls 4
```

스크립트는 실제 응답의 판단을 기준답안과 대조하며, 429 뒤에는 추가 호출하지 않는다.
사용량 예산 도달·자료 부족·이용 조건 미확인은 미실행으로 남긴다.
기준답안 일치율도 실제 학생의 학습 효과를 의미하지 않는다.
