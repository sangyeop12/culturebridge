# WBS 잔여 작업 실행 근거

확인일: 2026-10-23. 완료는 해당 작업의 명시한 범위에서 확인했다는 뜻이며,
자료 이용 허가, 전문가 승인, 실제 학습 효과, 사용자 제출 승인을 대신하지 않는다.

## 자료 이용 조건과 전문 용어 조사

25개 기존 원문에 대한 네 용도별 검토표와 제한 장치를 유지했다. 기관 회신을
확인했으나 접수 자동 회신은 이용 허가가 아니다. 무료 공개 보충 기록 5개가
기존 25개 원문의 번역·AI·재배포 권한까지 대체하지 않는다. CB-1.09는 진행 중이다.
유료 허가나 결제를 수락하지 않았고 허가 기록을 임의로 승인하지 않았다.

한국고고학사전의 공개 API는 실제 존재한다. 국립문화유산연구원 안내의
`idx=39`, `firstindex`, `recordcountperpage`로 HTTPS 요청하고 키 없이 HTTP 200을 확인했다.
API 안내 페이지의 공공누리 1유형을 개별 항목 전체에 적용하면 안 된다.
실제 조회 항목은 4유형이었다. 예시 명세와 실제 md_data 순서가 달라 명세 순서만으로
본문·권리 코드를 읽는 연동은 보류했다. CB-3.12의 조사 자체는 완료이며,
정의 조회의 현행 도구인 표준국어대사전의 실제 키 등록은 여전히 별도다.

- [JNTO 이용 조건](https://www.japan.travel/en/terms-of-use/)
- [베르사유 이용 조건](https://en.chateauversailles.fr/legal-information)

## 검색 연결 보완

대화 Agent에 해외 개별 유산·UNESCO 검색 행동을 추가했다. 기존 국가와 25개
검토 대상은 늘리지 않았다. 검색 결과에 존재하는 등록 ID만 읽고, 임의 URL을
수집하지 않는다. UNESCO는 메타데이터·공식 링크 안내이며 본문을 AI로 전송하지 않는다.
권한이 확인되지 않은 개별 원문은 기존 AI 제한과 로컬 읽기 도움말을 유지한다.

일반 인물·사건은 `/history-search`와 대화의 `search_history`에서 신편 한국사
검색 결과의 제목과 공식 원문 링크를 실제 조회한다. 제목 검색 후 필요한 경우
본문 검색으로 한 번 확장하며 원문 본문 자체는 수집·AI 전송하지 않는다.
세종·임진왜란 검색과 첫 공식 원문 링크의 HTTP 200을 확인했다. CB-3.13의
검색 범위 정의·연결은 이 한정된 범위에서 완료다. 모든 역사 주제의 설명·검증이
완료됐다는 의미는 아니다.
추가 후보로 조사한 Met의 문서화된 API는 이 환경에서 403이어서 작동하는 도구로
등록하지 않았다. 접근 제한을 우회하지 않았다.

## 실제 Gemini 확인

실제 키와 기존 모델을 사용하고 과금 설정·키·모델을 바꾸지 않았다. 첫 실행의
503과 대체 설명은 실패로 보존했다. 이후 선택 사례만 제한적으로 재확인했다.

- 관심·목표 긍정 추정, 관심 부정, 목표 변경, 불명확한 관심의 비추정을 확인했다.
- 정상 풀이와 오개념을 구분하고, 이유가 없는 답을 숙달로 올리지 않는 사례를 확인했다.
- 친근한 쉬운 설명과 정중한 상세 설명의 문장별 인용·별도 의미 검사를 확인했다.
- 시대 설명에서 추측을 확정 표현으로 바꿀 위험을 발견했다. 문장 수를 억지로
  늘리지 않도록 하고 추정 표현 누락을 선제 차단했다. 실제 재검사에서 추측을
  유지한 설명을 확인했고 종교적 배경 설명도 통과했다.

실제 응답의 표본 확인이지 모든 질문의 정답성·역사 전문가 승인·학생의 학습 효과
보증은 아니다. 원문·응답이 포함된 진단 JSON과 키는 공개 저장소에 넣지 않는다.

## 교육 내용과 코스 확인

25개 공식 원문을 새로 수집해 연결 성공 25건을 확인했다. 이름·대상 범위·연대를
재검토하고 3수준 75개 설명에서 원문 보존을 확인했다. 한국어 명칭은 기존 안내명과
별칭의 구분을 유지했으며, 근거 없는 연대·재료·종교 항목은 보류로 남겼다.
수도원 전체와 구성 건물, 궁전 영지와 개별 궁전, 건립과 재건을 합쳐 판단하지 않는다.

5개 코스×3수준 15개 경로의 비교·저장 근거 질문·문항 생성·채점·오답 복습·출력을
실행했다. 각 퀴즈는 내용 문항 5개이며 문항 제목 중복은 없었다. 모두 정답 5점,
모두 오답 0점과 오답 복습 연결을 확인했다. 실제 학생의 수업은 수행하지 않았다.

## 백업 복구

운영 DB를 새 백업 파일로 저장하고 별도의 새 DB로 복원했다. 32개 테이블의 행 수
일치, 무결성·외래키 검사와 주요 화면 6곳 HTTP 200을 확인했다. 실제 운영 DB를
덮어쓰거나 서버의 DB 경로를 바꾸지 않았다. 이 검사는 팀원의 다른 PC 확인과 별개다.

## 직접 확인이 필요한 항목

사전 키 발급·등록, 실제 안드로이드 음성·권한·설치, 실제 키보드·확대·키오스크 사용감,
실제 학생 수업, 팀원 PC 설치·실행, 기관 허가 회신, 최종 팀 검토·제출은 남긴다.
자동 검사·브라우저 화면 검사를 이 항목들의 실제 완료로 바꾸지 않는다.

최종 보고서의 내용과 발표 자료·시연 대본은 준비하되, 실제 시연 연습·교수 제출은
사용자의 최종 확인이 필요하다. 외부 배포와 과금은 이번 실행 범위에서 제외했다.

## 산출물과 회귀 검사

Python 3.12와 3.13에서 각각 687개 검사를 통과했다. 검색·음성·설치 이벤트의
추가 회귀 검사와 Ruff 정적 검사도 정상이다. 보고서(45번 문서),
발표 PPTX 10장, 정상·실패 시연 대본(46번 문서)을 작성했다. 슬라이드는 렌더링과
구조·글자 배치 검사를 확인했으며 실제 PowerPoint 실행·발표 연습과는 구분한다.

WBS는 267개 기능명과 기존 6개 필드·일별 일정·담당자 김상엽을 유지했다.
상단 주차 머리글만 10월·11월·12월로 변경했다.
완료 여부만 실행 근거에 따라 갱신했다. 자동 확인 항목을 완료 처리해도 기관
회신·키 등록·실제 기기·다른 PC·학생 수업·최종 제출 항목은 남긴다.

코드·문서·발표·WBS의 `2075a21`을 origin/main에 업로드한 것을 확인한 후
GitHub 반영 항목을 완료로 갱신했다. 그 단계의 현황은 완료 250개였다.
월별 현황 파일은 검색 범위 연결 1개를 추가 완료하여 267개 중 완료 251개,
진행 중 12개, 예정 4개다. 단순 항목 수이며 기능 완성도나 교육 품질의 백분율은 아니다.
후속 점검의 확인 범위와 미완료 이유는 47번 문서에 정리했다.
