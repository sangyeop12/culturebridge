# 관심사와 학습 목표 이어가기

기준일: 2026-10-21. 담당자: 김상엽.

## 구현

홈 자유 입력과 진행 중인 대화에 선택형 ‘내 관심사와 학습 목표’를 추가했다.
관심사 최대 8개·각 40자, 장기 목표 300자, 자기 설명 300자까지 사용자가 직접 입력한다.
초기에는 참고 허용이 꺼져 있다. 체크하고 저장한 경우만 다음 요청의 계획 자료에 추가한다.
저장을 강제하지 않으며, 기존의 자유 대화·검색·비교·코스·퀴즈 흐름을 유지했다.

`learning_intents`는 익명 소유 세션별 상태와 개정 번호를 보관한다.
`GET/PUT /api/learning/intent`는 다른 세션의 설정을 읽거나 쓰지 않는다.
PUT은 현재 개정 번호를 확인하고 불일치하면 409를 반환한다. UI는 덮어쓰지 않고 입력을
유지하며 다시 불러오도록 안내한다. 저장·비우기는 모델을 호출하지 않는다.

진행 중인 발화는 시작 시점의 설정을 사용한다. 같은 학습자 잠금 아래 저장하므로 현재
발화가 끝난 뒤 설정 변경이 반영될 수 있다. 이전 응답을 다시 생성하거나 바꾸지 않는다.

## 계획과 평가 분리

사용자가 허용한 설정은 `learner_confirmed_intent`라는 별도 계획 입력으로 전달한다.
현재 질문·명시적인 주제 변경을 저장한 관심사보다 우선하도록 계획 지침을 추가했다.
설정의 문장 안에 명령이 있어도 공식 도구의 허용 범위·출처 제약을 넓히지 않는다.
입력은 역사 사실의 출처나 이해도 평가 근거가 아니다. 자기 설명만으로 개념 관찰·숙달
기록을 만들지 않는다. 개념별 평가에는 기존의 확인 질문·사용자 답변·원문 근거 검사를 유지한다.

AI가 없는 대안 경로에서는 ‘어디부터 시작할까’ 같은 시작 요청에만 저장한 관심사를
열린 질문으로 제안한다. 새로운 구체적인 질문에 과거 관심사를 강요하지 않는다.
이 안내는 모델이 스스로 계획한 결과나 교육 효과 검증으로 표시하지 않는다.

## 사용자 통제와 보관

- 참고 해제 후 저장: 다음 요청에서 설정을 별도 추가 전달하지 않는다.
- 비우기: 관심사·목표·자기 설명을 비우고 참고를 끈다. 충돌 방지 개정 번호는 유지한다.
- 다시 불러오기: 서버의 현재 설정으로 편집기를 갱신한다.
- 전체 학습 기록 삭제: 해당 세션의 관심사 설정도 삭제한다.
- 기한 정리: 오래되고 살아 있는 대화가 없는 설정에만 적용한다. 특정 세션을 대상으로 한
  기한 정리는 다른 세션의 관심사·말투·개념 프로필을 정리하지 않는다.

비우거나 참고를 꺼도 이전 대화의 문장·이미 전송된 모델 입력은 소급 삭제되지 않는다.
민감한 개인정보를 입력하지 않도록 안내했다. 다른 기기나 설치 컨테이너와 자동 동기화하지 않는다.

## 검증 범위와 한계

자동 검사는 설정 검증·정규화·충돌·소유권·삭제·기한 정리, 다른 대화로 전달, 실제 모델
요청을 구성하는 코드의 입력 분리, 자기평가가 이해도로 바뀌지 않는 동작을 다룬다.
모델 응답은 가짜 클라이언트로 확인하며 실제 Gemini의 관심사 반영 품질을 보장하지 않는다.

전체 회귀 검사: Python 3.12·3.13 각각 576개 통과. 마지막 UI 실패 안내 보완 뒤 관련
16개 검사도 통과했다. 정적 검사와 변경 파일 공백 검사 통과. 로컬 브라우저에서 관심사·
목표·자기 설명 저장, 새로고침 복원, 새 대화의 제한된 관심사 제안을 확인했다.

이 문서는 직접 편집 기능을 처음 연결한 시점의 기록이다. 이후 사용자는 별도의 ‘저장할까요?’
확인 대신 대화에서 자동으로 파악해 반영하는 방식을 요청했다. 최신 구현은 문서 39를 따른다.
퀴즈 복습 연결은 문서 38 참고. 일반 역사·해외 질문용 공식 도구 확장과 실제 AI 품질 확인은
남아 있다. 실제 사전 키 등록·GitHub 업로드·외부 배포는 이번 범위가 아니다.
