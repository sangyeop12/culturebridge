# 학습자 중심 화면 문구

확인일: 2026-10-14

## 주요 변경

- 홈: 하나의 문화유산에서 세계로
- 추천: 함께 알아보면 좋은 문화유산
- 탐구: 두 문화유산 함께 알아보기
- 비교: 유사점과 차이점 알아보기
- 국내 검색: 한국 문화유산 둘러보기
- 세계 검색: 세계유산 둘러보기
- 기록: 다시 보는 비교 기록
- 주장 대조: 이 설명은 근거가 있을까요?
- 퀴즈: 배운 내용 퀴즈로 확인하기

버튼도 ‘이 유산 알아보기’, ‘두 문화유산 함께 알아보기’, ‘배운 내용 퀴즈 풀기’,
‘자료와 대조하기’처럼 활동 중심으로 통일했다.
실행·재조회 횟수·기술적 판정 안내는 ‘자료를 찾고 확인한 과정’과 ‘퀴즈 준비 안내’ 안에 유지한다.
실패와 근거 부족 표시는 숨기지 않으며 최종 사실 검증처럼 표현하지 않는다.
기록은 사용자 계정별 기록이 아니므로 ‘나의 기록’으로 표시하지 않는다.

## 검증

홈·국내/세계 검색·기록·추천·탐구의 제목을 HTTP/UI 회귀 테스트한다.
관련 테스트 27개 통과. 최종 Python 3.13.15 테스트 248개 통과(62.37초),
Python 3.12.14 테스트 248개 통과(57.81초). 두 환경 Ruff·포맷 검사 통과.
재시작한 서버의 홈·한국 검색·탐구 화면 HTTP 200과 새 제목을 확인했다.
표시 문구만 변경했으며 URL·API·원문·과거 저장본은 변경하지 않았다.
실제 브라우저 클릭/모바일 시각 검토는 별도다.
