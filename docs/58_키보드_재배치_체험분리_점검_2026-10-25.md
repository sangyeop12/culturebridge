# 키보드·화면 재배치·체험 분리 점검

점검일: 2026-10-25. 내장 브라우저와 별도 점검 DB를 사용했다.
점검 서버는 `localhost:8082`에만 열었으며 AI 호출을 끄고 기본 예제로 확인했다.
운영 DB, 사용자 API 키·한도·과금 설정과 개인 학습 기록은 변경하지 않았다.

## 브라우저에서 확인한 내용

- 첫 Tab으로 본문 바로가기 접근, Enter로 본문 이동, 다음 Tab으로 본문 링크 이동.
- 초점 테두리 표시, 홈의 학습 시작 앵커 이동 후 다음 펼침 항목으로 초점 이동.
- 설정 선택 상자의 Enter·방향키 조작과 설정 저장. 이후에도 저장값 유지.
- 체험 학습 수준의 Space 선택, Enter로 후보·비교·퀴즈 진입.
- 미응답 제출 시 안내와 첫 미응답 선택지로 초점 이동.
- 키보드로 5문항 선택·제출 후 점수와 오답 복습 표시.
- 320px 너비에서 설정·대화·후보·비교·퀴즈·학습 코스·유산 검색·학습 기록 화면의
  가로 넘침이 없음을 DOM 크기와 화면으로 확인. 홈은 400px 재배치와 초점 표시 확인.
- 수동 초기화 후 고급 선택이 초급으로 복원되고 새로운 체험 시작 안내 표시.
- 실제 무조작 시간이 지난 뒤 `/kiosk?reset=timeout`으로 자동 이동.
- 초기화 후 이전 비교 ID를 다시 열면 내용 대신 찾을 수 없다는 안내 표시.
- 체험 초기화 후 일반 학습에서 저장한 설명 설정은 유지.

브라우저 확대 단축키를 보냈으나 내장 브라우저의 뷰포트·배율은 변하지 않았다.
320px 재배치는 실제 브라우저 200%·400% 확대 시험과 같다고 주장하지 않는다.
확대율을 바꿀 수 있는 브라우저에서의 확대 확인, 화면 읽기 프로그램, 실제 터치 기기의
조작·음성·설치 확인과 다중 이용자의 사용성 평가는 별도다.

## 수정 내용

1. 일반 학습과 체험에 별도의 서명 쿠키와 소유자 구분을 사용한다.
   체험 초기화는 체험 쿠키만 교체한다. 일반 학습 세션은 보존한다.
2. 공개 모드뿐 아니라 로컬 모드에서도 다른 체험의 비교·퀴즈·성적에 접근하지 못한다.
   일반 학습 목록에서도 체험 기록을 제외한다. 기존 DB 기록을 삭제하지 않는다.
3. 체험 내부의 공식 원문·탐구 이동과 돌아가기에서도 체험 모드를 유지한다.
   공식 상세·자율 탐구 화면에도 체험 머리글과 무조작 초기화를 연결한다.
4. 브라우저 뒤로가기가 과거 화면을 캐시에서 복원하면 재조회해 접근 권한을 다시 확인한다.
5. 학습 수준 버튼의 실제 높이가 62px였던 CSS 우선순위를 수정해 72px로 맞췄다.
   좁은 화면의 체험 머리글 줄바꿈, 제목 계층, 수동 초기화 상태 안내도 보완했다.
6. 점검 중 발견한 ‘화강암라는’, ‘화강암와’ 형태의 조사 오류를 고쳤다.
