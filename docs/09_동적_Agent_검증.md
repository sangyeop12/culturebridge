# 동적 공식 자료 Agent

2026-10-13 · 기존 3개 예제는 유지하되 신규 탐구 대상은 공식 검색에서 직접 생성한다.

## 구조 변경

- 검색 결과 → 공식 식별자 검증 → dynamic_heritages/heritages 저장 → 공식 원문 수집.
- 원문과 학습 목표 → Gemini 검색 계획 → 공식 API 조회 → 반환 후보의 인덱스 안에서 모델 선정.
- 선택 후보 원문 → LangGraph 추출·검증·1회 재조회 → 근거 비교·퀴즈 저장.
- 같은 저장본을 질문·주장 검토·채점에서 사용한다. 이전 비교 저장본은 덮어쓰지 않는다.
- 키/AI 오류 시 원문 키워드·유형·국가 적합성으로 대체한다. AI 계획 여부와 실패·보류를 표시한다.
- 입력한 임의 URL을 다운로드하지 않는다. khs/unesco 공식 ID만 허용하며 호출 횟수에 제한이 있다.

## 대상 범위

한국은 국가유산청 공개 개별 유산, 해외는 UNESCO 공식 등재 항목이다.
UNESCO 소개는 `listed_text`로 구분한다. 공식 등재명 전체에만 연결하며,
유산군의 설명을 개별 구성 건물에 적용하지 않는다. 기존 대안탑용 실크로드 `group_text` 제외 규칙도 유지한다.
시대·구조·재료·종교 후보는 원문 정확 일치와 항목 관련 표현을 검사하지만 의미의 최종 검증은 아니다.
불교 외 이슬람·힌두교·기독교, 궁전·성곽·묘역 등도 원문에서 탐색할 수 있다.

## 실제 연결 확인

Gemini 사용량 제한 때문에 다음 실행은 모델을 끈 진단 프로세스에서 대체 탐색으로 확인했다.
서비스의 `.env`와 키는 수정하지 않았다.

- 경주 불국사: `khs:13:0005020000000:37`, 후보를 공식 목록에서 신규 탐색하고 중국 윈강 석굴 등을 선택.
- 비교 저장 `8bf4d4d3-dac2-4ab8-b510-8cb372deb2a0`, 근거 부족 항목 보류, 5문항 생성.
- 타지마할: `unesco:252`, 신규 해외 후보 탐색·비교 저장·5문항 생성, 당시 유효 근거 7/8항목.
- 비교 저장 `001f0773-a90f-4cad-96b4-e297a5f49a31`.
- 이후 후보 검색은 공식 소개도 포함하고 건축 비교에서는 공통 종교만으로 후보를 선정하지 않도록 보완했다.
- 위 저장본은 이 기기의 DB에만 존재한다. 후보 순위/근거 개수는 자료·모델·목표에 따라 달라진다.

## 검증 및 제한

- 신규 ID 두 개의 후보 탐색·추출·비교·5문항·채점·재조회 연결 테스트.
- 모델 계획/선정 경로 모의 테스트, 후보 근거 없음 보류, 국가 표기 동일성, 유산군 범위 검사.
- 임의 URL·누락 ID 거부, 브라우저 연결 전 원격 작업 보류, 질문의 저장본 근거 연결·퀴즈의 근거 저장본 필수 검사.
- 실제 모델 검색 계획·후보 선정의 성공 확인은 API 사용량 제한 해제 후 남아 있다.
- 실제 브라우저 클릭·교육자 의미 검토·추가 유산 품질 실험은 별도다.
- 무제한 웹 탐색이나 자동 진위 확정이 아니다. 공식 자료가 빈약하거나 주제 탐색이 실패하면 결과를 보류한다.
- 기본 예제/키오스크의 큐레이션 목록과 웹 공식 검색 기반 동적 탐구 경로는 구분한다.
- 최종 자동 검사: Python 3.12.14 및 3.13.15 각각 테스트 193개, Ruff·포맷 검사 통과.
- 상태·홈·동적 탐구 로딩 페이지·새 유산의 저장 비교 페이지 HTTP 200 확인.

## 요청 예시

```json
{
  "target": {"provider": "unesco", "record_id": "252"},
  "level": "beginner",
  "goal": "compare",
  "amount": "standard"
}
```

새 유산을 미리 코드에 등록하지 않고 공식 ID로 시작한다. 비교 후보가 없으면 comparison/quiz는 null이다.
API는 반환 후보 외의 모델 선택을 거부하며, 원문을 확보할 수 없는 요청은 오류/보류 상태로 처리한다.
