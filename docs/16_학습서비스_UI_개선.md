# 학습 서비스 UI 개선

기존 탐구·검색·추천·비교·퀴즈·저장과 비교 범위의 기능은 유지하고 표현 계층을 개선했다.

## 디자인

- 밝은 종이색 배경, 짙은 청록색의 주요 동작, 절제된 금색의 보조 색상.
- 공통 색상·타이포그래피·카드·입력창·버튼·원문 펼쳐보기는 `ui/theme.py`에서 관리한다.
- 서체는 운영체제에 설치된 서체를 사용한다. 외부 폰트·이미지 서비스나 추가 패키지 연결이 없다.
- 모든 일반 화면에 브랜드 홈 링크와 비교 학습·한국 문화유산·세계유산·비교 기록 탐색 메뉴를 제공한다.
- 홈은 서비스 소개→해외/국내 비교 범위→수준 및 목표→검색 순서를 유지하며 메뉴의 중복된 세로 링크를 정리했다.
- 검색 동작은 결과 아래가 아닌 입력창 가까이에 배치한다. 검색어·수준·목표·분량·범위와 반환 URL은 보존한다.
- 상세 설명은 조회 정보를 묶고 본문 읽기 크기와 줄 간격을 개선했다. 공식 원문·출처·검토 필요 경고는 숨기지 않는다.
- 모바일에서 입력창·비교 카드는 한 열로 배치한다. 키오스크의 72px 터치 대상과 시간 제한은 유지한다.
- 키보드 초점 테두리, 움직임 줄이기 설정, 메뉴 접근성 이름과 홈/상세 제목 계층을 제공한다.

## 검증

- Python 3.13.15 / 3.12.14에서 전체 테스트 각각 295개 통과. Ruff 검사·형식 검사 통과.

- 기본 회귀 테스트와 새 디자인 테스트를 함께 검증한다. 새 테스트는 공통 메뉴/테마, 검색 버튼 위치와 기존 입력 보존, 모바일·키오스크·접근성 스타일을 검사한다.
- 실제 인앱 브라우저에서 홈·검색·다보탑 설명·석굴암/호류지 비교·기본 퀴즈 화면을 확인했다.
- 390×844 모바일 뷰포트에서 홈·검색을 확인했다. 문서의 가로 폭이 뷰포트와 일치해 가로 넘침이 없었다. 임시 뷰포트 설정은 검증 후 복원했다.
- 외부 AI 연결 성공이나 모든 유산의 비교 근거 적합성을 보증하는 검증은 아니다. 이번 변경은 화면 표현과 사용성에 한정한다.
