원시 실행 보고서와 DB는 로컬 outputs에만 보관하며 Git에 포함하지 않는다.

## Gemini 실제 결과

- 관심사·목표 추정, 관심사 없는 인사, 관심 없음, 목표 변경의 구성요소 검사 4개 통과.
- 관심 없음 응답에는 사용자 발언에 없는 목표 취소 신호도 포함됐다.
  실제 응답을 기존 입력 근거 필터에 다시 통과시켜 잘못된 목표 취소는 제외되고
  관심 없음 신호만 남는 것을 확인했다. 모델 원출력이 완벽했다는 뜻은 아니다.
- 전체 흐름 요청: 다보탑과 해외 탑의 시대·재료 비교 및 퀴즈.
- 실제 AI 도구 선택: 다보탑 검색 → 해외 후보 탐색.
- 탐색 결과: 일본 도지 오층탑. 대상은 다보탑으로 유지됨.
- 이후 HTTP 429로 중단. 응답의 quotaId는
  `GenerateRequestsPerDayPerProjectPerModel-FreeTier`, quotaValue는 `20`.
- 전체 흐름 SDK 호출 4회 중 정상 응답 3회, 제한 응답 1회. 이후 추가 Gemini 호출 없음.
- 전체 흐름 경과 16.67초. 비교·퀴즈·복습은 완료되지 않음.
- 정상 응답의 관측 토큰: 입력 5,525 / 출력과 thinking 합계 381.
  이는 앞선 구성요소 검사까지 합친 총량이 아니며, 실제 청구 비용은 확인하지 않았다.
- 요청·대상·학습 목표 보존과 제한 안내는 확인했다. 한도 복구 후 재개 성공은 미확인이다.

평가 대상 비교·교육 답변이 생성되지 않았으므로 목표 이탈률·근거 없는 주장 비율은
0%가 아니라 **평가 불가**다. 구성요소 검사 통과는 대화 전체 성공이나 교육 효과 입증이 아니다.

## 검사 도구 보완

- `scripts/check_external_connections.py`: 실제 공식 연결 9개, 독립 DB, 비밀값·원문 미출력,
  설정 복원, 기존 보고서/DB 덮어쓰기 방지. Gemini 호출 없음.
- `scripts/check_agent_dialogues.py`: 선택적인 대화 턴 간 대기와 퀴즈 제출 전 호출 예산 검사.
  턴 간 대기는 일일 한도를 늘리거나 한 턴 내부 호출을 제한하지 않는다.
- 외부 연결 검사 도구의 정상·오류·경로 안전성 회귀 검사 4개 추가.
- Python 3.13 통합 검사: 린트·서식 및 테스트 826개 통과(270.21초).
  Python 3.12에서도 새 검사 도구 회귀 테스트 4개 통과.
  자동 회귀 검사는 실제 Gemini를 호출하지 않았으며 실제 연결 결과와 구분한다.

재실행 예시(새 보고서 이름 필요):

```powershell
.\.venv313\Scripts\python.exe scripts/check_external_connections.py --live --output outputs/api-connections-new.json
.\.venv313\Scripts\python.exe scripts/check_agent_dialogues.py --live --scenario overseas_comparison --max-calls 16 --turn-delay-seconds 60 --output outputs/api-dialogue-new.json
```

두 번째 명령은 실제 Gemini를 호출한다. 한도 복구 후 실행하며 429 발생 시 추가 호출을 중단한다.
남은 실제 검증은 비교→퀴즈→복습, 목표 변경 후 일관성, 설명 난도·근거 적합성 및 반복 실행이다.
표준국어대사전 실제 연결은 별도의 사용자 키 등록 이후 진행한다.
