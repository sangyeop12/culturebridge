# CultureBridge 작업실 UI 개편

2026년 11월 10일

첫 방문은 질문 입력으로 시작한다. 왼쪽에는 새 대화, 자료 찾기, 학습 코스, 나의 학습과 최근 대화를 배치한다. 화면 상단의 메뉴 버튼으로 사이드바를 접을 수 있고, 좁은 화면에서는 메뉴를 열어 사용한다.

## 통합한 흐름

- `/`와 `/learn`은 같은 대화 시작 화면을 사용한다. 대화 목록은 공통 사이드바 한 곳에서 제공한다.
- `/library`는 한국·세계유산을 통합 검색한다. 같은 화면의 검색 범위로 대상을 좁힌다. 인물·사건 검색은 자료 찾기의 별도 탭으로 연결한다.
- 코스는 `/courses`, 퀴즈·오답 복습·비교 기록·학습 목표는 `/learning-history`에서 이어간다.
- 학습 설정은 사이드바 하단에서 연다. 출처 안내, 기록 보관·삭제, 앱 설치와 체험 모드는 도움말에 모았다.
- 진행 중인 대화에서는 입력과 전송, 중단 버튼을 같은 영역에 모았다. 음성 입력과 진행 방식 변경은 펼쳐 사용한다.

기존 검색 조건이 포함된 홈 주소와 상세·비교·퀴즈 주소는 계속 지원한다. `/official`과 `/unesco`도 기존 링크와 세부 조회 기능을 위해 유지하며 주 메뉴에서는 통합 검색을 안내한다.

## 유지한 제품 계획

새 팀원 프로젝트 안내서의 공식 자료 기반 학습, 국내외 비교, 초급·중급·고급 설명, Agent의 검색·읽기·비교·퀴즈·복습 선택, 원문·이용 조건 확인, 한국어 풀이, 학습지 내보내기, 관심사 관리, 기록 보호와 키오스크 초기화 기능을 유지한다. NiceGUI·FastAPI·LangGraph·SQLite 기반의 기존 서비스와 소유권 검사를 재사용한다. 자료 읽기와 화면 이동 자체가 AI 요청을 발생시키지는 않는다.

## 디자인 참고

[Codex Desktop — dfones288/codex-desktop](https://github.com/dfones288/codex-desktop)의 프로젝트·대화 사이드바, 중앙 대화, 입력 영역과 접히는 활동 상세 구조를 참고했다. 해당 저장소의 React/Electron 코드를 가져오는 대신 CultureBridge의 NiceGUI 구성 요소로 구현했다. 교육용 한국어 표현과 녹색 계열의 브랜드는 유지한다.

## 검증 범위

전체 자동 검사 839개 통과, 1개 건너뜀. Ruff 검사와 181개 Python 파일의 형식 검사를 통과했다. 새 대화 진입 시 자동 생성 방지, 화면 간 최근 대화 유지, 다른 이용자의 대화 비노출, 기존 검색 주소의 호환성을 추가로 검사했다.

회귀 검사는 외부 AI 호출을 끄고 임시 데이터베이스에서 수행한다. 실제 Gemini와 기관 연결의 품질 검증은 별도다. 이번 환경에서는 브라우저 도구가 현재 URL을 확인하지 못해 시각 검증이 차단되었다. 실제 휴대전화·확대 화면과 대화 하단 입력 영역의 배치는 추가 시각 확인이 필요하다.
