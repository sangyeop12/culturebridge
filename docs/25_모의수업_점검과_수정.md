# 25개 자료 사전 검토와 대표 코스 모의 학습

## 무엇을 했는가

2026-10-17, AI가 학습자 역할로 진행한 점검이다. 실제 팀원·학생 참여자는 0명이며,
학습 효과나 수업 소요 시간을 실증한 결과가 아니다. Gemini 호출 없이 격리 DB에서 진행했다.
실제 학습 기록·키·제출 WBS는 변경하지 않았다.

5개 코스를 초급·중급·고급으로 각각 진행한 15개 시나리오에서 다음을 확인했다.

- 양쪽 자료 읽기 → 비교 → 5문항 → 채점 → 오답 복습 → HTML/Markdown/JSON 결과 구성
- 정답을 알고 모두 맞히는 통제 시나리오: 각각 5/5
- 정답과 다른 답을 넣는 통제 시나리오: 각각 0/5, 복습 5개
- 특정 오답 회차의 내보내기 점수: 모두 0/5
- 각 시나리오 5개 문항 제목 모두 다름, 유산 내용·비교 활동으로 구성
- 보기 최대 길이: 35자(기본 제공 코스의 규칙 기반 경로)
- 저장된 공식 원문 보존, 학습 결과 내보내기의 정답 필드 제외

이 점수는 시스템 채점 점검용이지 AI나 학생의 학습 성취 점수가 아니다.
문자열이 다른 질문도 교육적으로 비슷할 수 있으므로 문항 다양성의 최종 판정은 아니다.

## 발견한 문제와 반영

| 문제 | 수정 |
|---|---|
| 이름·첫 소개 문장이 구조 근거로 먼저 선택됨 | 지붕·천장·배치·모양 등 구체적 특징 문장 우선 |
| 묘당 재료에 주변 출입문 탑의 재료가 선택됨 | 출입문 자체 문장을 묘당 재료 근거에서 제외 |
| 왕릉 위치 설명의 ‘구릉’을 다른 무덤 이름으로 오인 | 지형 명칭과 대상 명칭을 구분 |
| 전각 코스 제목이 양쪽 지붕 근거를 약속하는 것처럼 보임 | ‘큰 건물의 재료와 공간 읽기’로 정리 |
| 궁전 조각의 나무와 건물 설명의 대리석을 단순 재료 차이로 표현 | 사용한 부분·설명 범위를 표시하고 일반화 주의 |
| 긴 원문 선택지·일반적인 출처 확인 문제 반복 | 짧은 특징 표현 4문항과 양쪽 자료 읽기·검토 1문항 |
| 새 특징 유형의 초급 퀴즈 생성 중 오류 | 미등록 보기 유형을 안전하게 처리 |
| 같은 유산의 ‘부분’ 질문이 아치·출입문으로 중복됨 | 유산·항목·읽기 기준이 같은 질문 중복 방지 |
| 돌 종류를 묻는 문항의 오답에 더 넓은 ‘돌’ 범주가 들어갈 수 있음 | 참인 상위 범주를 오답에서 제외 |
| 연대 보기에서 기원전·세기·범위 혼동 가능성 | 단위를 유지하며 부정 표현 연대는 보류 |

초급의 마무리는 양쪽 표현 연결, 중급은 같은 부분·사건인지 범위 대조,
고급은 관찰만으로 기술 전파를 확정할 수 없다는 추론의 한계로 나누었다.
자료에 없는 특징이 실제로 없다고 단정하지 않는다.
최신 학습 구성 버전은 **4**다. 과거 저장본은 덮어쓰지 않고 ‘최신 근거로 다시 탐구하기’를 이용한다.

## 25개 자료의 검토 결과

[대상별 이름·범위·권리 사전 검토](24_공식자료_25개_사전검토_결과.md)를 별도로 기록했다.
한국어 음역·대상 범위 대조는 AI 사전 점검이며 기관의 공식 한국어명 인증이나 팀 최종 승인이 아니다.
JNTO의 킨카쿠지 표기와 생트샤펠 왕실 예배당 표기를 검색 별칭에 보완했다.
생트샤펠 안내명은 ‘왕실 예배당’으로 더 구체화하고 기존 ‘성당’ 검색도 유지했다.

| 이용 조건 사전 분류 | 자료 수 | 의미 |
|---|---:|---|
| 명시적 허가 필요 | 13 | 우리 서비스용 번역·저장·재배포 등 허가 증빙 없음 |
| 개인·교육·인용 등 예외 범위 검토 필요 | 7 | 특정 목적의 예외가 공개 웹·AI 전송까지 허용한다는 뜻 아님 |
| 적용 가능한 허가 범위 미확정 | 5 | 면책 안내·기관 문의·행사 약관 등을 콘텐츠 이용허락으로 취급하지 않음 |

공개 재배포·서비스용 번역·외부 AI 처리 허가를 확보한 자료는 **0개**로 기록한다.
‘미확인’은 모든 사용이 불법이라는 법적 판정도, 사용 가능하다는 허가도 아니다.
이번 점검은 정책 조사와 상태 표시를 보완했으며, 모든 기존 열람 경로를 자동으로 차단하는 기능은 아니다.
허가가 필요한 기관에 문의를 보내거나 계약·약관 동의를 대신하지 않았다.

## 재현 방법

```powershell
$env:CULTUREBRIDGE_DB_PATH = 'outputs/individual-source-live.db'
$env:CULTUREBRIDGE_GEMINI_ENABLED = 'false'
.\.venv313\Scripts\python.exe -m culturebridge.audit_learning --output outputs/classroom-audit-new.json
```

명시적으로 `outputs` 아래 점검 DB를 선택해야 한다. 결과 파일은 기존 파일을 덮어쓰지 않는다.
신규 점검 DB라면 첫 실행에 공식 기관 접속이 필요하며 실패 시 보류로 기록한다.
기존 점검 캐시가 있으면 설정된 유효 기간 안에서 재사용한다. 외부 AI 호출은 하지 않는다.
