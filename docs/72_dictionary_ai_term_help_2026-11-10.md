# 사전 조회 실패 후 쉬운 AI 용어 풀이

- 사전 미설정·검색 결과 없음·키 오류·연결 실패·사전 조회 제한 시 대화의 용어 풀이를 Gemini로 이어간다. 공식 사전 뜻을 얻은 경우에는 기존 원문·출처·이용 조건을 그대로 표시하고 추가 AI 풀이 요청을 보내지 않는다.
- Gemini에는 질문한 용어만 전달한다. 사전 뜻·기관 원문·과거 대화는 이 요청에 포함하지 않는다. AI의 일반적인 풀이임을 표시하고 사전 출처나 역사 근거로 등록하지 않으며 이해도 평가에도 사용하지 않는다.
- 용어가 불분명하면 사용된 문장을 묻는다. 키 없음·AI 비활성·시간 초과·연결 오류에는 안내를 유지한다. 모델의 의미 정확성은 별도 실제 검토가 필요하다.
- 계획 단계에서 429가 발생했다면 용어 풀이를 위한 추가 AI 요청을 하지 않는다. 풀이 요청 자체의 429도 재시도하지 않는다. 429가 아닌 계획 응답 오류 후 용어 풀이에 성공한 경우에는 이미 해결한 질문에 연결 복구 대기 문구를 붙이지 않는다.
- 기존 사전 조회 API는 공식 사전 결과만 반환한다. 일반 AI 풀이를 공식 사전 API 결과에 혼합하지 않는다.
- 실제 Gemini 호출 없이 모의 응답으로 사전 실패 상태별 전환, 공식 뜻 우선, 불명확한 용어, 한도·연결 오류와 대화 상태를 검사했다. 사전·대화·Agent 관련 테스트 57개 통과.
- Python 3.13에서 코드 규칙·266개 파일 서식 검사와 전체 기능 테스트 848개가 통과했다(269.69초). 실제 Gemini 응답의 의미 정확성과 현재 계정의 호출 가능 여부는 이 검사에 포함하지 않았다.

## 서원 질문의 실제 연결 실패 확인

- 사용자가 보고한 두 현상을 구분했다. 첫 질문의 풀이 실패와 별개로 “서원이 뭐냐고”는 제한된 용어 질문 판별에 포함되지 않아 일반 안내로 빠졌다.
- 실제 “서원” 풀이 요청 1회에서 Gemini가 HTTP 503과 모델 혼잡 안내를 반환했다. 수정 후 재확인은 503에 한 번 재시도했으나 최종 504 시간 초과로 끝났다. 실제 요청은 합계 3회이며 정상 풀이 응답은 확보하지 못했다. 키 오류나 429를 관찰한 것은 아니다.
- 이 단계에서는 503에만 남은 시간 안에서 한 번 재시도했다. 공식 자료나 사용자 대화 기록은 이 요청에 전송하지 않았다. 이후 전용 모델과 선택적 대체 모델을 추가한 현재 동작은 아래와 같다.
- “뭐냐고”·“뭔데”·“뭔가요”·“무슨 뜻이냐고” 표현을 같은 용어 질문으로 인식하도록 보완했다. 사전·AI 풀이 결과가 있을 때 불필요한 AI 연결 복구 안내를 붙이지 않고, 실패 시에는 질문을 보존하고 혼잡과 응답 지연을 구분한다.
- 수정 후 관련 회귀 검사 64개가 통과했고, 이후 추가한 504 시간 초과 사례를 포함한 용어 풀이 검사 20개도 통과했다. 실제 Gemini 풀이 품질 검증과 다른 시간대의 정상 연결 확인은 남아 있다.

## 전용 모델로 용어 풀이 연결

- 현재 실행 환경의 일반 대화 모델은 `gemini-3.8-flash`였다. 같은 키의 모델 목록을 확인하고, 별도 “서원” 요청에서 `gemini-2.5-flash-lite`가 약 2.5초 만에 정상 풀이를 반환하는 것을 확인했다. 이는 용어 풀이 함수의 실제 요청이며 브라우저의 전체 학습 흐름 검증은 아니다.
- 짧은 용어 풀이의 기본 모델을 `gemini-2.5-flash-lite`로 분리했다. 일반 대화의 `GEMINI_MODEL`과 로컬 키·과금 설정은 변경하지 않았다. `CULTUREBRIDGE_GEMINI_TERM_MODEL`을 빈 값으로 설정하면 일반 대화 모델을 사용한다.
- 명확한 뜻 질문은 별도의 AI 계획 호출 없이 사전 도구로 연결한다. 실패한 용어 질문 뒤 “이어서 진행해 주세요”에도 남아 있는 같은 용어로 이어간다. 자유 탐구·비교·퀴즈·복습의 모델 계획 경로는 유지한다.
- `CULTUREBRIDGE_GEMINI_TERM_FALLBACK_MODEL`에 다른 모델을 지정하면 503·504에 한 번 전환할 수 있다. 기본은 미지정이며 동일 모델의 503은 한 번만 재시도한다. 429에는 동일·다른 모델 모두 추가 요청하지 않는다.
- 통합 경로의 별도 실제 확인에서는 당시의 `gemini-3.8-flash`가 429를 반환해 추가 실제 AI 호출을 중단했다. 이후 전용 모델 기본값과 직접 연결 경로는 모의 응답으로 검사했다. 앞선 Flash-Lite의 정상 응답과 이 429 실행은 서로 다른 검사다.
- 사전·용어·대화·Agent 관련 테스트 68개 통과. 실제 학생의 이해도·교육 효과 검증을 대신하지 않는다.
- 최종 Python 3.13 통합 검사에서 코드 규칙·266개 파일 서식 검사와 전체 기능 테스트 859개가 통과했다(279.44초). 통합 검사는 실제 Gemini를 호출하지 않았다. 수정된 서버의 `/learn` HTTP 200과 용어 전용 모델 설정을 확인했다.
