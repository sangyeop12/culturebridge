# 검색·학습 화면으로 돌아가기

확인일: 2026-10-14

## 화면과 상태

- 상세: 검색 결과로. 직접 링크로 방문하면 해당 유산 이름으로 한국 검색 화면을 연다.
- 추천·탐구: 검색 결과로. 검색 문맥이 없는 탐구는 선택 대상의 추천 화면으로 돌아간다.
- 비교: 검색 결과로 또는 추천 화면으로. 비교 기록에서 열면 비교 기록으로 돌아간다.
- 퀴즈: 비교 화면으로. 대상·수준·저장된 비교 ID를 유지한다.
- 모든 기존 ‘처음으로’ 버튼은 새 시작 용도로 유지한다.

홈은 q/scope/page/level/goal/goal_text/amount를 복원한다.
반환된 검색은 브라우저 연결 뒤에만 조회하며 페이지 로딩 응답만으로 외부 조회를 실행하지 않는다.
상세 수준 전환은 반환 주소의 수준도 갱신한다.
반환 주소는 각 단계에서 동일한 검색 문맥을 전달한다. 이전 화면 주소를 재귀적으로 중첩하지 않는다.

공식 검색·세계 검색도 이름과 수준을 복원하고 반환 시 결과를 다시 조회한다.
기본 퀴즈는 문제 생성에 쓰는 데이터와 별도로 직전 비교 저장본 ID를 가지고 돌아간다.
반환용 저장본도 비교 대상이 일치하는지 검사한다. 퀴즈 응답·정답 공개 정책은 변경하지 않는다.
키오스크는 명시적인 버튼을 사용하며 mode와 학습 수준을 유지한다.

## 안전성

브라우저 history.back()을 사용하지 않는다. 방문 이력이 없거나 다른 사이트에서 진입해도 목적지가 명확하다.
홈·국내/세계 검색·기록·키오스크 루트만 반환 주소로 허용한다.
외부 URL, // 주소, 역슬래시, 인코딩된 제어문자, 미허용 경로는 안전한 대체 화면으로 돌린다.
반환 주소 안의 return_to를 제거하고 알려진 검색 파라미터만 유지한다.
새 반환 주소는 원문이나 역사적 판단을 변경하지 않으며 기존 비교 저장본을 덮어쓰지 않는다.

## 검증

검색 조건의 여러 단계 전달·입력 복원·같은 결과 페이지 조회·연결 전 외부 작업 보류,
상세 수준 변경·직접 링크 대체 경로·기본 퀴즈의 같은 비교로 복귀·키오스크 모드·대상 불일치 저장본 제외,
외부/스크립트/중첩 반환 주소 차단 등 이동 테스트 17개 통과(3.01초).
Python 3.13.15: 전체 265개 통과(53.69초), Python 3.12.14: 전체 265개 통과(54.50초).
두 환경 Ruff·포맷 검사 통과. 마지막 검색 화면 링크의 수준 전달 보완 후 관련 37개도 통과(7.25초).
재시작한 서버의 검색 조건 복원 홈·고급 공식 상세·탐구 로딩 페이지 HTTP 200과 반환 버튼을 확인했다.

실제 브라우저 클릭/모바일 시각 검토는 별도다. 반환된 검색 결과는 최신 조회이며 과거 결과와 완전히 같음을 보장하지 않는다.
