# 목표 보존·학습 관찰·신뢰성 평가

작성일: 2026-10-25. 이 문서는 구현한 보호·측정 기능과 아직 입증하지 않은 결과를 구분한다.
API 설정은 변경하지 않았고, 일일 한도 초과가 확인된 상태에서 추가 실제 호출을 하지 않았다.

## 1. 목표 이탈 보호

- 사용자 문장에서 비교 기준 유산·명시한 비교 항목·퀴즈 요청을 별도 상태로 보존한다.
  예: `다보탑과 해외 유산을 시대와 재료로 비교`, `다보탑을 기준으로 … 비교`.
- 후속 `계속 진행해 주세요`나 모델의 목표 요약으로 원래 조건을 덮어쓰지 않는다.
- 기준 대상이 아직 검색 결과에 없으면 해외 후보끼리 비교하지 않고 기준 대상 검색을 요구한다.
- 기준 대상이 확인되면 그 대상을 포함한 비교만 허용한다. 단축 이름은 확인된 이름의 끝부분과
  대조한다. 모든 별칭·언어·부정 표현을 이해하는 범용 개체 연결기라는 뜻은 아니다.
- 비교 항목을 모델이 줄여도 원래 항목의 양쪽 근거를 검사한다.
  근거가 부족한 결과나 이전 목표의 저장본으로 퀴즈를 승인하지 않는다.
- 명시적 새 기준 대상, 정정·주제 변경을 처리한다. 사용자 중단과 건너뛰기는 유지한다.
- 비교·퀴즈가 남아 있으면 `finish`를 선택해도 전체 목표를 완료했다고 표시하지 않는다.

## 2. 학습 결과 관찰

대화의 **이번 학습에서 확인한 점**에서 비교 항목의 근거 확보와 설명 변화 관찰을 구분한다.
학습자 설명의 질문·답변·인용 근거·판단·대화 순서를 보존한다.
같은 유산·같은 개념에서 이전의 오해/불명확 판단 이후 근거와 맞는 설명이 관찰됐는지 집계한다.
다른 유산의 답, 정정 요청이 붙은 기록, 순서를 알 수 없는 기존 기록은 개선 사례로 합치지 않는다.

이는 AI의 잠정 관찰이며 숙달 인증이나 교육 효과의 인과적 증명이 아니다.
실제 교육 효과를 확인하려면 학습 전 설명, 학습 직후 다른 문항, 일정 시간이 지난 뒤의
재확인 답변을 수집하고 원문과 대조해야 한다. 같은 문항 반복 정답만으로 효과를 인정하지 않는다.
가능하면 담당 교사가 정확성·질문 직접성·설명 난도를 독립 검토해야 한다.

`mastery_established`, `educational_effect_established`를 자동으로 참으로 바꾸지 않는다.
학생이 참여하지 않은 합성 점검 결과를 실제 학습 결과로 발표해서는 안 된다.

## 3. 실제 Agent 반복 점검

`scripts/check_agent_dialogues.py`는 별도 DB에서 실제 모델·공식 도구를 실행한다.
기존 대화 외에 표현을 바꾼 다보탑 요청, 궁궐, 무덤 비교 시나리오를 추가했다.
각 시나리오는 실행 전에 기준 대상·필수 항목·퀴즈·복습 기대 조건을 정한다.
최대 10회 반복을 지원하지만 전체 SDK 호출 예산과 429 중단을 우선한다.
합성 답안 제출 뒤에는 오답 복습 요청까지 실행하며, 학습 효과 검증으로 취급하지 않는다.

예시(일반 API 사용량 발생, 한도·키·과금 설정은 변경하지 않음):

```powershell
.venv313/Scripts/python.exe scripts/check_agent_dialogues.py --live --output outputs/agent-check-new.json --scenario overseas_comparison --scenario comparison_rephrased --scenario palace_comparison --scenario tomb_comparison --repeat 3 --max-calls 60
```

전체 시나리오를 끝내기에 예산이 부족할 수 있다. 중단·미실행 횟수도 보고서에 남으며
실행하지 않은 사례를 통과로 계산하지 않는다. 추가 재시도는 별도 실행으로 수행한다.

## 4. 측정 항목과 분모

| 항목 | 계산 기준 | 주의 |
|---|---|---|
| 과제 성공률 | 사전 기대 조건을 가진 실행 중 실제 결과가 조건을 충족한 실행 | 비교 저장만으로 성공 아님. 퀴즈 제출·필요한 오답 근거 조회도 확인 |
| 목표 이탈률 | 기준 대상 기대 조건이 있는 고유 비교 결과 중 대상을 빠뜨린 결과 | 차단 시도는 실제 생성 결과와 구분. 같은 저장본 중복 집계 금지 |
| 같은 도구 복구율 | 실패를 겪은 실행 중 같은 도구가 나중에 성공한 실행 | 전체 사용자 목표 복구율을 의미하지 않음 |
| 근거 없는 주장 비율 | 독립 검토에서 supported/unsupported로 판정한 실제 답변 문장 | 인용 수로 자동 판정하지 않음. 검토한 문장 집합에만 적용 |
| 응답 시간 | 턴별 평균·최근접 순위 방식 p95·표본 수 | 소표본 p95를 운영 성능 보장으로 사용하지 않음 |
| 호출·토큰·비용 | 실제 SDK 호출과 공급자의 사용량 메타데이터 | 추론 토큰 포함. 단가는 명시적 입력만 사용. 누락 시 비용 알 수 없음 |

캐시 할인·추가 도구 요금·세금 등을 포함한 청구서 산출 기능은 아니다.
키·단가가 다르면 비용도 달라진다. 실제 가격을 기본값으로 추정하지 않는다.
미검토·미측정 값은 `null`이며 0%·0원·100%로 대체하지 않는다.

저장된 결과는 API 호출 없이 다시 집계할 수 있다.

```powershell
.venv313/Scripts/python.exe scripts/summarize_agent_checks.py outputs/agent-check-new.json
```

선택적인 `--grades` 파일은 다음 구조의 JSON 목록이다. 보고서에 실제로 있는 응답 문장을
지정해야 하며, 동일 문장을 중복 채점할 수 없다. 검토자의 판단 정확성까지 코드가 보증하지 않는다.

```json
[{"scenario":"overseas_comparison","repetition":1,"turn_index":0,
  "claim":"실제 응답에 들어 있는 검토 대상 문장",
  "verdict":"uncertain","reviewer":"검토자 식별명",
  "reason":"공식 원문과 대조한 판단 근거와 출처를 작성"}]
```

정확성뿐 아니라 질문에 직접 답했는지, 학습 수준에 맞는지, 원문에 없는 일반화를 했는지
함께 검토한다. `uncertain`을 근거가 없다는 확정 판정으로 합산하지 않는다.

## 5. 현재 결론

보호 장치와 평가 기반을 구현한 것이며, 반복 실측 수치·실제 학생의 교육 효과를 확보했다는
뜻은 아니다. 기존 읽기 점검 기록을 재집계하면 3회 호출·1턴 8.19초·중단 1회가 확인되지만,
당시 없는 성공 기준·토큰 정보·문장 검토 결과를 소급해서 만들어 내지 않는다.
이번 수정의 다양한 실제 모델 반복 성공 여부는 API 호출 가능 상태에서 확인해야 한다.
