# 개인화 설명·적응형 학습과 실제 진행 WBS

기준일: 2026-10-21. 담당자: 김상엽. 기존 검색·비교·코스·퀴즈 기능을 유지한다.

## 설명 방식

말투와 설명 깊이를 별도로 저장한다. 깊이는 대화에 맞춰 조절, 짧고 쉽게,
근거까지 자세히 중 선택할 수 있다. 수준 선택은 필수가 아니다. 현재 발화에서
쉬운 설명이나 자세한 설명을 요청하면 저장한 깊이보다 현재 요청을 우선한다.

Gemini 풀이의 각 문장은 원문의 연속 인용과 연결한다. 인용 포함 여부와 숫자를
검사한 뒤 별도 모델 요청으로 문장 전체의 근거, 대상 범위, 부정·추정·연대 사건을
대조한다. 허용된 풀이만 제공하며 원문·출처는 별도로 그대로 표시한다.
자세한 설명에는 해석 범위를 살펴보는 읽기 기준을 함께 제공한다.

이는 AI 의미 검토이지 역사 전문가의 승인이나 사실성의 수학적 보장이 아니다.
모델 실패·시간 부족·잘못된 인용·의미 검사 거절에는 기존 로컬 읽기 도움말을 사용한다.
공식 원문, 사전 정의, 사용자 원문은 말투 설정으로 덮어쓰지 않는다.
이해도 평가에는 말투·설명 깊이 설정을 전달하지 않는다.

## 적응형 학습

같은 개념 이름이더라도 다른 유산의 관찰을 그대로 합산하지 않는다.
현재 자료 ID와 원문에 연결된 최근 관찰만 사용한다.

| 근거·요청 | 다음 활동 |
|---|---|
| 지금 쉽게 설명해 달라는 요청 | 중요한 표현 찾기부터 단계별 풀이 |
| 원문과 어긋나는 설명 1회 | 해당 근거를 다시 읽고 이유 확인 |
| 같은 근거에서 혼동 2회 | 핵심 표현과 설명 대상을 작은 단계로 분리 |
| 이유가 불명확함 | 근거 찾기와 자기 말 설명을 보충 |
| 같은 설명을 반복함 | 다른 관점의 확인 질문 |
| 서로 다른 자기 설명 2회가 근거와 일치 | 해석 가능 범위·추가 자료를 생각하는 심화 질문 |
| 다른 문제·심화 요청 | 현재 요청에 맞는 다른 질문·깊이 선택 |

같은 답을 복사해 반복한 것은 서로 다른 설명 두 번으로 세지 않는다.
최근 답변이 원문과 어긋나면 과거의 긍정 관찰만으로 심화시키지 않는다.
이 분기는 교육적 활동 선택이며 능력 등급이나 숙달 확정이 아니다.

## 이해도 판단 분리

실제 모델 점검에서 도구 선택과 이해도 평가를 한 응답에 요구할 때 자료 ID를
누락하거나 사용자 답변을 원문 근거로 사용하는 응답이 있었다. 기존 저장 검사는
그 판단을 거절했다. 이를 보완해 확인 질문에 대한 설명은 작은 별도 구조의 응답으로
판단하며, 자료 ID·개념은 서버의 확인 질문 기록에서 연결한다. 인용은 여전히
원문에 실제로 포함돼야 한다. 다른 주제는 다시 계획 흐름으로 넘긴다.

## 출처·시간·실패 보호

저장된 퀴즈 복습 원문과 과거 인용도 기존 기관별 AI 이용 조건을 적용한다.
미등록 URL이나 AI 처리 승인이 확인되지 않은 자료는 외부 모델에 보내지 않고
로컬 도움말로 이어간다. 번역·재서술에는 번역 목적 승인도 확인한다.
이는 기관에 새 허가를 받았다는 뜻이 아니다.

기본 한 발화 시간 예산은 45초다. 설명 생성·검토도 남은 예산 안에서 요청한다.
이미 시작한 HTTP 요청을 강제로 종료하지는 않으며 저장 직전 중단 신호를 다시 확인한다.
계획 호출이 실패한 같은 단계에서는 설명 생성을 추가 호출하지 않는다.
Gemini 2.5 Flash의 작은 구조화 요청에는 생각 토큰을 끄고 출력 예산을 확보한다.
제공자의 최소 시간제한보다 남은 예산이 작으면 요청하지 않는다.

## 실제 Gemini 점검 결과와 한계

격리 DB에서 실제 등록 키와 `gemini-2.5-flash`를 사용했다. 비밀 키는 보고서·로그·Git에
넣지 않았으며 과금 설정·키 변경은 하지 않았다. 국가유산청에서 다보탑의 원문을
새로 확보하고 해당 원문에 맞는 검사 문항을 구성했다.

- 궁궐 관심과 배치 비교 목표를 현재 발화 근거로 추출하는 응답을 확인했다.
- 인사와 불명확한 관심만 있는 발화에 관심사를 지어내지 않는 응답을 확인했다.
- 친근한 쉬운 설명과 정중한 설명이 문장별 인용·별도 의미 검사를 통과하는 사례를 확인했다.
  예: 두 탑의 높이가 각각 10.29m와 10.75m로 비슷하다는 내용과 수치가 보존됐다.
- 이전 결합 방식의 이해도 응답은 잘못된 인용·누락 ID 등으로 검사를 통과하지 못했다.
- 수정한 분리 방식의 실제 이해도 응답 검증은 호출 한도 초과(429)로 마무리하지 못했다.
  한도 응답 이후 같은 검사 실행의 남은 요청은 중단한다. 추가 과금이나 모델 변경으로
  제한을 우회하지 않는다.

따라서 실제 Gemini 교육 품질 전체를 완료 처리하지 않는다. 새 판단 방식의 정상·오개념·
불확실 답변 사례와 추가 유산을 확인해야 한다. 실제 학생의 학습 효과를 검증한 것도 아니다.
재실행은 한도를 확인한 뒤 수동으로만 수행한다.

```powershell
.venv313\Scripts\python.exe scripts\check_conversation_quality.py --live --output outputs\conversation-quality-new.json
```

일반 pytest는 실제 키가 있어도 외부 AI를 끄고 실행한다. 실제 연결 점검과 모의 검사 결과를
구분한다. 로컬 진단 보고서는 `outputs`에 두고 원문 전체·세션·키·DB를 공개 저장소에 올리지 않는다.

## WBS 갱신

기존 10월 20일 제출본은 덮어쓰지 않는다. 10월 19일 실제 진행본을 바탕으로
기존 53개 작업의 상세와 담당자를 갱신하고 대화형 추가 개발 18개를 추가했다.
총 71개 작업 모두 김상엽 담당이며 완료 51개, 진행 중 14개, 예정 5개, 보류 1개다.
작업 개수 비율을 전체 구현률로 해석하지 않는다.

기존 9~16주차 계획 일정과 색상·병합·기본 서식은 보존한다. 추가 작업의 일정칸은
임의의 마감일을 만들지 않고 비워 둔다. 상태 열은 실제 현재 상태다.
추가 행까지 담당자·상태 필터를 확장했다. 구현 항목과 실제 품질·기기 검증 항목을
분리했으므로 구현 완료가 실제 검증 완료라는 뜻은 아니다.

남은 작업에는 실제 사전 키 검증, 국가유산 용어 자료의 전용 API·조건 확인,
일반 역사·해외 질문에 대한 공식 도구 확대, 실제 Gemini 재검증, 휴대전화 검증,
실제 학습자 사용, 복구·다른 PC 확인, 최종 보고서·팀 승인이 포함된다.
공개 서버는 보류하며 이 작업에서 배포하지 않는다.

## 자동·화면 검사

- Python 3.13 전체 회귀: 624개 통과(297.72초).
- Python 3.12 전체 회귀: 624개 통과(298.26초).
- 이해도 이의 표시 뒤 과거 관찰로 심화시키지 않도록 보완하고 관련 37개를 추가 재확인했다.
- 브라우저 음성·설치 제어 모의 검사 13개 통과. 실제 마이크·설치 검사와 다르다.
- Ruff와 변경 공백 검사 통과.
- 격리 미리보기에서 설명 깊이·말투 저장과 새로고침 복원을 확인했다.
- 실제 진행 WBS의 작업값·담당자·상태, 기존 일정 셀·병합 보존을 별도 검사했다.

전체 회귀 수집 이후 추가한 이의 표시 검사 1개는 관련 37개 재검사에 포함한다.
자동 검사 수가 실제 Gemini 교육 품질을 대신하지 않는다.
