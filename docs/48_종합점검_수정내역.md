# 종합 점검 후 수정 — 2026-10-24

기존 기능을 삭제하지 않고 목표 유지·근거 검사·실패 복구·기록 재사용·화면 동선을 보완했다.

## 기능과 연결

- 짧은 학습도 선택 목표와 자유 목표의 필수 항목을 유지한다. 항목이 많으면 설명 분량을 줄이고 필수 목표를 버리지 않는다.
- 새 주제/기록 정정 이후의 AI 입력은 이전 주제의 인용과 분리한다. 이전 대화는 화면에 보존하고 새 주제의 미승인 출처는 계속 차단한다.
- AI 연결 실패 시 명시적으로 선택한 자료와 이어서 설명 요청만 이전 자료를 사용한다. 새 인물·사건 질문은 공식 검색으로 안내하며 이해도를 임의 평가하지 않는다.
- 자유 질문은 인용 존재뿐 아니라 숫자·재료·추정 표현을 검사하고 별도 AI 의미 검토를 거친다. 실패 시 근거 기반 대체 답변으로 전환한다.
- 탐구 비교와 해당 퀴즈는 요청 캐시가 만료되어도 소유자별 저장 결과를 재사용한다. 원문 내용이나 목표가 달라지면 새 비교를 만들고, 명시적 재분석 기능은 유지한다.
- 반복 복습은 쉬운 단계·혼동 대조·설명 수정·심화 질문을 구분하고 해당 원문 표현을 연결한다. 질문의 수는 유한하며 모든 학습자의 효과를 입증한 것은 아니다.
- 추천 코스는 사용 허용된 관심사를 참고해 표시 순서를 조절한다. 코스 목표와 사용자가 선택한 수준을 몰래 변경하지 않는다.

## UX/UI와 안내

- 설명 설정은 대화 학습에 적용된다고 명시한다. 비교·코스 수준/목표는 각 화면에서 선택한다.
- 대화 목록 화면의 자기 자신으로 이동하는 이어가기 링크를 제거하고 홈에서는 대화 목록 위치로 안내한다.
- 관련 화면 메뉴에서 현재 화면으로의 중복 링크를 줄인다.
- 코스 시작 조작을 큰 삽화보다 먼저 배치한다.
- 자료 읽기·핵심 비교·퀴즈·복습의 공통 단계와 현재 위치를 표시하고 세부 목표 목록은 펼쳐본다.
- 탐구 실패·성공 화면 모두 검색 조건을 유지한 복귀 링크를 사용한다.
- 한국 인물·사건 검색, UNESCO 목록, 해외 개별 자료의 지원 범위를 구분해 안내한다.
- 대화 Agent와 비교 워크플로의 차이를 README와 구현 결과 보고서에 반영한다.

검토 통과는 역사 전문가의 승인, 모든 역사 분야 지원, 모든 해외 자료의 이용 허가를 뜻하지 않는다.
실제 휴대전화 음성 인식·설치와 학생 학습 효과 검증은 별도이며 완료로 변경하지 않는다.
