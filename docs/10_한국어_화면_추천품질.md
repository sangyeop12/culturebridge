# 한국어 화면과 대상 중심 추천 보완

확인일 2026-10-14

## 화면

- 탐구 화면은 선택한 유산 이름을 넣은 한국어 학습 제목으로 표시한다.
- 해외 유산명은 등록된 한국어 안내명(공식 영문명)으로 병기한다. 원본 이름·ID·출처·원문은 수정하지 않는다.
- 한국어 안내명은 공식 한국어 명칭을 보장하지 않는다. 미등록 명칭은 확인 필요로 표시한다.
- 나라 이름과 특징(Buddhist/Pagoda/Grotto 등)은 한국어로 안내한다.
- 대체 검색은 쉬운 한국어로 설명하고, 긴 검증 문구와 실행 기록·원래 추천 이유는 펼쳐보기 안에 둔다.
- 초급에서도 자료가 부족하거나 같은 구조·재료인지 확인되지 않았음을 명시한다.

## 추천·추출

- 대상 이름과 대상 자체의 문장을 기준으로 핵심 유형을 찾는다. KHS 탑 원문의 부모 사찰·주변 석굴 배경은 별도로 제외한다.
- 탑 이름·탑에 대한 직접 문장·이어지는 문맥을 구분한다. 이 규칙은 일차적 선별이며 범용 한국어 의미 분석이 아니다.
- 핵심 유형 검색을 우선하고 같은 유형 후보를 먼저 검토한다. 원문 길이/키워드 개수의 이점은 제한한다.
- 실크로드 도로망·역사유적지구·기념물 복합단지 등 유산군은 개별 대상과 자동으로 짝짓지 않는다.
- 후보의 원문을 다시 확인한 뒤 직접 근거 2항목 이상과 유형의 구조 근거를 요구한다. 선택한 대상 자체도 2항목 이상이어야 자동 비교한다.
- 부족하면 보류한다. 해외 근거가 충분하지 않아 국내 후보가 남으면 그 사실을 화면에서 알린다.
- 다보탑의 불국사 창건 문장을 다보탑의 시대 근거로 사용하지 않는다. 추측/추정 표현을 지운 연대는 거부한다.
- ‘석탑’에서 석재 후보를 찾되 화강암으로 자동 단정하지 않는다. 목조건축을 모방한 형태를 목재라는 근거로 사용하지 않는다.
- 기존 저장본은 보존한다. 새 규칙은 새 탐구와 근거 재검사에 적용한다.

## 검증과 제한

다보탑 배경 문장 제외·추정 연대 유지·석재/화강암 구분·목조건축 모방 구분,
유산군 배제·근거 빈약한 후보 제외·한국어/영문 병기·초급 UI 문구를 회귀 테스트한다.
