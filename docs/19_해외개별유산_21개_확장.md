# 해외 개별 유산 공식 자료 확장

## 범위

기존 4개에 17개를 추가해 5개국 21개 대상을 등록했다.
등록은 기관 URL·대상 식별자·문단/문장 선택자를 정의한 것이다. 역사적 사실 검증 완료와 다르다.
등록되지 않은 URL을 사용자나 모델로부터 받아 수집하지 않는다.
한글·영문명·별칭·국가명으로 검색하고, 홈 자동완성에서 탐구로 이동한다.
UNESCO 등재 유산군과 개별 대상의 ID는 합치지 않고 parent_id로 포함 관계만 기록한다.

## 수집과 교육 근거

- 페이지 전체를 본문으로 사용하지 않는다. 해당 대상의 문단 시작 표현을 확인하고 문장 단위로 범위를 제한한다.
- 도지 사원 창건 796년과 현재 탑의 1644년을 구분한다. 봉황당의 불상 재료나 주변 건물의 연대를 대상 건물의 속성으로 사용하지 않는다.
- 도다이지의 관광 설명 중 의심스러운 높이/폭 번역 문장은 제외한다. 더럼 성의 1072년은 더럼 대성당의 연대로 사용하지 않는다.
- 일본정부관광국의 공식 한국어 페이지를 사용하는 대상은 한국어 원문을 그대로 보관한다. 다른 기관 영문은 임의로 공식 번역으로 표시하지 않는다.
- 경내 전체와 건물 하나를 구분해 화면과 출처 설명에 표시한다. 각 구성물의 속성을 전체 유산의 속성으로 확대 해석하지 않는다.
- 출처의 사용 조건 링크를 유지한다. 이미지 다운로드·재배포, 원문 이용 허가 확보, 완전한 한국어 번역은 이번 작업의 완료 범위가 아니다.
- 실패 원문이나 오래된 캐시를 정상 근거로 승격하지 않는다. HTTPS 검증을 끄거나 외부 리다이렉트를 무제한 따라가지 않는다.

## 추천 연결

기존 탑·고분·궁전에 전각·사찰·성곽·성당·거석 유적의 개별 공식 자료 경로를 추가했다.
해외 범위, 다른 국가, 유형과 양쪽 학습 목표의 근거를 검사한다.
출처 확인은 최대 6개이며 적합 후보 3개를 확보하면 중단한다.
자료 수집 성공과 학습 목표별 비교 적합성은 다르다. 종교 근거가 없으면 구조 근거만으로 종교 비교를 시작하지 않는다.

## 실제 점검과 남은 한계

2026-10-16 개발 환경의 별도 진단 DB에서 Gemini 없이 직접 조회했다.

- 20개: 새 원문 수집 및 로컬 인용 검사 통과 항목 2개 이상 확인.
- 호류지 오층탑: ConnectError로 수집 보류. 21개 모두 정상 연결했다고 표시하지 않는다.
- 개별 연결 성공은 후보 간 모든 조합, 학습 수준별 교육 품질, 역사적 의미 검증 또는 실제 Gemini 전체 흐름의 검증 완료를 뜻하지 않는다.
- 고정 문단 선택자는 기관 페이지 개편 시 수정이 필요하다. `check_individual_sources --all`로 재검사한다.
- 한국어 안내명·표현·구성 범위는 교육자 검토가 필요하다. 현재 유형은 건축 유산 중심이며 모든 국가와 유물 유형을 지원하지 않는다.

전용 자동 테스트는 등록 ID 검증, 포함 관계, 한국어 검색·자동완성, 기관 장애, 재조회 실패,
고정 URL 리다이렉트 차단, 잘못된 대상/연대 배제, 전각 추천 분기와 목표 근거 부족 보류를 검사한다.
외부 연결 진단과 자동 테스트는 별도로 수행한다.

## 실행 검증 기록

- Python 3.12/3.13의 전체 자동 테스트 각각 356개 통과. 이번 확장의 전용 테스트는 33개이다.
- `ruff check src tests`, `ruff format --check src tests` 통과.
- 별도 진단 DB에서 실제 국가유산청 다보탑과 일본정부관광국 도지 오층탑 원문으로
  초급·모양/재료 관찰 탐구를 실행했다. 비교 저장 성공, 유효 항목 7개, 근거 퀴즈 5문항을 확인했다.
- 위 통합 점검은 Gemini를 끈 대체 경로이며 모델의 정상 검색 계획·후보 선택·생성 퀴즈 검증과 구분한다.
- 실제 사용 DB·과거 학습 기록·제출한 WBS는 변경하지 않았다.
