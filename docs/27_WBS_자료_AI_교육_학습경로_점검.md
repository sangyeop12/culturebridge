# 자료·AI·교육·학습 경로 점검

점검일: 2026-10-18. WBS의 네 항목에 대한 내부 작업 기록이다.
최종 제출 보고서·발표 자료가 아니며 모바일·키보드·키오스크,
복구·팀원 PC 설치·GitHub 공유·배포는 이번 작업에서 제외했다.

## 결과를 읽는 기준

실제 팀원이나 학생 참여자는 **0명**이다. 아래 시나리오는 프로그램과 AI가 수행한
통제 점검이며 사람의 이해도·만족도·학습 효과·수업 시간을 입증하지 않는다.
한국어 이름·풀이의 AI 사전 검토와 기관 이용 허가는 서로 다른 상태다.
검토 결과를 이용 허가나 역사 해석의 최종 승인으로 바꾸지 않았다.

### 기관 정책 재확인

다음 정책의 공개 문구를 다시 대조했다. 동일 기관 정책은 그 기관의 여러 대상에 연결된다.

- [베르사유](https://en.chateauversailles.fr/legal-information): 개인·사적 이용 외 조건과 링크 조건.

- [CMN](https://www.monuments-nationaux.fr/mentions-legales): 교육 등 예외와 저자·무변형 조건. 번역·제3자 AI 전송 허가로 확대하지 않는다.
- [에든버러성](https://www.edinburghcastle.scot/terms-and-conditions/): 개인 발췌와 수정·상업 이용 범위 구분.

- [Incredible India](https://www.incredibleindia.gov.in/en/terms-of-use): 법률상 예외 또는 사전 서면 허가 조건.

## 2. 실제 Gemini

- 기존 연결 점검: `gemini-2.5-flash`, 실제 응답 성공, `used_ai=true`.
- 기본 대기시간의 석굴암–호류지 흐름: 질문 AI 응답·인용 2개는 성공했으나
  추출·퀴즈는 대체 방식이었다. 전체 AI 성공으로 집계하지 않았다.
- 별도 프로세스에서 추출·질문·퀴즈 대기시간을 45초로 두고 재점검:
  추출 `gemini`, 질문 `used_ai=true`·인용 2개, 퀴즈 Gemini 초안·근거 검사 5문항 성공.
  오답 5개 제출 시 0점·복습 5개를 확인했다.
- 서비스 설정·로컬 .env는 바꾸지 않았다. 첫 실패의 원인을 시간 초과로 확정하지 않는다.
- 구조화 추출은 퀴즈와 동일하게 추가 thinking budget을 사용하지 않도록 했다.
  변경 후 기본 15초/30초 조건의 추가 실행에서는 AI 추출은 성공했으나
  퀴즈가 429 사용량 제한을 받아 대체 문항을 사용했고 질문도 대체 답변이었다.
  따라서 기본 설정에서 전체 AI 흐름이 안정화됐다는 결론은 내리지 않는다.
  이후 추가 실호출은 중단했다.
- 이것은 기본 예제 한 쌍의 확인이다. 해외 개별 자료 25개 전체의 AI 실행 성공이 아니다.
  동적 검색 계획·자동 선택과 모든 수준의 실제 AI 응답은 이 결과로 검증되지 않는다.
- 답변·추출의 상태는 `needs_review`다. 인용 연결 검사는 의미의 진실성 보증이 아니다.

## 3. 교육 품질 보완

발견한 세 가지 근거 오용을 일반 규칙으로 차단하고 합성 회귀 사례를 추가했다.
인물 생몰년의 괄호 표기와 시대 범위 괄호를 구분하며, 별도 명시적 건물 연도가 있으면 유지한다.
새 퀴즈 초안 지시와 대체 문항에서 개발용 '자료에서 찾은 후보'를
'공식 설명에 따르면'으로 바꿨다. 근거의 한계는 별도 안내로 보존한다.
기존 저장 퀴즈·비교 원문은 덮어쓰지 않았다.

실제 AI 생성 5문항의 유산명·재료·구조·시대 정답을 저장 근거와 대조했다.
다만 목조 구조와 목재 재료를 각각 묻는 문항은 학습 내용이 겹칠 수 있다.
문항 제목이 다르다는 이유만으로 교육적 다양성을 최종 승인하지 않는다.

## 4. 학습자 역할 시나리오

5코스×3수준 15개에서 자료 읽기→비교→저장 근거 질문→퀴즈→채점→오답 복습을 실행했다.
모두 정답/모두 오답의 통제 답안을 사용했고, 각각 5점/0점·오답 복습 5개를 확인했다.
질문은 같은 저장본 근거에 연결되고 외부 AI를 호출하지 않는다.
정상 사용자 DB 대신 별도 점검 DB를 사용했다.

재현 도구: `scripts/check_learning_readiness.py`.
새 DB·새 출력 이름만 허용하고 서비스 DB에서는 공식 자료 캐시만 읽는다.
실제 Gemini 호출은 `--live`, 25개 신규 조회는 `--refresh-materials`를 명시해야 한다.
API 키·SDK 예외 본문은 보고서에 기록하지 않는다.
일반 회귀 테스트도 로컬 .env의 실제 키에 영향을 받지 않도록 AI를 기본 비활성화했다.
모델 경로 테스트는 모의 클라이언트로 명시적으로 활성화하며, 실호출 점검은 별도로 실행한다.

## 아직 완료라고 부를 수 없는 것

기관 허가 확보, 사람의 한국어·역사 해석 최종 승인, 실제 팀원 참여 수업,
동적 검색부터 시작하는 전체 AI 조합의 안정성은 별도 확인이 필요하다.
이 문서는 이 항목들을 완료로 처리하거나 제출 WBS를 수정하지 않는다.

## 회귀 확인

Python 3.13 전체 451개 통과(107.15초), Python 3.12 변경 관련 37개 통과(5.61초).
변경한 Python 파일의 Ruff 검사 통과. Python 3.12 전체 검사를 이번 작업에서 다시
수행한 것은 아니다. 첫 회귀 실행은 실제 .env의 AI 활성화 영향을 받아 두 검사가
실패했으며, 일반 테스트의 AI 기본 비활성화를 반영한 뒤 전체 통과를 확인했다.
이 수치는 실제 학생의 성취도나 외부 API의 지속적 가용성을 보증하지 않는다.
