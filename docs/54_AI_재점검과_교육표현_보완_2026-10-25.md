# 실제 AI 재점검과 교육 표현 보완

점검일: 2026-10-25 (한국 시간). API 키·모델·한도·과금 설정은 변경하지 않았다.
실제 Gemini와 공식 자료를 사용하되, 별도 점검 DB와 가상 학습자 대화로 실행했다.
실제 학생의 학습 효과나 모든 대화의 일관성을 검증한 결과는 아니다.

## 실제 호출에서 확인한 문제

1. 동적으로 만드는 계획 응답 규격의 ID 열거형에 빈 문자열이 포함돼 Gemini가 400으로 거절했다.
   사용하지 않는 ID는 `__none__`으로 전달하고, 내부 결정으로 변환할 때 빈 값으로 복원했다.
   ID 제한과 도구 실행 권한 검사는 유지했다. 수정 후 실제 계획 응답이 돌아오는 것을 확인했다.
2. 해외 비교 대화에서 해외 검색 뒤 대상을 다시 물었고, 이어서는 다보탑 대신 해외 후보끼리 비교했다.
   지정한 기준 대상·비교 항목을 유지하고 직접 선택 요청을 되묻지 않도록 계획 지시를 보완했다.
   관찰된 대상의 이름을 사용자가 명시한 경우, 그 대상을 빠뜨리는 비교는 실행 전에 차단한다.
   정정·부정 표현은 단순 이름 일치로 강제하지 않는다. 미관찰 이름·별칭의 의미 해석까지
   이 검사 하나로 보장하지는 않으므로 실제 모델 재검증이 필요하다.
3. 10월 25일 한국 시간 재실행에서는 다보탑 검색과 공식 원문 읽기가 성공했다.
   다음 계획 호출에서 429가 반환돼 재료 설명과 후속 확인 질문의 실제 실행은 완료하지 못했다.
   이때 이미 읽은 자료가 있어도 다시 항목을 고르라는 안내가 나왔다.
   같은 턴에서 읽은 대상과 사용자가 명시한 좁은 질문이 일치하면, 확보한 인용으로 제한된
   설명을 제공하도록 수정했다. 이전 주제 자료를 임의로 재사용하거나 AI를 다시 호출하지 않는다.

## 교육 내용·안내 개선

- 비교 후보 도구 결과에 화면에서 쓰는 쉬운 한국어 추천 이유를 포함했다.
- 퀴즈의 `재료을`, `재료은` 같은 조사 오류를 없앴다.
- 재료에 관한 부분 안내를 시대·종교 등 다른 항목에 잘못 붙이지 않도록 했다.
- 두 유산을 연결하는 문제는 같은 항목·관찰 기준의 사실끼리 구성한다.
  날짜와 다른 유산의 재료를 임의로 짝짓지 않는다.
- 대리석·사암·석회암 문제에서 상위 범주인 석재가 오답으로 함께 제시되지 않도록 했다.
- 설명은 원문 인용과 분리하고, 연결 실패 때 이해도·숙달을 추정하지 않는 기존 정책을 유지했다.

## 호출 제한과 남은 실제 검증

실제 응답에 일일 무료 요청 한도 초과가 기록됐다. 해당 키·모델의 당시 응답이며
모든 계정의 일반 한도를 의미하지 않는다. 제한 뒤에는 추가 실제 호출을 중단했다.

- 실제 확인: 수정된 요청 형식으로 계획 응답 수신, 해외 검색, 비교 실행 시도,
  다보탑 검색 및 공식 자료 읽기.
- 미완료: 이번 수정 후 다양한 실제 대화에서 기준 대상 유지, 개인화 설명,
  비교 → 퀴즈 → 사용자 답안 제출 → 오답 복습까지의 연속 성공.
- 자동 검증: 공급자 규격의 빈 열거값 방지, ID 복원, 기준 대상 보존/정정,
  읽기 직후 제한 안내, 같은 기준의 문항 구성 등 회귀 검사를 추가했다.

원시 점검 기록은 Git에 포함되지 않는 `outputs/agent-dialogues-recheck-*.json`과
별도 점검 DB에 보관했다. 운영 학습 기록 및 비밀 설정은 변경하지 않았다.
