# CultureBridge UX/UI 통합과 WBS 재구성

기준일: 2026-10-21. 기능을 제거하거나 공개 배포하지 않은 로컬 변경이다.

## 서비스 흐름과 공통 디자인

- 주요 메뉴를 홈 / 역사 이야기 / 문화유산 탐구 / 추천 학습 코스 / 나의 학습으로 통일했다.
- 내부 화면에는 현재 위치와 관련 화면 메뉴를 제공하고, 자료·기록·설치 안내는 공통 하단에 배치했다.
- 크림색 배경, 짙은 녹색, 절제된 황동색과 동일한 글자·간격·카드·입력·버튼 규칙을 적용했다.
- 홈은 질문으로 시작하는 학습을 먼저 안내하되 기존 유산 검색·비교 진입도 유지한다.
- 대화는 사용자와 안내자의 말풍선을 구분한다. 정확히 같은 인용문은 본문에서 반복하지 않고 근거 펼침에 보존한다. 저장 원문·인용·질문은 수정하지 않는다.
- 음성과 상세 설정, 추가 진행 조작은 필요한 때 펼친다. 중단·재개·건너뛰기는 미전송 질문을 보내거나 지우지 않는다. 중단 시 주 버튼은 이어서 학습으로 바뀐다.
- 공식 자료 검색 버튼은 결과 목록보다 위에 유지한다. 기존 검색어·수준·목표·돌아가기 맥락은 유지한다.
- 작은 화면은 주 메뉴를 줄바꿈 격자로 표시하고 입력·카드·설정을 한 열로 정리한다. 실제 기기 검증과 브라우저 화면 크기 모의 확인은 구분한다.

## 통합 WBS

새 기준 파일: `CultureBridge_WBS_기존양식_세분화_2026-10-21.xlsx`.
처음 만든 통합세분화 파일은 열 구성까지 변경했으므로 사용하지 않는다. 기존 실제 진행 파일을 직접 불러와 원래 여섯 항목, 주차별 일정표, 열 너비·글꼴·머리글·고정 창과 단계·작업 병합 방식을 유지한 수정본으로 대체한다. 이전 실제 진행 파일과 10월 20일 제출본은 보존한다.

| 단계 | 작업 수 |
| --- | ---: |
| 기획·설계 | 33 |
| 기능 개발 | 71 |
| 통합·품질 검증 | 17 |
| 운영·협업 | 6 |
| 최종 정리 | 5 |
| 합계 | 132 |

대화형 확장을 뒤에 별도 추가하는 대신 요구 정의·화면·데이터·도구·Agent·평가·검증 단계에 통합했다. 화면별 설계와 구현, 백엔드 동작, 완료 기준을 구분했다. 로그인은 현재 서비스 범위가 아니므로 추가하지 않았다. 공개 서버 과금·배포는 보류 범위다.

모든 담당자는 김상엽이다. 일정은 원본 9~16주차의 **2026-10-13~2026-12-06**, 55칸 배치를 그대로 사용한다. 월요일 칸이나 계획 시작·종료 열을 추가하지 않는다. 실제 구현 날짜를 재현하는 일정이 아니며, 완료 여부 열은 실제 상태를 표시한다.

초록은 기획·설계·개발·운영 작업의 계획 구간, 주황은 조사·검증·정리 작업의 계획 구간, 회색은 주말이다. 기존 색상 팔레트와 셀 채우기 방식이다. 색은 완료 상태가 아니며 일정 변경 시 해당 칸의 채우기를 조정한다. 완료 상태와 역할분류는 드롭다운으로 별도 관리한다. 작업량에 맞춰 행을 확장하고 세부 내용이 잘리지 않도록 행 높이만 조정했다.

현재 분류는 완료 110 / 진행 중 17 / 예정 5이다. 작업 크기가 달라 이 비율을 전체 구현률로 환산하지 않는다. 실제 Gemini 품질·휴대전화·사전 키·이용 권한·학습자 사용·최종 제출 검토는 확인 전 완료로 바꾸지 않았다.

## 확인 범위

격리 DB와 Gemini 비활성 미리보기에서 홈 진입, 대화 시작, 코스 목록·상세, 공통 메뉴를 확인했다. 390px 화면에서 주요 메뉴와 카드의 가로 넘침을 확인했고, 미전송 질문을 유지한 중단·재개와 하단의 실제 DOM 순서를 확인했다. 실제 휴대전화·마이크 권한·설치 검증은 아니다.

스프레드시트는 132개 세부 작업과 상태·담당자 일치, 원본 여섯 열과 55칸 달력, 머리글 병합·색상·열 너비·글꼴·고정 창 보존을 검사하고 단계별 렌더링으로 확인했다. 새 작업 ID 열은 추가하지 않았다. 전문가의 역사·권한 최종 승인과 자동 검사는 별개다.

최종 회귀 검사는 Python 3.13에서 647개(307.01초), Python 3.12에서 647개(297.67초) 모두 통과했다. Ruff와 변경 공백 검사도 통과했다. 실제 Gemini 호출은 수행하지 않았으며 기존 한도 초과에 따른 품질 검증 대기 상태를 유지한다.

로컬 운영 DB를 `backups/before-unified-design-20261021.db`로 백업한 뒤 8081 서버를 새 UI로 재시작했고 상태 확인 응답 200을 확인했다. 격리 미리보기 서버는 종료했다.

2026-10-23 최종 문구 조정 후 Python 3.13과 3.12에서 각각 662개 회귀 검사가 모두 통과했다. 친근한 안내는 유지하고 기술적·부적절한 설정명만 정리했다. 실제 Gemini 응답 품질과 휴대전화 확인은 검증 대기로 유지한다.
