# 연결 학습 운영 보완

## 적용한 항목

1. 기본 비교와 API에서 목표·자유 목표·분량·학습 순서를 보존한다.
2. 석탑·목탑 차이는 비교 축으로 안내한다. 핵심 유형과 자료 단위·양쪽 목표 근거 검사는 유지한다.
3. 동일 기본 비교는 내용/세션 지문으로 재사용한다. 탐구·퀴즈·동일 답안 채점은 기본 5분 동안 세션별 성공 결과를 재사용한다.
4. 저장 원문 기반 질문과 현재 요약 기반 질문의 안내를 구분한다.
5. 호류지 사찰 오층탑 및 시안시 정부 대안탑의 개별 소개 어댑터를 추가한다. 입력 URL을 수집하지 않는다.
6. 초급 긴 문장의 핵심 표현은 줄 단위로 읽으며 생각해 보기 질문을 제공한다. 전체 원문은 보존한다.
7. 비교 설명에 재료·연대 사건·종교적 쓰임·공간의 비교 기준을 제공한다. 인과/영향을 추정하지 않는다.
8. 규칙 퀴즈의 내용 중심 보기를 늘리고 오답별 원문 확인·사건 구분 보충 활동을 제공한다.
   자유 목표의 비키워드 표현은 지원 항목만 선택하는 Gemini 해석으로 보완하며, 모델 실패 시 기본 계획을 사용한다.
9. 질문은 최대 최근 6개 대화 메시지를 맥락으로만 사용한다. 각 AI 답변 문장의 출처·인용 일치·대상 범위를 검사한다.
10. 별칭과 포함 관계의 식별 계층을 추가한다. 과거 ID를 삭제하거나 유산군과 개별 탑을 같은 유산으로 합치지 않는다.
11. 비교의 반복 설명을 펼쳐보기로 묶고, 보류 시 설명 읽기/목표 변경 경로를 제공한다.
12. 결과 없음 시 유사한 한국어 검색어를 안내하며, 검색어 제안을 공식 조회 결과로 표시하지 않는다.
13. 학습 기록 화면/API에서 성적·오답·보충 활동·저장 비교로 돌아가기를 제공한다.
14. 공개 모드의 서명된 익명 세션과 기록 소유권 검사, 키오스크 세션 교체를 제공한다.
15. 동시 학습/요청 제한, SQLite 백업/무결성 검사와 공개 모드 비밀 설정 검사를 제공한다.

## 실제 연결 확인과 한계

- Python 3.12.14와 3.13.15에서 Ruff 검사·형식 검사 및 테스트 각각 311개 통과. 자동 테스트는 실제 Gemini 응답이나 교육적 적합성의 보증이 아니다.
- 2026-10-14 브라우저에서 홈 불국사 검색→다보탑 해외 추천→대안탑 비교 저장→5문항 퀴즈→채점→학습 기록의 오답·원문 접기·비교/퀴즈 반환을 확인했다. Gemini 실패 시 대체 경로로 동작했다.
- 국가유산청 다보탑→시안시 정부 대안탑 개별 원문→해외 비교 저장→5문항 퀴즈: AI를 끈 대체 경로에서 확인.
- 제목만 적힌 줄·상징적 소개를 구조 근거로 쓰지 않도록 추가 선별했다. 실제 대안탑의 사찰 내부 위치 문장이 구조 근거로 선택되는 것을 확인했다.
- 시안시 정부 공식 소개 원문 수집 성공. 호류지 공식 소개는 인증서 오류로 보류했다. 인증서 검증을 끄거나 원문을 임의 작성하지 않았다.
- Gemini 직접 호출: 429 사용량 제한. 정상 AI 계획→선택→추출→질문→퀴즈 성공 경로는 아직 실증 완료가 아니다.
- 보완한 비교 분석은 규칙 기반 교육 안내/검토 후보이며 교육자 검토를 대신하지 않는다.
- 추가 공식 어댑터는 현재 두 개별 유산 범위이다. 모든 국가/유형의 공식 자료와 한국어 이름을 확보한 것은 아니다.
- 기록 접근 보호와 동시/요청 제한은 단일 서버 프로세스 기준이다. 계정/다중 서버 운영은 별도 설계가 필요하다.
- 원본 제안서와 과거 검증 문서는 작성 당시 기록이다. 현재 현황은 이 문서와 README의 최신 항목을 우선한다.

## 문서 일정 정합성

원본 WBS의 자기 참조는 실제 선행 관계로 교정해야 한다. 현재 구현 현황을 계획 진행률 0%와 혼동하지 않는다.
교정할 선행 ID: 26→25, 28→23·24·27, 30→29, 31→30, 33→32, 35→34,
37→36, 39→38, 40→39, 43→35·42, 44→43, 46→45, 47→46,
49→46·47·48, 50→49, 54→53, 55→53·54, 56→55, 57→56.
이는 일정 의존성 교정안이며 발표·평가를 이미 수행했다는 뜻이 아니다. 실행 버전은 잠금 파일과 실제 테스트 기준으로 확정한다.
