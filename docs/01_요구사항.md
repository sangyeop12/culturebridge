# 1. 프로젝트 개요 및 개발 배경

CultureBridge는 하나의 문화유산에서 출발해 한국·중국·일본의 관련 문화유산을 비교하고, 공식 출처를 확인하며 학습할 수 있는 AI Agent 기반 교육 플랫폼이다.

□ 1.1 개발 목적

- 여러 기관에 흩어진 공식 자료를 한곳에서 검색하고 비교한다.
- AI가 비교 후보와 이유를 제안하되 공식 출처를 함께 제시한다.
- 역사적 사실·해석·근거 부족 상태를 구분한다.
- 개인 웹 학습과 박물관형 터치 체험에 같은 서비스를 활용한다.

□ 1.2 MVP 범위

- 한국·중국·일본의 불교 문화유산 샘플 데이터
- 문화유산 검색·목록·상세 조회
- 관련 문화유산 추천과 항목별 비교
- 초급·중급·고급 학습 수준
- 공식 출처와 검증 상태 표시
- 4지선다형 퀴즈 5문항 구조
- 웹 모드와 키오스크 모드

□ 1.3 제외 범위

- 실제 박물관 전시 시스템 연동
- 사용자 계정과 개인정보 저장
- 운영기관의 실시간 API 제공을 전제로 한 기능
- 출처로 확인되지 않은 역사적 영향 관계의 단정

# 2. 서비스 개요 및 핵심 기술

□ 2.1 기능 요구사항

① 학습 수준을 선택한다.

② 문화유산을 검색하거나 목록에서 선택한다.

③ AI Agent가 비교 후보와 추천 이유를 제시한다.

④ 두 문화유산의 시대·구조·재료·종교적 배경을 비교한다.

⑤ 사용자는 자유 질문을 입력하고 출처가 연결된 답변을 확인한다.

⑥ 학습을 마치면 4지선다형 퀴즈 5문항을 풀고 해설을 확인한다.

- 초급: 위치·형태·재료 관찰과 기본 사실 확인.
- 중급: 시대·구조·재료 연결, 공통점과 차이점 비교.
- 고급: 사실과 해석의 구분, 영향 관계의 증거, 출처 범위와 근거 부족 판단.
- 각 수준은 네 비교 항목의 설명과 다섯 퀴즈 문항을 별도로 구성한다.
- 정답 위치를 분산하며 퀴즈 API는 정답과 해설을 제출 전 공개하지 않는다.

□ 2.2 비기능 요구사항

- 출처 추적: 모든 핵심 설명은 하나 이상의 출처와 연결한다.
- 개인정보 최소화: MVP는 계정 없이 임시 세션을 사용한다.
- 입력 검증: 검색어·ID·학습 수준·퀴즈 답안을 검증한다.
- 접근성: 큰 터치 영역, 키보드 탐색, 충분한 색 대비를 제공한다.
- 키오스크 초기화: 처음으로 버튼 또는 5분 미사용 시 시작 화면으로 돌아간다.
- 실패 처리: 외부 AI 호출 실패 시 검증된 기본 설명으로 전환한다.
- 보안: API 키는 환경변수로만 관리하고 응답·로그에 노출하지 않는다.

# 3. 완료 기준

■ 1 구간 완료 기준

- 요구사항·화면·Agent·DB·API 설계가 저장소에 기록되어 있다.
- 개발 환경을 설치하고 앱의 상태 확인 API를 실행할 수 있다.
- 문화유산 3건을 검색하고 비교 후보를 받을 수 있다.
- 핵심 서비스 테스트가 통과한다.
