# 교육 내용 추가 검수와 실제 진행 WBS

기준일: 2026-10-19. AI의 원문 대조·코드 보완 기록이며 역사 전문가의 최종 승인이나
기관의 이용 허가를 대신하지 않는다. 실제 팀원·학생 참여자는 0명이다.

## 검수 범위

등록 해외 개별 자료 25개를 공식 사이트에서 다시 수집했다. 25개 모두 새 원문 수집에
성공했으며 이름·대상 단위·연대·구성 부분을 등록 정보와 대조했다.
초급·중급·고급 75개 읽기 구성에서 공식 원문이 보존되는 것을 확인했다.
한국어 이름은 계속 학습용 안내 표기이며 공인 번역으로 승격하지 않았다.

한 문장에 여러 연대나 사건이 있으면 하나의 건립연도로 단순화하지 않는다.

## 공통 수정

- 설명과 퀴즈가 하나의 연대 읽기 함수를 사용한다. '약', 세기 초반·중엽·후반,
  기원전, 연도 범위를 보존한다. 여러 사건·상대 연대·부정 문장은 정확한 연도 문항으로 만들지 않는다.
- 추정·전승 연대끼리의 차이를 확정적인 연도 차이로 계산하지 않는다.
- '완공', '지어진' 등 명시적 사건 표현을 인식한다. 사찰 창건으로 다른 건물의 연대를 추정하지 않는다.
- 모양·지붕·계단·난간 같은 구체적 특징을 단순한 건물 종류보다 먼저 설명한다.
- 재료 읽기에는 지붕·천장·조각·표면 마감 등 사용 부분을 표시한다.
- 같은 유산·같은 인용·같은 답을 반복하는 로컬 문항을 제외한다.
- 고급 로컬 퀴즈는 내용 확인 3문항, 범위 해석 1문항, 양쪽 근거 비교 1문항을 목표로 한다.
  근거가 충분하지 않으면 이 구성을 억지로 채우지 않는다.
- 학습 구성 버전은 6이다. 과거 저장본·퀴즈·원문·성적은 덮어쓰지 않는다.
  이전 결과는 '최신 근거로 다시 탐구하기'로 새로 생성할 수 있다.
- 해외 개별 원문의 외부 AI 처리 권한 제한은 그대로 유지한다. 이번 검수는 Gemini를 호출하지 않았다.

[프티 트리아농](https://en.chateauversailles.fr/discover/estate/estate-trianon/petit-trianon).
더럼 공식 페이지의 브라우징 도구 조회는 실패했지만 서비스의 새 원문 수집은 성공했다.
두 접근 결과를 같은 것으로 취급하지 않았다.

## 학습 경로 확인

수정 후 별도 점검 DB에서 5개 코스×3수준 15개 경로를 재실행했다.
각 경로는 자료 읽기·비교·저장 근거 질문·퀴즈 5문항·채점·오답 복습까지 완료됐다.
문항 제목 중복 없음, 모두 정답 5점/모두 오답 0점, 오답 복습 5개와 원문 보존을 확인했다.
이는 실제 학생의 이해도·난도 적합성·학습 효과를 입증한 결과가 아니다.

## 실제 진행 WBS의 판정 기준

제출한 10월 20일 기준본은 변경하지 않고 별도의 10월 19일 실제 진행본을 만든다.
작업 목록·담당자·역할 비율·9~16주차 계획 색상·서식은 유지한다.
완료 여부 열은 실제 상태이며 일정색은 원래 계획이라는 점을 제목에 표시한다.

- **완료:** 해당 설계·기능 구현 또는 명시한 자동 검증이 끝나고 확인 근거가 있는 항목.
  교육 내용의 완전성·인간 검수·권한 승인을 포함하는 뜻은 아니다.
- **진행 중:** 부분 결과는 있지만 최종 검수·환경 확인·전체 흐름 확인 등이 남은 항목.
- **예정:** 실제 팀원 시나리오 테스트, 최종 보고서, 팀 최종 검토·제출.
- **보류:** 공개 배포 여부·비밀 설정의 전체 항목. 로컬 비밀 설정은 구현했으나 공개 배포는 보류 중이다.

자료 이용 조건(14행), Gemini 전체 흐름(42행), 교육 품질(43~44행), 실제 기기·오류
종합 확인(46~47행), 복구·다른 PC 환경 확인(50~51행), 최종 릴리스(53행), 발표·시연
최종 준비(55행)는 완료로 승격하지 않는다. 최신 main에는 이후 디자인·교육 수정이
아직 올라가지 않았으므로 '과거 main 공유 완료'만으로 최종 릴리스를 완료 처리하지 않는다.
45행의 '팀원 3명'은 제출본 문구를 유지했으며 실제 인원은 팀 확인이 필요하다.
