# 대화형 역사 학습 1차 구현

기준일: 2026-10-20. 모든 작업 담당자: 김상엽.

이 문서는 1차 구현 시점의 기록이다. 10월 21일 설명 개인화·적응형 분기와
최신 WBS·실제 Gemini 점검 현황은 문서 40을 따른다.

## 이번 변경

기존 비교·검색·코스·퀴즈 API를 유지하고 홈에 자유 대화 진입점을 추가했다.
`/learn`에서 현재 브라우저의 대화를 다시 열 수 있다. 초·중·고급이나 유산 ID를
지정하지 않아도 대화를 시작한다. 기존 검색 화면은 그대로 사용할 수 있다.

새 LangGraph는 다음 행동 계획, 도구 실행, 응답의 노드로 구성한다. Gemini가 질문,
국가유산청 검색, 검색 결과의 공식 ID 읽기, 설명, 이해 확인, 복습 중 행동을 선택한다.
검색 결과를 다시 계획 노드에 전달하므로 고정된 비교 순서를 그대로 실행하는 구조와 다르다.
임의 URL이나 검색되지 않은 ID는 원문 수집 도구로 전달하지 않는다.

설명은 기존 원문 추출·용어 풀이 도구를 재사용한다. 원문 인용과 공식 출처를 함께
표시하고, 원문 전체 읽기 및 기존 해외 비교 탐구로 이동할 수 있다. 인용 일치는
역사적 의미의 최종 검증을 뜻하지 않는다. 설명의 표현은 개념별 잠정 이해도와
현재 발화의 쉬운 설명 요청을 참고하나, 아직 완전한 개인화 생성 설명은 아니다.

확인 질문 뒤 사용자가 설명한 내용, 개념, 원문 근거, 모델의 잠정 판단과 경로 변경
이유를 저장한다. 숙달 등급이나 확정 점수로 표현하지 않는다. 정정 요청 시 관찰을
삭제해 과거를 바꾸는 대신 판단에 이의를 표시한다. 다른 대화에서도 현재 개념 기록을
계획에 활용한다. 자기평가나 근거 없는 모델 평가만으로 이해도를 갱신하지 않는다.

## 저장 및 API

- `learner_profiles`: 익명 소유 세션별 개념 관찰 기록.
- `learning_conversations`: 소유자, 개정 번호, 대화·목표·검색 결과·학습 계획 상태.
- `learning_turn_requests`: 요청 ID·내용 해시·처리 결과를 저장해 재시작 후에도 중복 방지.
- `learning_interrupts`: 처리 중인 요청에 대한 협력적 중단 신호.

기존 테이블과 API 계약을 삭제하거나 대체하지 않는다. 시작 시 `CREATE TABLE IF NOT EXISTS`로
추가한다. 새 대화 API는 공개 모드 설정과 관계없이 항상 소유 세션을 검사한다.

- `POST /api/learning/conversations`: 대화 만들기.
- `GET /api/learning/conversations`: 자신의 최근 대화 목록.
- `GET /api/learning/conversations/{id}`: 자신의 대화 상태 복원.
- `POST /api/learning/conversations/{id}/turns`: 요청 UUID와 개정 번호로 메시지·제어 전송.
- `POST /api/learning/conversations/{id}/interrupt`: 현재 개정에 대한 중단 요청.

브라우저 익명 세션 기반이며 계정 로그인·다른 기기 동기화는 없다. 쿠키 삭제나
브라우저 세션 만료 이후 동일인임을 보장하지 않는다. 기존 학습 데이터 삭제 기능에
대화·프로필·중복 방지 기록·중단 신호 삭제를 연결했다. 보관 기한은 대화의 마지막
활동 시점을 기준으로 판단한다.

## 실행 제한과 실패 처리

기본 한 발화당 계획·도구 노드는 최대 6회, 계획 입력은 최대 18,000자,
각 계획 출력은 최대 1,200토큰이다. 동일 발화 내 같은 검색·읽기는 반복하지 않는다.
기본 전체 시간 예산은 45초이고 각 모델 호출 시간제한은 남은 시간과 기존 제한 중
작은 값이다. 외부 도구의 이미 시작된 HTTP 호출을 강제 종료하지는 않는다.
중단·시간 예산은 다음 노드와 저장 직전에 확인하는 협력적 제어다.

`CULTUREBRIDGE_LEARNING_TURN_SECONDS`와 `CULTUREBRIDGE_LEARNING_TURN_STEPS`로
검증된 범위 안에서 조정한다. 기존 동시 실행·요청량 제한도 적용한다.
대화당 최대 200회, 소유 세션당 최대 100개 대화를 허용한다.
화면 복원은 최근 40개 메시지, 계획 이력은 최근 30건, 개념은 최대 32개와 개념당
최근 5개 관찰로 제한한다. 전체 무제한 대화 원문 보관 기능은 아니다.

AI가 없거나 실패하면 제한된 안내임을 표시한다. 사용자가 짧고 명확한 대상명을
입력하면 공식 검색을 제공하고, 결과를 직접 골라 원문을 읽을 수 있다. 이 대안 경로를
자율 AI 계획 또는 개념 이해도 평가 완료로 표시하지 않는다.

## 추가 개발 및 검증 필요

이번 변경으로 요구사항 R01~R10 전체를 완료 처리하지 않는다.

1. 표준국어대사전 도구의 실제 인증키 연결 검증. 코드·라이선스 표시 연결은 문서 35 참고.
2. 국가유산 용어사전 전용 API 제공 여부 확인. 웹 페이지가 있다는 이유로 API라고 단정하지 않기.
3. 기존 퀴즈의 명시적 대화 복습 연결은 문서 38에서 추가했다. 실제 AI 판단의 교육적 타당성과 적응형 평가 다양화는 남아 있다.
4. 일반 역사·해외 질문에 필요한 공식 도구 확장. 현재 새 검색 도구는 국가유산청 대상명 검색이다.
5. 직접 지정한 관심사·목표는 문서 37, 저장 확인 없는 대화 자동 파악은 문서 39에서 연결했다. 실제 추정의 정확성과 개인별 설명 품질 검증은 남아 있다.
6. STT·안내 말투·PWA 기본 코드는 문서 36에서 추가했다. 실제 마이크 인식·Android/iOS 설치는 별도 검증 필요.
7. 실제 Gemini 응답의 교육 품질·의미 타당성 검토 및 실제 기기 사용성 검증.

회귀 테스트의 가짜 모델 응답은 상태 전이·소유권·출처 연결 검증용이며 실제 Gemini의
응답 품질이나 학습 효과를 증명하지 않는다. 교수님 문서에 제시된 WBS 개편안은 별도로
반영해야 한다. 기존 제출본이나 이용 허가의 승인 상태는 이번 작업에서 변경하지 않는다.
