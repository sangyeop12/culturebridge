# 음성 입력·안내 말투·홈 화면 추가

기준일: 2026-10-21. 담당자: 김상엽.

## 음성 입력

홈 자유 입력과 대화 화면에 ‘말로 입력’, ‘음성 입력 멈추기’를 추가했다.
버튼의 브라우저 클릭 처리에서 Web Speech API를 시작한다. 한국어, 단회 인식,
최대 30초이며 전사 결과를 입력란에 더한 뒤 사용자가 직접 전송한다.
인식 시작 후 직접 수정했거나 입력 한도 1,000자를 넘으면 덮어쓰지 않는다.
전송 중, 중단 후, 페이지 이동 후 늦게 도착한 전사는 반영하지 않는다.

오디오 녹음·서버 업로드·파일 저장·음성 재생(TTS)은 구현하지 않았다.
전송한 텍스트는 기존 대화 기록으로 저장한다. 브라우저 제공업체가 음성을 원격 처리할
수 있다는 안내를 입력란 주변에 표시했다. 브라우저 정책과 외부 음성 처리 동의는
사용자가 판단해야 한다. 지원되지 않는 브라우저·권한 거부·음성 없음·네트워크 실패에서는
텍스트 입력을 계속 제공하며 자동 재시도하지 않는다.

Web Speech API는 모든 브라우저에서 지원되지 않으며 일부 구현은 원격 음성 인식이다.
[MDN SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)

## 말투와 설명 깊이

`GET/PUT /api/learning/preferences`와 `learning_preferences` 테이블을 추가했다.
소유 익명 세션별로 친근하게·정중하게·간결하게·직접 선택을 저장한다.
전체 학습 기록 삭제 시 해당 세션의 설정도 삭제한다. 보관 기한 정리는 살아 있는
대화가 없는 오래된 설정에만 적용한다.

처음에는 화면의 알려진 안내 표현만 바꾸었으나, 문서 40의 후속 변경으로 다음 설명의
문장 표현과 풀이 깊이도 조절한다. 모델 계획·이해도 평가에는 말투 설정을 전달하지 않고,
설명 생성 단계에만 제한된 말투·깊이를 전달한다. 문장별 인용 검사와 별도 AI 의미 검사를
통과한 풀이를 사용하며 실패하면 기존 읽기 도움말로 이어간다.

원본 대화·사전 뜻풀이·사용자 문장·공식 원문을 덮어쓰지 않는다. 직접 선택은
‘존댓말’, ‘간결’, ‘짧게’를 인식하며 그 밖의 요청은 친근한 안내를 사용한다.
깊이는 자동·쉽게·자세히로 구분하고 현재 발화의 요청을 우선한다.

## 홈 화면 추가 기반

`/manifest.webmanifest`, `/sw.js`, `/pwa/*`, `/install`을 추가했다.
이름·시작 주소·독립 실행 표시·180/192/512px 창작 누각 아이콘을 제공한다.
192/512px 아이콘은 maskable 안전 영역 안에 주요 도형을 배치했다.
브라우저가 설치 제안을 제공할 때만 사용자의 클릭으로 요청하고, iOS Safari는
공유 메뉴에서 ‘홈 화면에 추가’하는 방법을 안내한다. 설치나 권한 허용은 자동화하지 않는다.

Service Worker는 공개 연결 안내와 아이콘만 사전 캐시한다. 대화·비교·퀴즈·학습 기록·API·
개인화 HTML·POST·검색 문자열이 있는 요청은 저장하지 않는다. 개인화 화면은 네트워크로
읽으며 연결 실패 시 일반 안내만 보여준다. 오프라인 입력 전송 대기열도 없다.
새 버전은 대기 상태로 두고, 입력 유실 안내 후 사용자가 ‘새 버전 적용’을 선택한 경우만
활성화와 새로고침을 요청한다. 캐시 정리는 이 서비스의 공개 캐시 이름에만 한정한다.

실제 기기는 HTTPS 접속이 필요하며 localhost/루프백은 개발 예외이다.
브라우저별 설치 지원과 노출 방식은 다르다.
[MDN 설치 조건](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)

홈 화면 추가는 서버 호스팅이나 로그인 기능이 아니다. 서버가 켜져 있어야 대화와
검색을 사용할 수 있다. 브라우저와 설치 컨테이너 사이의 쿠키·기록 연속성은 실제 기기에서
별도 확인해야 하며 기기 간 자동 동기화를 보장하지 않는다. 외부 배포는 이번 범위가 아니다.

## 검증과 남은 확인

- Python 테스트: 설정 소유권·삭제·검증, 인용 보존, 음성 텍스트 병합, 웹 자원과 화면 응답.
- Node 단위 검사: 권한 실패 등 인식 이벤트, 중단·지연 결과, 공개 캐시 한정과 업데이트 선택.
- 로컬 브라우저: 텍스트 대화·말투 저장·중단 안내·새로고침 복원·홈 화면 안내 확인.
- 전체 Python 회귀 검사: 3.12·3.13 각각 560개 통과. Node 브라우저 로직 단위 검사 13개 통과.
- wheel 빌드 성공 및 음성·PWA 스크립트 포함 확인. `.env`·DB는 패키지에 포함되지 않음.
- **미실시:** 실제 마이크 인식, Android/iOS 설치·단독 실행·권한 전환, 실제 Gemini 품질,
  실제 사전 인증키 연결. 단위 테스트의 가짜 브라우저 API는 실제 기기 검증이 아니다.

실제 키는 등록하지 않았고 GitHub 업로드도 수행하지 않았다.
