# 해외 비교 기본 · 국내 비교 부가 기능

기본 홈은 ‘해외 문화유산과 비교’, 국내 비교는 펼쳐보기 안의 별도 진입 버튼과 `/domestic` 화면으로 구분한다.
시작 유산의 국가와 무관하게 해외는 한국 밖, 국내는 한국이다. 국가가 불명확하거나 한국과 해외가 혼합된 후보는 자동 선택하지 않는다.

## 적용 범위

- 공식 후보 검색, 상세 후보 재검사, 자율 탐구, 등록 유산 추천, 명시적인 비교 생성에 동일한 범위 조건을 적용한다.
- 해외 모드는 UNESCO 후보만 검색하고 국내 모드는 국가유산청 후보만 검색한다. 시작 대상 자료 조회는 대상에 맞는 기관을 사용한다.
- 제한된 재검색에서도 범위를 유지한다. 후보 부족 시 보류하며 국내/해외를 몰래 바꾸지 않는다.
- 새 비교 저장본에는 범위를 기록한다. 과거 저장본과 원문은 수정하지 않는다.
- 검색 반환 문맥과 상세 수준 전환, 추천·탐구·비교 링크에 범위를 전달한다.

## 검증

`tests/test_comparison_scope.py`는 국가 구분, 범위별 검색 기관, 후보 부족 시 보류, 상세 국가 재검사,
자율 탐구→비교 저장→퀴즈 연결, API 범위 검사, 별도 국내 화면과 검색 조건 유지 등을 검사한다.
HTTP/컴포넌트 검증이며 실제 브라우저 클릭·모바일 시각 검증을 대신하지 않는다.

- Python 3.13.15 / 3.12.14 전체 테스트 각각 284개 통과. 실시간 Gemini 호출 없이 검증했다.
- 마지막 상세·목록 링크의 비교 범위 전달 보완 후 범위·반환 이동 테스트 36개 재검증.
- Ruff 검사와 형식 검사 통과.
- 수정된 서버 `http://127.0.0.1:8081/`에서 상태 확인·기본 홈·국내 홈·국내 범위를 지정한 한국/세계 검색 화면 HTTP 200 확인.

## 남은 제약

UNESCO 등재 자료에 개별 탑의 직접 근거가 충분하지 않으면 해외 비교를 보류할 수 있다.
국내 후보를 대신 보여 주거나 이름만 비슷한 해외 후보를 강제로 비교하지 않는다.
실제 Gemini 계획·선택 성공 경로는 API 사용량 제한 해제 후 별도 확인이 필요하다.
