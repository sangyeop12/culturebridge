# 대표 코스·자료 검토표·학습 결과 내보내기

## 적용 범위

2026-10-17 기준. 기존 비교·맞춤 학습·퀴즈·복습 기능을 재사용했다.
국가와 해외 자료 수를 늘리지 않았으며, 25개 전체를 억지로 코스에 배치하지 않았다.
유료 배포·과금·기존 학습 기록 삭제는 수행하지 않았다.

## 자료 검토표

`/sources`에서 대상별 검토 사항을 펼쳐 보고 검토표를 내려받을 수 있다.
[25개 검토표](22_해외문화유산_25개_검토표.md)는 원문 본문이 아닌 메타데이터와 검토 항목이다.

- 연결 상태와 한국어 의미 검토·재이용 허가를 구분한다.
- 한국어 안내명·별칭, 개별 건물/경내 전체, UNESCO 상위 등재 관계를 함께 표시한다.
- 대상별 주의 사항: 내부 불상의 재료와 건물 재료, 창건·이전·재건, 성과 성당의 연대 등을 구분한다.
- 팀 승인 기록이 없으면 한국어 이름과 풀이를 검토 완료로 표시하지 않는다.
- 기관 이용 조건의 참고 링크와 미확정 범위를 표시한다. 공식 자료라고 자유로운 저장·번역·재배포를 허용하는 것은 아니다.
- 교육 목적이라는 이유만으로 공개 웹 서비스나 AI 변환이 자동 허용된다고 간주하지 않는다.
- 호류지 오층탑은 별도 연결 보류 대상으로 남겨 25개 수에 포함하지 않는다.

검토표 재생성(기존 파일은 덮어쓰지 않음):

```powershell
.\.venv313\Scripts\python.exe -m culturebridge.review_materials --output outputs/material-review.md
```

이 명령은 현재 DB의 마지막 연결 시도와 수집본을 읽는다. 새 원문 수집이나 Gemini 호출은 하지 않는다.
자동 유형 대조는 의미·범위 검증의 대체 수단이 아니다. 미수집이면 근거 항목을 비워 둔다.

## 대표 수업 5개

| 코스 | 비교 대상 | 기본 수준·시간 | 목표 |
|---|---|---|---|
| 두 나라의 탑, 모양과 재료 살펴보기 | 다보탑–도지 오층탑 | 초급·25분 | 구조·재료 |
| 큰 건물의 지붕과 공간 읽기 | 도다이지 대불전–에든버러성 대연회장 | 중급·25분 | 건물과 구성 부분 |
| 궁전의 공간과 장식 비교하기 | 니노마루 어전–그랑 트리아농 궁전 | 중급·30분 | 공간·장식·재료 범위 |
| 무덤을 설명하는 공간과 재료 | 경주 무열왕릉–타지마할 묘당 | 초급·25분 | 무덤과 주변 설명 구분 |
| 성당의 연대와 공간, 원문으로 읽기 | 생트샤펠–더럼 대성당 | 고급·30분 | 연대의 사건·원문 대조 |

시간은 수업 설계용 권장치이며 학습 성과가 실증된 소요 시간은 아니다.
각 `/courses/{id}`에서 목표·활동 3개·마무리 질문을 확인하고 설명 수준을 선택한다.
시작할 때 양쪽 원문을 확보하고 목표의 근거 항목을 재검사한다. 부족하거나 오래된 자료만 있으면 보류한다.
자료 읽기 → 비교 → 5문항 퀴즈 → 오답 복습 → 학습지 저장 순서로 진행한다.
자유 탐구는 기존 홈 검색에서 계속 이용할 수 있다.

코스 기록은 익명 세션별로 표시한다. 코스에서 시작한 비교를 삭제하면 연결된 코스 기록도 삭제된다.
이전 수준의 기록은 해당 수준으로 이어 볼 수 있다. 쿠키 삭제 후 기록 복구를 보장하는 계정 시스템은 아니다.

## 결과 저장

비교 화면·퀴즈 채점 후·학습 기록·코스 기록에서 다음을 이용한다.

- 인쇄·PDF 저장: 인쇄용 HTML을 열고 브라우저 인쇄에서 PDF 저장을 선택한다.
- 학습지 `.md`: 목표·학습 순서·비교 요약·출처·제출된 점수·복습 활동·작성란을 저장한다.
- 학습 데이터 `.json`: 같은 결과를 구조화된 형태로 저장한다.

이 기능은 브라우저 인쇄 방식이며 서버가 PDF 파일을 생성하는 기능은 아니다.
제출 전에는 점수·정답을 내보내지 않는다. 제출 후에도 문항 본문·선택지·정답·원문 전체·직접 인용은 제외한다.
지원되지 않는 표현은 억지로 요약하지 않고 원문 확인이 필요하다고 표시한다.
자유 목표·점수 등은 개인 학습 정보일 수 있으므로 파일 공유 전 확인이 필요하다.
파일 생성에 Gemini나 외부 기관 재조회는 필요하지 않다.
기본 예제 등 구조화된 근거가 없는 항목은 판단 보류로 표시될 수 있다.

내보내기는 로컬 모드에서도 세션 소유권을 확인한다. 저장 ID를 알아도 다른 세션의 학습지는 받을 수 없다.
특정 채점 회차를 요청하면 비교 ID와 회차의 소유권을 함께 확인한다.
HTML은 사용자 문자열을 이스케이프하며 응답은 `private, no-store`로 반환한다.

## 확인 범위와 남은 검토

격리된 점검용 DB에서 25개 원문 연결·유효 항목 2개 이상, 5개 코스의 비교 저장·5문항 생성까지 확인했다.
키 없이 동작하는 대체 경로로 점검했으며 실제 Gemini 교육 품질을 입증하는 결과는 아니다.
한국어 이름·풀이의 의미 승인과 각 기관의 공개 이용·번역·AI 처리 권한 확인은 별도 작업이다.
연결 성공·테스트 통과를 역사적 분석 또는 권한 검토 완료로 바꾸어 표시하지 않는다.

API:

- `GET /api/courses`
- `POST /api/courses/{course_id}/start` (`level` 선택)
- `GET /api/courses/{course_id}/progress`
- `GET /api/material-review?format=json|md`
- `GET /api/comparisons/{record_id}/export?format=html|md|json&history_id=...`
