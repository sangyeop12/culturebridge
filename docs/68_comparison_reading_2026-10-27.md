# 비교 화면 표시 개선 (2026-10-27)

- 저장 데이터를 수정하지 않고 양쪽의 유효한 근거가 있는 항목만 표시한다.
- 일반 비교에서 빠진 항목 안내와 공통점 없음 블록은 표시하지 않는다.
- 사용자가 명시한 학습 목표의 근거가 없을 때만 안내한다. 비교 가능한 항목이 전혀 없으면 다른 유산을 찾는 경로를 제공한다.
- 영어 비교 설명은 한국어 읽기 도움말로 먼저 표시하고 원문·출처는 펼쳐보기로 제공한다. 도움말은 전체 번역으로 표시하지 않는다.
- 한국어 풀이 버튼은 해당 항목의 정확한 원문 인용을 기존 번역 서비스에 전달한다. 번역 및 AI 이용 조건을 모두 확인하고, 숫자·부정·재건·추정 표현 등의 기존 검사를 유지한다.
- 검사에 통과한 한국어 풀이가 저장되어 있으면 다음 조회부터 우선 표시한다. 화면 조회만으로 Gemini를 호출하지 않으며, AI가 꺼져 있어도 저장된 풀이를 사용할 수 있다.
- 원문 및 저장 비교의 근거는 그대로 보존한다. 자동 검사는 번역의 역사적 의미에 대한 전문가 검토를 대신하지 않는다.

## 확인 결과

- 통합 검사: 린트·서식 검사 및 테스트 830개 통과.
- 캐시 조회 분리 후 관련 테스트 28개 추가 실행 통과.
- 실제 저장된 니노마루 어전–그랑 트리아농 비교 화면 확인: 시대·종교 항목 미표시, 구조·재료 한국어 도움말 표시, 공식 원문 펼쳐보기 유지.
- 이번 확인에는 실제 Gemini 호출을 사용하지 않았다. 실제 번역 응답 품질은 확인하지 않았으며, 한도·권한·연결 문제 시 도움말로 유지한다.
