# 화면 문구와 WBS 갱신

## 작업 범위

홈·대화·설정·관심사 관리·검색·유산 상세·비교·퀴즈·코스·학습 기록·이용 안내의
고정 문구와 자료 확인 과정의 표시 경로를 점검했다. 공식 원문, 사전 뜻풀이,
사용자의 대화, 공식 기관 이름과 검색어는 바꾸지 않았다.

- 설명 문체 → 설명 표현, 설명 깊이 → 설명의 자세함.
- 이해도에 대한 잠정 기록 → 지금까지의 이해도 살펴보기.
- 지지·반박 후보 → 설명을 뒷받침하거나 어긋날 수 있는 근거.
- 원문 추출·문자열 일치·최신 캐시 등의 표현을 자료 찾기·인용문 대조·보관 자료로 정리.
- 비교 범위 확인·개별 공식 자료 확인 과정에서 내부 도구명이 그대로 노출되던 경로 보완.
- 자동 삭제·백업의 켜짐 여부를 실제 동작에 맞는 쉬운 문장으로 안내.
- 체험의 석굴암 공식 원문 → 비교 학습 링크에 체험 모드 유지. 학습 수준과 국내외 범위도 유지.

기능·도구 선택·저장 방식·공식 자료 이용 조건은 바꾸지 않았다. 친근한 문장을
일괄적인 격식체로 바꾸지 않았다. 알려진 고정 안내만 수정했으며 자유 생성 답변을
문자열 치환으로 일괄 수정하지 않았다. 과거에 저장된 비교의 안내는 저장 시점 문구가
남아 있을 수 있다.

## 확인 결과

- Python 3.13: 전체 통합 검사 796개, Ruff 린트·249개 파일 서식 검사 통과.
- Python 3.12: 화면 문구·체험 이동·검색 복귀 관련 검사 61개 통과.
- 12개 주요 경로의 HTTP 렌더링, 친근한 표현 유지, 공식 인용·사용자 입력 보존 검사.
- 새로운 내부 도구 표시 검사 7개와 앞서 추가한 체험 링크 조합 검사 12개 포함.
- 별도 테스트 DB의 브라우저에서 설정의 새 항목명과 비교 질문 안내 표시 확인.
- 실제 5분 무조작 초기화와 이전 기록 차단은 문서 61에 따로 기록.

일반 서버 8081과 개인 DB를 점검용으로 바꾸지 않았다. 브라우저 화면 검사는 Gemini를
끄고 수행했다. 실제 AI 호출 검증은 사용자 요청 순서에 따라 GitHub 반영 뒤 별도 실행한다.

## WBS 반영

실제 현황본의 기능상세 177개를 쉬운 표현으로 바꾼 수정본을 유지한다.
이후 최신 검사 수와 5분 초기화 확인 결과를 E228·E229·E245에 반영했다.
기능상세 최대 길이는 기존과 같은 17자다.

267개 작업, 김상엽 담당, 10~12월 일정, 양식·병합·서식·주말 날짜 색상·드롭다운은 보존했다.
완료 246개·진행 중 17개·예정 4개로 상태 수는 변하지 않았다.
실제 AI 품질·목표 변경·완주, 휴대전화 음성·설치, 실제 확대, 실제 수업 항목은
미확인 부분이 있어 진행 중 또는 예정 상태를 유지했다. 10월 27일 계획 제출본은 바꾸지 않았다.

기존 원본은 `outputs/wbs-plain-20261025/before.xlsx`, 이번 상태 갱신 직전 파일은
`outputs/copy-audit-20261025/wbs/before.xlsx`에 보존했다. 원시 DB·화면·API 키는
GitHub 업로드 대상에서 제외한다.
