# 한국어 풀이 자동 준비와 후속 학습 점검

## 구현

- 새 비교 저장 후 양쪽에 유효한 근거가 있는 영어 항목의 한국어 풀이를 준비한다. 기존과 같은 캐시 키로 저장해 비교 화면에서 별도 클릭 없이 사용한다.
- 번역·AI 처리 조건을 모두 만족하는 자료만 전송한다. 미허용 자료와 실패한 번역은 기존 한국어 읽기 도움말을 유지하며, 전체 번역이라고 표시하지 않는다.
- 429 발생 시 해당 번역 묶음의 후속 요청을 중단한다. 비교 기록은 이미 저장되어 있으므로 보존된다. 수동 풀이 버튼에도 한도 안내를 연결했다.
- 화면과 내보내기에서 양쪽 근거가 없는 비교 항목을 제외한다. 퀴즈의 개별 유산 문제는 한쪽에만 있어도 유효한 원문 사실을 사용할 수 있다. 이를 양쪽의 공통 사실로 간주하지 않는다. 동적 비교 퀴즈의 목표별 양쪽 근거 검사와 문항별 출처·대상 검사는 유지한다.
- 단일 근거를 인용하는 AI 문항이 다른 유산을 함께 지칭하거나 두 유산의 공통점을 주장하면 거부하도록 추가했다.
- 이전 저장 비교를 읽는 것만으로 외부 API를 호출하거나 기록을 덮어쓰지 않는다. 이전 기록은 준비된 캐시가 있으면 이를 사용하고, 없으면 수동 요청 또는 다시 탐구로 갱신할 수 있다.

## 실제 검증 (2026-10-30)

- 자동 검사: 전체 회귀 테스트 831개 통과. 이후 추가한 저장 보존·학습지 표시 검사는 관련 테스트 31개, 단일 근거 공통점 차단은 관련 테스트 15개로 추가 확인했다. 린트·서식 검사 통과.

- 실제 Gemini 7회 호출: 6회 응답, 7번째 429. 이후 호출 중단.
- 다보탑 요청에서 검색·읽기 도구 및 설명, 이후 세종대왕 주제로 변경 시 역사 검색 도구 선택을 확인했다. 두 번째 응답은 추가 질문이므로 목표 달성 완료로 판정하지 않는다.
- 해외 비교 첫 요청에서 제한 발생. 비교→퀴즈→복습 전체 흐름 및 번역의 의미 정확성은 미검증이다.
- 니노마루 어전·그랑 트리아농의 현재 자료는 AI 처리·번역 조건이 승인되지 않아 실제 전송 0회였다. 허가 상태를 임의로 변경하지 않았다.
