# 실제 호출 재확인과 평가 자료 보완

점검일: 2026-10-25. 사용자가 요청한 잔여 작업을 진행했다.
API 키·모델·한도·과금은 변경하지 않았으며, 사용자 학습 DB와 분리한 실행 기록을 사용했다.

## 실제 호출

1. 최소 호출 점검에서 SDK 요청 1회가 응답했다. 호출 예산이 1회여서 전체 설명 완주를
   평가한 실행은 아니다. API가 다시 완전히 초기화됐다고 해석하지 않는다.
2. 다보탑 기준 비교와 주제 변경을 최대 18회 SDK 요청 안에서 점검하도록 실행했다.
   비교 요청의 계획 응답 2회 후 세 번째 요청에서 일일 무료 한도 429가 나왔다.
   추가 호출을 중단했으며 후속 턴과 주제 변경 시나리오는 실행하지 않았다.

| 비교 요청 실행에서 관찰한 항목 | 결과 |
|---|---|
| 사용자 요청 | 다보탑 기준, 해외 유산, 시대·재료 비교, 퀴즈 준비 |
| 실제 모델이 선택한 도구 | 다보탑 검색 후 해당 국가유산청 개별 원문 읽기 |
| 소요 시간 | 사용자 턴 7.99초, 표본 1개 |
| SDK 요청 | 응답 2회, 한도 오류 1회 |
| 성공 응답의 보고 사용량 | 입력 4,702토큰, 출력 187토큰 |
| 비교·퀴즈 완주 | 미완료, 저장된 비교 없음 |
| 원래 요청 | 실행 DB의 pending_request에 보존 |
| 기준 대상·항목 | task_contract에 다보탑, 시대·재료, 퀴즈 요청 보존 |
| 사용자 안내 | 한도 도달과 자료·요청 보존 표시 |

실패 요청의 사용량이 없어 전체 실행 비용은 확정하지 않는다. 2/3은 SDK 응답 비율이지
과제 성공률이 아니다. 비교가 생성되지 않아 목표 이탈률은 측정하지 못했다.
이 실행에서 요청 보존은 실제로 확인했지만, 한도 회복 후 완주나 장기적인 일관성이
검증됐다는 의미는 아니다. WBS의 실제 AI 품질·완주 평가는 진행 중으로 유지한다.

원시 실행: `outputs/agent-quota-probe-20261025-04.json`,
`outputs/agent-live-goals-20261025-04.json`과 각 실행의 동명 DB.
실제 실행을 더 추적할 수 있도록 후속 보고에는 목표 계약과 대기 요청 보존 여부도 기록한다.

## 이해도 평가 자료의 실행 가능성

기존 해외 평가 사례의 원문이 준비돼 있어도 현재 프로젝트 정책상 AI 처리가 허용되지
않는 출처는 모델에 전송하지 않았다. 이번 선택 사례 6개는 이 이유로 API 요청 없이 중단됐다.
기존 원문 연결 성공과 실제 AI 평가 가능 상태를 혼동하지 않도록 도구를 수정했다.

- `source_matches_case`와 `source_ai_allowed`를 별도로 기록한다.
- 오프라인 점검에서도 정책 차단 건수를 표시한다. 텍스트 일치만으로 준비 완료 처리하지 않는다.
- 기존 해외 자료는 그대로 유지하며 정책을 우회하거나 권한을 임의 승인하지 않는다.
- 국가유산청 문서 캐시를 직접 읽는 평가 경로와 제공자 구분 ID를 지원한다.
- 다보탑의 추정 연대·기단/탑신 구조·석탑 재료·종교적 맥락에 관한 10개 응답 사례를 추가했다.
- 정답 풀이, 오개념, ‘모르겠어요’, 다른 주제로 전환하는 응답을 구분한다.
- `--variant`로 특정 응답만 선택할 수 있어 재검증 때 불필요한 중복 호출을 줄인다.

실제 수집한 2026-10-25 다보탑 원문과 대조한 오프라인 결과는 10개 모두 텍스트·정책 조건을
충족했다. **모델 판단은 아직 실행하지 않았으므로 판단 일치율은 미측정**이다.
사례와 기대 판정은 AI가 작성한 검토 기준이며, 역사 전문가가 승인한 정답 집합이나
실제 학습자의 교육 효과 자료가 아니다.

```powershell
# API를 호출하지 않는 준비 상태 점검
.venv313/Scripts/python.exe scripts/check_assessment_quality.py --db outputs/agent-live-goals-20261025-04.db --output outputs/assessment-next-ready.json --case khs-estimated-year --case khs-pagoda-structure --case khs-stone-material --case khs-religious-context

# 한도 회복 후 명시적으로 실행할 때만 --live 사용
.venv313/Scripts/python.exe scripts/check_assessment_quality.py --db outputs/agent-live-goals-20261025-04.db --output outputs/assessment-next-live.json --case khs-pagoda-structure --variant 0 --variant 1 --live --max-calls 2
```

새 출력 경로만 사용하며 기존 실제 기록은 덮어쓰지 않는다.
기존 화면·비교·퀴즈·원문 기능을 제거하지 않았다.

변경 관련 자동 검사 31개를 Python 3.13·3.12에서 각각 통과했고 Ruff 검사도 통과했다.
자동 검사는 사례 선택·캐시 읽기·권한 차단·호출 중단 등 구현 검증이며,
실제 모델의 이해도 판정 정확성을 대신하지 않는다.
