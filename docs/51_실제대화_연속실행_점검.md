# 실제 모델·공식 자료를 연결한 대화 점검

점검일: 2026-10-24

## 범위와 방법

실제 Gemini와 기존 공식 자료 조회 도구를 사용했다. 모델 응답·검색 결과·원문을 모의 응답으로
대체하지 않았다. 다만 학습자 발화는 점검용으로 작성했으므로 실제 학생 참여 시험은 아니다.
기존 사용자 DB와 분리한 새 DB에서 실행했으며, 모델 SDK 호출 수와 오류 코드를 기록했다.
과금 설정·API 키·서비스 코드는 변경하지 않았다.

새 `scripts/check_agent_dialogues.py`는 시나리오별 새 대화와 학습자 소유 세션을 사용한다.
실제 실행 결과·최종 응답·인용 수·비교/퀴즈 생성 여부를 기록한다. 429가 발생하면 해당 실행에서
남은 모델 호출을 중단하며, 이후 발화를 통과로 계산하지 않는다. 별도 재실행도 보고서를 덮어쓰지 않는다.

이번에는 5가지 상황에서 6턴을 실행했다. 실제 SDK 호출 시도는 총 14회이며, 12회 응답과
2회 429 오류를 관찰했다. 장기 대화·반복 실행의 안정성을 확정할 표본은 아니다.

## 관찰 결과

| 상황 | 실제 행동 | 평가 |
| --- | --- | --- |
| 관심이 정해지지 않은 시작 | AI가 관심 시대·주제를 질문. 사실 설명·이해도 판정 없음 | 적절한 시작. 한 번에 질문이 여러 개여서 간결성 보완 가능 |
| 다보탑 재료 설명 요청 | 국가유산청 검색 → 개별 원문 읽기 → AI 설명·인용 | 도구 연결은 정상. 설명에 높이 정보가 포함돼 재료 질문에 대한 직접성·초급 풀이가 미흡 |
| 같은 대화에서 “좀 더 쉽게, 확인 질문” | 429 이후 제한 안내로 전환 | AI 실패임을 명시했으나 현재 자료를 활용하지 않고 일반 관심 질문으로 돌아감. 흐름 유지 미흡 |
| 세종대왕·훈민정음 공식 자료 요청 | `search_history` 실행 후 자료 선택 질문 | 실제 자료 검색 실행 확인. 본문을 읽은 것으로 답하지 않음. 안내 문장은 공식 원문으로 이동한다는 점을 더 분명히 할 필요 있음 |
| 의도적으로 없는 유산 이름 | 국가유산청 검색 결과 없음 → 재질문 | 존재하지 않는 유산 설명을 만들지는 않음. “이번 검색에서 찾지 못함”을 답변 첫머리에 명확히 안내하는 편이 적절 |
| 다보탑의 해외 탑 비교·퀴즈 요청 | 미확인 ID로 `discover` 시도 → 차단 → `search`로 변경 → 429 | 미확인 ID 차단과 실제 재계획 확인. 비교 저장·퀴즈 준비·복습 완주는 미확인 |

재료 설명의 문제는 역사적 거짓으로 확정한 것이 아니다. 원문에 있는 석탑·높이 설명을 인용했으나,
“무엇으로 만들었는지 쉽게 설명해 달라”는 요청에 높이보다 돌이라는 재료 풀이를 우선해야 한다는 문제다.

없는 유산은 “세계 어디에도 존재하지 않는다”라고 단정할 수 없다. 확인한 검색 범위에서 결과가
없다는 사실을 명확히 안내해야 한다.

## API 제한과 검증하지 못한 부분

실제 429 응답의 `quotaId`는 `GenerateRequestsPerMinutePerProjectPerModel-FreeTier`,
`quotaValue`는 `5`였다. 마지막 오류에는 `retryDelay: 13s`가 있었다. 이는 이번 키·모델에서
관찰한 응답이며, 모든 Gemini 계정에 동일한 한도가 적용된다는 설명은 아니다.

이전 단일 계획 검사와 달리 실제 학습 한 턴에는 계획 선택 여러 번, 설명 작성, 별도 의미 검사 등이
포함된다. 따라서 다중 단계 흐름의 호출 수와 사용 가능한 한도를 함께 고려해야 한다.
이번 실행은 다음을 완료한 것으로 표시하지 않는다.

- 실제 해외 자료 수집 → 비교 저장 → 퀴즈 → 고정된 점검자 답안 제출 → 복습 전체 완주
- 자연어 주제 변경의 실제 연속 대화
- 여러 번 반복했을 때의 행동 일관성
- 실제 학생의 학습 효과·역사 전문가 검토

기존 자동 계약 검증이나 합성 관찰을 사용한 모델 계획 검사를 위 미검증 항목의 대체 통과로 계산하지 않는다.

## 수정 우선순위

1. **질문과 설명의 초점 맞추기**: 항목명이 재료라는 이유만으로 전체 문장에 포함된 높이까지
   설명하지 않도록, 질문에 답하는 핵심 사실과 쉬운 용어 풀이를 우선하고 목표 적합성을 검사하기.
2. **호출 제한 후 흐름 유지**: 현재 자료·학습 목표·진행 중 활동을 유지하고, 재개 안내를 제공하기.
   `좀 더 쉽게` 같은 자연스러운 후속 표현도 제한 안내에서 기존 자료와 연결하기.
3. **도구 선택의 실행 가능 조건 전달**: 아직 관찰한 유산 ID가 없을 때 후보 탐색을 선택하지 않도록
   도구별 전제 조건을 계획에 명확히 전달하기. 서버의 미확인 ID 차단은 계속 유지하기.
4. **명확한 결과 안내**: 검색 실패는 확인한 범위의 실패로 설명하고, 인물·사건 자료는 외부 공식
   원문으로 이동하는 기능임을 안내하기.

위 실제 대화 점검 시점에는 서비스 수정을 적용하지 않았다. 이후 사용자 요청으로 적용한 변경은
[후속 수정 기록](52_대화_초점과_학습흐름_보완.md)에 별도로 정리했다. 당시 실제 응답 결과는 그대로 보존한다.

## 재현 자료

로컬의 `outputs/`는 Git 제외 경로다. 사용자 기록이 아닌 점검용 대화와 공식 자료 캐시만 포함한다.

- `outputs/agent-dialogues-2026-10-24-initial.json` 및 동명 `.db`
- `outputs/agent-dialogues-2026-10-24-followup.json` 및 동명 `.db`
- `outputs/agent-dialogues-2026-10-24-comparison.json` 및 동명 `.db`

재실행 예시:

```powershell
.venv313/Scripts/python.exe scripts/check_agent_dialogues.py --live --output outputs/new-dialogue-review.json --scenario overseas_comparison --max-calls 18
```

새 파일명을 사용해야 하며, 정상 API 사용량이 발생한다. 별도 허가 없이 유료 설정·키 변경으로
한도를 확대하지 않는다.
