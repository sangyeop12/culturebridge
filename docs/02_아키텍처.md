# 3. 시스템 아키텍처

□ 3.1 시스템 구성

사용자 브라우저·박물관형 터치 화면 → NiceGUI → FastAPI → 서비스 계층 → LangGraph Agent·SQLite → 검증된 결과 → NiceGUI 화면

□ 3.2 AI Agent의 4가지 역할

① 자율 학습 커리큘럼 설계 Agent

학습 수준과 목표를 확인하고 탐구 순서·비교 항목·학습 분량을 결정한다.

② 자율 역사 탐구 Agent

선택 문화유산과 비교 후보를 찾고, 공식 자료가 연결된 비교 초안을 만든다.

③ 맞춤형 퀴즈 생성·평가 Agent

검증된 학습 내용으로 수준별 4지선다형 문제와 해설을 구성한다.

④ 역사적 주장 검증 Agent

설명과 사용자 주장을 출처와 대조하고 `확인됨`, `추가 확인 필요`, `근거 부족`으로 분류한다.

□ 3.3 실행 원칙

- LangGraph는 검색 → 자료 수집 → 비교 → 검증 → 학습 결과 생성 상태를 관리한다.
- 생성형 AI가 없어도 검색·추천·비교 API는 결정론적으로 동작한다.
- Gemini 응답은 검증 전 초안으로 취급한다.
- 검증 결과가 충분하지 않으면 단정형 문장을 반환하지 않는다.

□ 3.4 기술 스택

| 구분 | 기술 | 적용 기준 |
| --- | --- | --- |
| 언어 | Python 3.12·3.13 | 현재 개발 환경 3.12, 목표 환경 3.13 호환 |
| Frontend | NiceGUI | 웹·키오스크 공용 UI |
| Backend | FastAPI | REST API·입력 검증 |
| Agent | LangGraph | 상태 기반 실행과 조건 분기 |
| LLM | Gemini API | 비교 설명·문항 초안 생성 |
| DB | SQLite | 문화유산·출처·비교·퀴즈·학습 기록 |
| 서버 | Uvicorn | ASGI 실행 |
