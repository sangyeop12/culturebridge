# 학생용 화면 간소화 — 2026-10-27

## 변경 범위

- 주요 메뉴를 대화 학습·문화유산·학습 코스·나의 학습으로 정리했다.
  홈은 로고 링크, 설정은 기존 설정 버튼으로 접근한다.
- 관련 화면 링크는 ‘더 둘러보기’로 묶었다. 기존 주소와 기능은 유지했다.
- 홈 소개 영역을 줄이고 질문 입력을 앞쪽에 배치했다. 질문 예시 버튼은
  입력칸만 채우며 AI 호출이나 자동 제출을 하지 않는다.
- 비교 화면의 중복 목표 표기를 줄였다. 학습 순서는 펼쳐볼 수 있다.
- 핵심 비교 뒤에 퀴즈 이동을 배치하고 내 생각 정리·출처·추가 질문·주장 검증은
  각각 접힌 영역으로 제공한다. 기존 이벤트 처리와 저장 방식은 유지했다.
- 대화 답변의 여러 출처를 하나의 펼침 영역에 모았다. 원문과 이용 조건은 보존했다.
- 작은 화면에서는 네 개 메뉴를 같은 폭으로 배치하고 장식 삽화는 숨겼다.

## 검증

- Python 3.13 전체 자동 테스트 828개 통과, 린트·서식 검사 통과.
- 마지막 제목·모바일 간격 조정 후 Python 3.12 관련 테스트 54개 통과.
- 별도 DB와 Gemini 비활성 서버에서 질문 예시 입력, 추가 질문 펼치기,
  비교→퀴즈 이동 및 5/5 채점을 실제 브라우저로 확인했다.
- 390px 너비의 홈 화면과 키보드 Enter를 이용한 관련 메뉴 펼치기를 확인했다.
  실제 휴대전화나 학생 대상 사용성 평가를 대신하지 않는다.
- 기존 DB를 백업하고 8081 서버에 변경을 반영했다. 키·모델·사용자 설정은 바꾸지 않았다.
- 이번 점검에서 실제 Gemini 요청은 하지 않았다. 기존 AI 한도 관련 대기 항목은 그대로다.
