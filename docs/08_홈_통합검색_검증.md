# 홈 통합 검색 보완

2026-10-13 · Python 3.12/3.13 · 국가유산청·UNESCO

이후 검색 결과에서 직접 비교 탐구를 시작하는 동적 Agent를 추가했다.
기존 3개 대상 제한을 변경한 내용은 [동적 Agent 기록](09_동적_Agent_검증.md)을 참고한다.

## 수정 내용

- 홈은 NiceGUI Input이 보내지 않는 `update:model-value`에 연결돼 있었다. `on_value_change`로 변경해 입력/지우기 직후 목록이 갱신되도록 했다.
- 비교 등록 목록 3개와 공식 자료 발견 결과를 별도 영역으로 표시한다. 불국사 검색 시 기존 3개 카드가 그대로 남지 않는다.
- 홈에 자동완성·최대 8개 제안 버튼·검색 버튼·Enter 검색·검색 범위 선택을 추가했다.
- 자동완성은 기본 검토 검색어·등록 유산·이전에 검색한 국가유산청 이름·캐시된 UNESCO 영문 이름을 사용한다. 입력 중 외부/AI 호출은 없다.
- 공식 검색은 국가유산청과 UNESCO를 병렬 조회하며 한 기관 실패 시 나머지 결과를 유지한다.
- 한국 국가명은 국가유산청 전체 목록을 조회하고, 해외 국가명은 UNESCO 국가 검색으로 연결한다.
- 한글 별칭을 만리장성·타지마할·마추픽추·앙코르와트·후지산·자금성·피라미드·베르사유·콜로세움 등으로 보강했다.
- 별칭이 유산군을 가리킬 때는 공식 등재 이름을 그대로 보여준다. 별칭을 개별 건물의 사실로 사용하지 않는다.
- 결과는 기관별 10건, 이전/다음 페이지를 지원한다. 입력/범위를 바꾸면 이전 조회 결과를 지우고 늦게 도착한 결과도 폐기한다.
- 미등록 국내 유산은 국가유산청 설명 화면, 해외 세계유산은 UNESCO 원문으로 안내한다. 기존 비교·퀴즈 데이터로 자동 등록하지 않는다.

## 실제 자료 확인

| 검색어 | 범위 | 확인 결과 |
| --- | --- | --- |
| 불국사 | 통합 | 국가유산청 19건, UNESCO 1건 |
| 경복궁 | 한국 | 국가유산청 11건 |
| 한국 | 한국 | 국가유산청 17,940건 중 첫 페이지 |
| 만리장성 | 세계 | The Great Wall 1건 |
| 타지마할 | 세계 | Taj Mahal 1건 |
| France | 세계 | 57건 |

위 수는 조회 시점 기준이다. 국가유산청 결과에는 사찰 자체뿐 아니라 관련 탑·유물 등도 포함된다.
불국사/콜로세움 등의 UNESCO 매칭은 묶음 등재 기록일 수 있으며 이를 명시한다.

## 자동 검사 범위

- 불국사 공식 검색과 비교 미지원 구분, 부분 장애, 국가 검색 분기, 한글 별칭, 페이지 전달을 검사한다.
- 초기 캐시 없이도 기본 검색어 제안 가능, 입력 시 외부 호출 없음, 잘못된 검색어/범위 요청 거부를 검사한다.
- NiceGUI 홈 Input 값을 바꾸는 회귀 테스트로 기존 카드 제거·제안 표시·석굴암 재검색의 갱신을 확인한다.
- 이는 서버 UI 컴포넌트 검사이며 실제 브라우저 클릭·모바일 화면 배치 검증을 대체하지 않는다.
- 최종 자동 검사: Python 3.12.14와 3.13.15에서 각각 테스트 183개 및 Ruff/포맷 검사 통과.

## 지원 범위

한국은 국가유산청 공개 목록, 해외는 UNESCO 등재 목록이다. 전체 해외 문화유산·전체 유산명 한글 번역을 지원하는 것은 아니다.
공식 자료 조회가 가능한 유산 수와 비교·퀴즈 지원 유산 수(3개)는 다르다.
