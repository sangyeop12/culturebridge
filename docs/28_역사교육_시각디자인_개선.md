# 역사 교육 서비스 시각 디자인

2026-10-19 작업 기록.

- 공통 배경을 따뜻한 한지색으로 바꾸고 먹색·녹색·황토색 포인트를 사용했다.
- 주요 제목에 기기 기본 명조 계열 글꼴을 적용했다. 외부 글꼴 서버는 호출하지 않는다.
- 직접 작성한 벡터 삽화를 홈, 세계유산 검색, 대표 코스 목록·상세에 연결했다.
- 탑·큰 건물·궁전·무덤과 묘당·성당의 다섯 가지 주제를 구분한다.
- 코스 목록은 데스크톱 2열·좁은 화면 1열 카드이며 기존 학습 링크를 유지한다.
- 삽화는 유산 유형을 표현한 창작 이미지다. 특정 유산의 실제 모습·사진·복원도가
  아니며, 화면에 이를 표시한다. 구조·재료를 판정하는 근거로 사용하지 않는다.
- 실제 유산 사진이나 기관 이미지를 새로 수집·재배포하지 않았다. 원본 출처와
  사용 조건을 확인하지 않은 사진을 자동으로 불러오는 기능도 추가하지 않았다.
- 이미지 대체 설명, 기존 키보드 포커스·동작 축소·키오스크 터치 크기를 유지한다.
- 학습 설명·추천·Agent·DB 처리와 API 키 설정은 변경하지 않았다.

브라우저에서 홈·코스·세계유산 화면 렌더링을 확인했다. 390px 미리보기의 홈에서
가로 넘침이 없는 것을 확인했으며 실제 휴대전화 점검을 대체하지 않는다.
서비스는 기존 8081 주소에 재시작해 적용했다. GitHub 업로드는 이번 요청에 포함하지 않았다.

검증: Python 3.13 전체 458개 통과(111.28초), 변경 UI 파일 Ruff 통과, 정상 서비스
상태 확인 200. 기존 테마 검사의 배경색 기대값은 의도한 새 색상으로 갱신했다.
