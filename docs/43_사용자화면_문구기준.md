# 사용자 화면 문구 기준

기준일: 2026-10-22. 자연스러운 설명과 구어체는 유지하고, 기술적이거나 공식 서비스 화면에 부적절한 용어만 정비한다. 앞선 전면 격식체 변경은 되돌렸다.

## 유지하는 표현

- 친근하게·정중하게·간결하게, 짧고 쉽게, 함께 알아보기 등 이용자가 이해하기 쉬운 표현
- 설명과 오류 안내의 ‘해요·해 주세요’ 문체
- 초급·중급·고급의 설명 난도와 사용자가 선택한 설명 스타일
- 공식 인용문, 사전 뜻풀이, 학습자 입력과 저장된 대화

## 정비하는 표현

- 말투 바꾸기 → 설명 스타일
- 선호하는 말투 → 설명 문체
- 기본 자료 비교 → 예제 자료로 비교
- 세션·캐시·XML 등 내부 용어 → 현재 브라우저의 기록·검색어 추천 정보·세계유산 목록 등 상황에 맞는 안내
- AI 계획 사용 불가 같은 내부 처리 안내 → 맞춤 응답 연결 상태와 이용 가능한 기본 안내

기술 용어를 줄이더라도 개인정보 처리 대상·외부 전송·공유 범위·삭제 시 복구 불가·자료 및 AI 검토의 한계는 유지한다. 기관명과 라이선스 명칭은 임의로 바꾸지 않는다.

## 적용 범위와 검증

홈, 대화 학습, 음성 입력·설명 설정, 관심사·학습 목표, 검색·상세·비교, 퀴즈·복습, 코스·학습 기록, 자료·기록 안내를 점검한다. 설치·업데이트·연결 중단 안내는 기존 자연스러운 문구로 복원했다.

주요 화면에서 이전의 부적절한 설정명과 내부 용어가 노출되지 않는지, 친근한 설명과 선택지가 유지되는지 확인한다. 인용·사전·학습자 입력과 저장 기록 비변경은 별도로 검사한다. 실제 Gemini 호출과 실제 휴대전화 검증은 이번 작업에 포함하지 않는다.

2026-10-23 최종 자동 검증: Python 3.13에서 662개, Python 3.12에서 662개 모두 통과했다.
