# 학습 흐름 중심 UI 후속 정리

- 홈의 큰 시작 카드 세 장과 중복 시작 버튼을 제거하고 소개 바로 아래 질문 입력을 배치했다. 코스·직접 검색·음성·이전 대화·설정 기능은 유지한다.
- 긴 검색 범위 설명은 펼쳐보기로 정리했다. 해외 검색의 지원 범위 한계는 안내에서 유지한다.
- 비교 화면에 현재 학습 단계와 짧은 행동 안내를 표시한다. 유효한 구조 근거에 지원되는 모양이 있을 때만 기존 학습 도식을 함께 보여준다. 실제 유산 복원도로 표시하지 않는다.
- 퀴즈는 답을 고른 문항 수를 표시한다. 답 변경 시 중복 계산하지 않고 채점 방식과 문항은 변경하지 않는다.
- 후속 UI 검사 27개와 비교·설명 관련 검사 45개 통과. 2026-11-04에 `.venv313` 환경에서 `scripts/check.ps1`을 실행해 코드 규칙·서식 검사와 전체 기능 테스트 836개가 통과했다(279.91초). 실제 Gemini 호출 없이 검사했다.
- 2026-11-04 로컬 서버 8081 포트와 홈 HTTP 200 응답을 확인했다. 이 확인은 실제 기기·학습자 사용성 검증을 대신하지 않는다. 수정본은 로컬에 있으며 이번 작업에서 GitHub에 업로드하지 않았다.
- 70번 기록의 큰 그림 카드 구성은 이번 단순화로 대체되었다. 전시관 삽화와 코스별 그림은 유지된다.
- 실제 사진 추가 및 어린이 대상 사용성 조사는 완료하지 않았다. 이 수정만으로 상용 서비스 수준이 검증됐다고 주장하지 않는다.
