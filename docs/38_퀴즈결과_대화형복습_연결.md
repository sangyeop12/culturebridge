# 퀴즈에서 대화 복습으로

기준일: 2026-10-21. 담당자: 김상엽.

## 연결 흐름

기존 퀴즈 채점 직후와 ‘나의 학습’에 ‘대화로 다시 익히기’를 추가했다.
키오스크 체험에는 새 이동을 넣지 않아 기존 초기화·기록 분리 흐름을 유지한다.
GET이나 새로고침으로 대화를 생성하지 않으며 버튼 선택 시에만 생성한다.
`POST /api/learning/reviews/{history_id}/conversation`에서 같은 채점 기록은 같은 대화를
다시 열어 중복 생성을 막는다. 중단한 대화도 그대로 열어 재개할 수 있다.
대화 한도인 200회에 도달했으면 이전 대화는 보존하고 새 복습 대화를 만든다.

로컬 공유 기록 표시 설정과 관계없이 가져오기에는 항상 `learning_reviews.owner`의
익명 소유 세션을 검사한다. 남의 기록에는 버튼을 제공하지 않고 API도 404로 거절한다.
대화 생성과 링크 저장은 하나의 트랜잭션이다. 데이터는 `learning_review_links`와
대화의 `quiz_review`에 보관한다. 점수·오답만으로 개념 프로필을 갱신하지 않는다.
예전 공유 기록의 소유자를 현재 사용자라고 임의로 바꾸지 않는다. 해당 기록의 기존
해설·퀴즈 다시 풀기는 유지하고, 새로 채점한 자신의 기록으로 복습할 수 있게 안내한다.

## 근거와 확인 질문

문항의 인용·출처 URL을 저장된 채점 결과의 추출 근거와 정확히 대조한다.
개념·대상이 모호하거나 근거 부족 상태, 700자를 넘는 인용은 자동 평가 연결에서 제외한다.
해설을 볼 수 있는 길은 유지한다. 근거가 연결된 문항은 원문을 인용하고 왜 그렇게
생각했는지 자기 말로 설명하도록 질문한다. 새로운 외부 자료를 자동 수집하지 않는다.

‘다른 문항 다시 살펴보기’에서 현재 오답 문항을 선택할 수 있다. 선택 동작은 AI를
호출하거나 이해도를 평가하지 않는다. 작성 중인 입력도 지우지 않는다. 대화 중에 답변을
보내면 기존의 출처 일치·확인 질문·사용자 설명 검사를 거쳐 잠정 개념 관찰을 남길 수 있다.
관찰에는 어느 퀴즈 복습 문항에서 나눈 설명인지 기록하며, 확정 숙달 점수로 표시하지 않는다.
후속 확인 질문에도 문항 연결을 유지한다. 매번 단순 정오답을 숙달로 변환하는 기능은 아니다.

계획 입력에는 복습 문항을 별도로 구분해 전달하고 점수만으로 판단하지 않도록 지시한다.
대화를 보낼 때 AI가 문항·답안·근거를 참고할 수 있음을 화면에 알린다.
생성·문항 선택만으로 모델을 호출하지 않는다. AI를 사용할 수 없으면 제한된 설명만 제공하며
자동 이해도 평가를 했다고 표시하지 않는다.

현재 인용은 **채점 당시 저장된 스냅샷**이다. 최신 원문과의 일치·역사적 의미·전문가 검수를
새로 완료한 것으로 간주하지 않는다. 전부 정답인 기록에도 숙달을 확정하지 않는 안내를 제공한다.
문항별 근거가 없는 과거 형식은 기존 해설을 안내한다. 해설이 비어 있다는 이유만으로 ‘모두 정답’이라고
표시하던 기록 화면의 조건도 실제 점수 기준으로 수정했다.

## 변경과 보관

주제 변경이나 기록 정정은 복습 체크포인트·활성 맥락을 분리한다. 원래 대화는 보존한다.
다시 해당 채점 기록으로 복습을 시작하면 새로운 복습 대화를 만든다.
학습 기록이나 대화 삭제 시 연결 행은 FK로 정리한다. 대화 스냅샷과 채점 기록은 각각 기존
보관 기준을 따른다. 기한 정리로 채점 기록만 없어져도 살아 있는 대화 스냅샷을 무조건 삭제하지 않는다.
세션 전체 삭제는 대화·채점 기록·개념 프로필을 함께 정리한다.

## 검증 범위

단위·API 검사는 소유권, 생성 재사용, 근거 누락·모호성, 전부 정답, 문항 전환,
중단·주제 변경, 설명 뒤의 근거 연계 관찰, 삭제, GET의 비생성 동작을 다룬다.
실제 Gemini의 오답 원인 분석·교육 효과·전문가 검토를 대신하지 않는다.
전체 회귀 검사: Python 3.12·3.13 각각 588개 통과. 마지막 보완 뒤 복습 연결 12개도
각 환경에서 다시 통과했다. 정적 검사·공백 검사 통과. 별도 DB와 가짜 채점 자료로
기록 → 대화 복습 → 다른 문항 선택 → 작성 중 입력 유지의 화면 흐름을 확인했다.
사전 키 등록·GitHub 업로드·외부 배포는 이번 작업에서 하지 않았다.
