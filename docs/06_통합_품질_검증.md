## 자동 검증

- `scripts/check.ps1`: Ruff 검사·포맷 검사·pytest. 테스트는 실제 Gemini를 호출하지 않는다.
- 최종 결과: Ruff 통과, 58개 Python 파일 포맷 통과, 테스트 155개 통과(18.47초).
- 무재검색·재검색 성공·계속 부족한 경우·1회 종료·비교 한 번 저장·퀴즈 재사용을 검사한다.
- 없는 인용·다른 유산·유산군 설명·오래된 자료를 제외하고 양쪽 근거가 없는 공통점을 생성하지 않는다.
- 인물 생몰년을 대안탑 건립연대로 채택하지 않는 회귀 테스트를 포함한다.
- 초급 문제는 긴 영문 인용 없이 쉬운 재료 관찰과 근거 읽기를 제공한다. 실제 아동 대상 사용성 실험은 아니다.
- 긴 Agent 처리는 브라우저 연결 후 시작한다. 로딩 페이지가 기본 응답 제한시간 때문에 실패하는 문제를 수정했다.

## 실제 연결 검증

- Gemini를 활성화한 호류지·대안탑/고급/근거 검토 탐구: HTTP 200.
- 1회 재검색 후 `unesco:660`, `unesco:1442`, `xian:dayanta`를 수집했다.
- 실행 기록 9단계, 유효 추출 6/8항목, 공통점 후보 1개, 퀴즈 5문항을 확인했다.
- 대안탑의 시대·재료 2항목은 근거 부족으로 유지했다. 실크로드 전체 설명이나 현장 생몰년으로 채우지 않았다.
- 저장 비교 ID: `202b0bd9-7a0a-4031-9a45-6d4db9ec2daf` (이 기기의 로컬 DB에만 존재).
- 같은 저장본으로 초급·중급·고급 각각 5문항을 생성하고 채점 API의 5/5 및 근거 반환을 확인했다.
- 세 수준 모두 제출 전 API 응답에 정답이 없음을 확인했다.
- 시작·키오스크·비교 목록·탐구 로딩·저장 비교 페이지 HTTP 200. 이는 실제 클릭·시각 배치 검증을 대신하지 않는다.
- 시안시 요청은 프로젝트를 식별하는 정직한 User-Agent를 사용한다. 인증·쿠키·보안 확인 우회는 하지 않는다.

## 제한과 별도 확인 사항

- 추출·공통점·지지/반박은 모두 검토 후보이며, 원문 일치가 역사적 의미의 최종 검증을 뜻하지 않는다.
- 재검색은 미리 등록된 공식 출처 안에서 제한적으로 실행한다. 무제한 검색·범용 연구 Agent는 아니다.
- 자유 목표는 지원 주제 키워드로 구성한다. 어떤 목표든 완전한 생성형 맞춤 수업을 작성하는 기능은 아니다.
- 자동 UI 제어가 현재 브라우저 URL을 안전하게 확인하지 못해 중단됐다. 최종 클릭·모바일 실측·키보드 전체 이동·화면 읽기·전시 기기 터치 검증은 미완료다.
- Python 3.13 실제 실행, 운영 배포, 최종 발표 자료·시연 캡처·리허설은 별도 작업이다.
- API 키와 로컬 DB는 GitHub에 포함하지 않는다. 기존 저장 비교는 당시 스냅샷을 유지한다.
