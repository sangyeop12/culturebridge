# 무료 공개 자료 확보 및 허가 문의 준비

기준일: 2026-10-19. 기존 25개 유산과 모든 학습 기능을 유지한다.

## 실제 확보한 무료 공식 기록

익명 공개 API를 통해 다음 5개 기록을 실제로 받아 로컬 JSON으로 보관했다.
실패 0건, 외부 AI 호출 0건, 허가 문의 발송 0건, 유료 계약·결제 동의 0건이다.
프랑스 두 건은 이전 연결을 다시 조회했고, 영국 세 건은 이번에 추가했다.

| 유산 | 기관·번호 | 자료 범위 | 라이선스 |
|---|---|---|---|
| 몽생미셸 수도원 | 프랑스 문화부 PA00110460 | 수도원·부속 시설의 역사·시기 등 기록 | Licence Ouverte 2.0 |
| 생트샤펠 | 프랑스 문화부 PA00086001 | 파리 건물의 명칭·시기 등 기록 | Licence Ouverte 2.0 |
| 화이트 타워 | Historic England 1260258 | 해당 건물의 공식 등록명·번호 | OGL v3.0 |
| 더럼 대성당 | Historic England 1161023 | 대성당 건물의 공식 등록명·번호 | OGL v3.0 |
| 스톤헨지 | Historic England 1010140 | 스톤헨지·진입로·인접 고분의 지정 기록 | OGL v3.0 |

이는 **기존 원문 5건의 완전한 대체**가 아니다. 특히 영국 자료는 명칭·등록 정보
중심이며 건축 구조·재료·종교적 배경을 모두 설명하지 않는다. 스톤헨지 기록은 인접
유적을 포함하는 더 넓은 범위임을 표시한다. 등록 번호나 지정일을 건립 연대로 쓰지 않는다.
기존 기관 원문의 권한을 이 라이선스로 허용 처리하지 않는다.

출처:

- [프랑스 문화부 데이터셋](https://culture.data.gouv.fr/datasets/5af120e5b595087cfabcde81)
- [Licence Ouverte 2.0](https://www.data.gouv.fr/pages/legal/licences/etalab-2.0)
- [Historic England 공개 데이터 안내](https://historicengland.org.uk/listing/the-list/data-downloads)
- [Historic England 공개 데이터 이용 조건](https://historicengland.org.uk/terms/website-terms-conditions/open-data-hub/)
- [OGL v3.0](https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/)

Historic England 데이터는 항목 ID·발행자 계정·서비스 URL·공개 이용 조건과 OGL 표시를
확인한 뒤, 각 유산의 등록 번호·정확한 명칭·공식 링크가 일치할 때만 표시한다.
기하 도형·사진·로고·다른 웹페이지의 긴 설명은 가져오지 않는다.
기관의 출처 표시와 Ordnance Survey 권리 표시를 포함하고 공식 인증을 암시하지 않는다.

`/sources`에서 다섯 대상의 '다른 공식 기록도 함께 읽기'로 접근한다.
추가 조회에 실패해도 기존 학습 기능은 유지한다.

```powershell
python -m culturebridge.collect_open_records --output outputs/free-records-new.json
```

기존 파일은 덮어쓰지 않는다. 파일의 `records`와 `failures`를 함께 확인해야 한다.

## 무료 허가 문의 준비

원래 25개 원문은 보충 기록만으로 전부 대체되지 않으므로 원문별 네 용도의
허용 범위를 묻는 초안을 14개 기관·권리 정책 단위로 묶었다. 같은 CMN 정책을
사용하는 두 사이트는 하나로 묶으며 유산 누락·중복 없이 25개를 포함한다.

문의 범위는 저장·화면 표시, 한국어 번역·학습용 가공, Gemini API 전송,
수업용 결과 다운로드·재배포다. 비용이 드는 허가·처리·업무는 수락하지 않고
시작하지 말도록 명시했다. 무응답을 허가로 간주하지 않는다.
사진·로고·지도·제3자 자료는 요청 범위에서 제외한다.

학교·수업·신청자 정보가 포함된 실제 초안은 `outputs`의 로컬 파일에만 저장한다.
공개 코드 저장소에는 개인 정보가 담긴 초안과 발신 주소를 포함하지 않는다.
다음 명령은 **초안 생성만** 하며 발송하지 않는다.

```powershell
python -m culturebridge.prepare_permission_requests --school "학교·학과" --course "수업명" --applicant "신청자" --output outputs/requests-new.json
```

## 확인한 문의 경로 예

다음은 공식 페이지에서 확인한 연락 경로이며, 답변이나 허가를 확보한 뜻은 아니다.
일반 문의 창구는 실제 권한 담당 부서로 전달을 요청해야 할 수 있다.

| 기관 | 공식 페이지에서 확인한 경로 | 근거 |
|---|---|---|
| 인도 관광부 | dg-tourism@nic.in | [이용 조건의 허가 신청 안내](https://www.incredibleindia.gov.in/en/terms-of-use) |
| 타지마할 관광부 | info@tajmahal.gov.in | [공식 연락처](https://www.tajmahal.gov.in/disclaimer.aspx) |
| 마디아프라데시주 관광청 | suggestions.mptb@mp.gov.in | [의견·문의 안내](https://www.mptourism.com/disclaimer.php) |
| Historic Environment Scotland | enquiries@hes.scot | [재이용 요청 안내](https://www.historicenvironment.scot/how-to-request-information/historic-environment-scotland-s-statement-of-public-task-october-2024/) |

14개 초안의 수신자는 자동 확정하지 않는다. 발송 시점에 공식 수신처와 발신 계정,
회신 주소를 확인해야 한다. Gmail은 연결 제안만 했고 연결이 확인되지 않았다.
따라서 이번 작업에서 실제 기관에 보낸 메일은 0건이다.
권리자 허가와 대체 자료의 충분성 확인이 남아 있어 WBS 항목은 완료로 바꾸지 않는다.
