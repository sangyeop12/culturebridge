# 검색·접근성·웹 기능 후속 점검

확인 기준: 2026-10-23. 사용자가 요청한 네 작업과 WBS 월별 구분의 반영 기록이다.

## 인물·사건 자료 찾기

신편 한국사의 공개 웹 검색을 연결했다. 계약된 Open API라고 표기하지 않는다.
인물·사건 이름을 80자 이내의 일반 검색어로 제한한다. 제목 검색을 먼저 하고
결과가 없을 때 본문 검색으로 한 번 확장한다. 최대 5개 제목과 고정된 공식
호스트의 원문 링크만 반환한다. 임의 URL·검색 연산자·스크립트는 실행하지 않는다.
시간·응답 크기를 제한하고 연결 실패를 검색 결과 없음과 구분한다.

별도 화면 `/history-search`는 키 없이 사용할 수 있다. 대화 Agent에도
`search_history`를 연결했다. 대화의 실제 Gemini 도구 선택 자체는 이번에 별도
실호출하지 않았으며 선택 후 실행·호출 제한은 회귀 검사로 확인했다.

세종·임진왜란으로 각각 실제 제목 검색 5건과 첫 공식 링크 HTTP 200을 확인했다.
브라우저에서도 임진왜란을 입력하고 Enter로 검색 결과를 확인했다. 제목·링크
조회이며 원문 본문을 수집·AI 요약하거나 전체 역사 학습을 완성한 것은 아니다.
검색 결과의 참고 링크: [국사편찬위원회 한국사데이터베이스](https://db.history.go.kr/).

## 접근성·화면 폭

본문 바로가기의 첫 Tab 초점, Enter로 본문 초점 이동과 눈에 보이는 외곽선을
확인했다. 홈·대화·설정·코스·역사 검색 화면은 320px 설정에서 문서 폭과 스크롤 폭이
305px로 같았다. 스크롤바를 제외한 값이며 가로 넘침을 발견하지 못했다.
640px·1280px에서도 검색 결과를 확인했다. 한 화면의 제목 1단계 표기도 확인했다.

미리보기의 단축키로 실제 브라우저 확대 비율이 바뀌는 것은 확인하지 못했다.
좁은 CSS 화면 검사를 실제 200% 확대 검사로 표현하지 않는다. 실제 확대·화면 읽기
도구·키오스크 사용성은 WBS의 진행 중 항목으로 남긴다.

## PWA·음성

- 검색 조건이 붙은 개인 대화 주소도 네트워크 실패 시 일반 오프라인 안내로 연결한다.
  개인 HTML·API·POST는 캐시하지 않는다. 기존 공개 캐시만 교체한다.
- 설치 창의 거절·실패를 처리하고, 브라우저의 연결 상태와 서버 실행 필요를 구분한다.
- 브라우저 기본 확인 창을 서비스 안의 업데이트 확인 창으로 교체했다.
  실제 브라우저에서 Tab으로 ‘계속 학습하기’ 초점과 Escape 취소를 확인했다.
  명시적으로 적용하기 전에는 대기 중인 업데이트를 활성화하지 않는다.
- 음성 인식 취소 중 중복 중단 오류를 흡수하고, 빈 음성과 길이 초과를 구별한다.
  빈 입력에서 1,000자 음성이 한 글자 계산 때문에 거부되던 경계값을 수정했다.
  입력 수정·늦은 응답·권한 거절 후 재시도 시 기존 입력을 덮어쓰거나 자동 전송하지 않는다.

실제 JS를 Node의 브라우저 테스트 대역에서 실행해 오류·취소·재시도·네트워크·캐시
계약을 검사했다. 실제 음성·권한 재설정·안드로이드 설치·기기 오프라인 통합 검사를
대신하지 않는다. 이전 기본 확인 창이 열린 탭은 사용자가 취소해야 할 수 있다.
