# 해외 개별 유산 25개 확장

현재 상태: 아래 25개 등록 점검 후 성 마거릿 예배당을 추가해 **정상 연결 25개·보류 1개(총 등록 26개)**로 보완했다. 국가는 기존 5개국 그대로다.

## 범위

기존 21개에 아래 4개를 추가했다. 국가를 추가하지 않았다.
일본 9개, 중국 2개, 인도 4개, 프랑스 6개, 영국 4개로 총 25개이다.
기존 목록과 수집·인용 정책은 [21개 확장 기록](19_해외개별유산_21개_확장.md)을 참고한다.

| ID (`official:` 뒤) | 한국어 안내명 | 국가 | 자료 범위 | 공식 자료 |
|---|---|---|---|---|
| humayun-tomb | 후마윤 묘 | 인도 | 묘당 건물·정원 설명 | [인도 관광부](https://www.incredibleindia.gov.in/en/delhi/delhi/humayuns-tomb) |
| agra-fort | 아그라성 | 인도 | 성 전체 | [아그라 지구 정부](https://agra.nic.in/tourist-place/agra-fort/) |
| sanchi-great-stupa | 산치 대탑 | 인도 | 대탑(제1탑) | [마디아프라데시주 관광청](https://www.mptourism.com/destination-sanchi.php) |
| edinburgh-great-hall | 에든버러성 대연회장 | 영국 | 대연회장 건물 | [에든버러성 운영기관](https://www.edinburghcastle.scot/see-and-do/highlights/the-great-hall/) |

## 연결과 범위 제한

- 한국어 안내명·영문명·별칭 검색과 자동완성, 공식 자료 탐구, 유형별 후보 탐색에 기존 공통 경로로 연결했다.
- UNESCO 등재 ID와 개별 대상 ID는 별도로 유지한다. 포함 관계가 같다는 이유로 같은 유산으로 합치지 않는다.
- 산치 페이지에서는 대탑 문단만 선택한다. 제2탑·제3탑과 주변 사찰·박물관 설명은 제외한다.
- 아그라성에서는 성 자체의 재건·재료 문장만 선택한다. 내부 궁전과 타지마할의 설명은 성의 특징으로 사용하지 않는다.
- 대연회장에서는 건물 설명만 선택하고 왕의 사망 연대가 있는 별도 문단은 제외한다.
- 공식 영문을 임의로 공식 한국어 번역으로 표시하지 않는다. 한국어 이름은 학습용 안내명이다.
- 자료 수집과 역사적 의미 검증은 다르다. 실제 학습 목표에 필요한 양쪽 근거가 부족하면 비교를 보류한다.

## 실제 연결 점검

2026-10-16 별도 진단 DB에서 Gemini 없이 25개를 모두 재조회했다.

- 24개: 원문 새 수집 및 유효 근거 항목 2개 이상 확인.
- 호류지 오층탑 1개: 기존 ConnectError로 수집 보류. 인증서 검증을 끄지 않았으며 정상 연결로 계산하지 않는다.
- 신규 4개 유효 항목: 후마윤 묘(구조·재료), 아그라성(시대·구조·재료), 산치 대탑(구조·재료·종교적 배경), 대연회장(시대·구조·재료).
- 모든 조합의 추천 성공이나 실제 Gemini 응답의 교육 품질까지 확인했다는 의미는 아니다.
- 실제 사용 DB·학습 기록·제출한 WBS는 변경하지 않았다.

## 통합 점검

별도 진단 DB에서 실제 국가유산청 다보탑과 산치 대탑의 수집 원문으로
초급 비교를 실행해 비교 저장과 근거 퀴즈 5문항 생성을 확인했다.
분석 상태는 `needs_review`이며 인용 연결만으로 의미 검증이 끝났다고 표시하지 않는다.
Gemini를 끈 경로의 확인이며 실제 모델 응답 검증과 구분한다.
진단 DB와 조사용 원문 파일은 Git 추적에서 제외한다.

Python 3.12·3.13에서 전체 자동 테스트 각각 361개가 통과했다.
등록 수 25개와 기존 5개국의 정확한 집합, 중복 없는 URL, 검색·별칭,
개별 대상과 유산군 구분, 주변 건물과 인물 연대 제외를 검사한다.
`ruff check src tests`, `ruff format --check src tests`도 통과했다.

## 정상 연결 대상 25개 확보

기존 연결 오류 대상을 성공으로 계산하지 않고, 영국의 [성 마거릿 예배당 공식 소개](https://www.edinburghcastle.scot/see-and-do/highlights/st-margarets-chapel/)를 추가했다.
ID는 `official:st-margarets-chapel`, UNESCO 포함 관계는 `unesco:728`이며 대연회장과는 별도 건물이다.
건물 설명만 발췌하고 왕비의 시성 연도는 제외한다. 별칭·자동완성·탐구·후보 추천은 공통 경로에 연결했다.
실제 수집과 시대·구조의 유효 근거 추출을 확인했다. 등록 수는 일본 9·중국 2·인도 4·프랑스 6·영국 5개다.
호류지의 식별자는 과거 기록의 호환성을 위해 유지하며, 연결 오류를 숨기거나 다른 건물로 바꾸지 않는다.

추가 후 26개를 모두 재조회해 25개 정상 수집·유효 항목 2개 이상, 호류지 1개 연결 보류를 다시 확인했다.
Python 3.12·3.13의 전체 자동 테스트는 각각 363개 통과했으며, 정적 검사와 서식 검사도 통과했다.

## 후속 연결 검증·유형 분류 보완

실제 원문의 제목과 등록 유형을 대조해 대연회장/본당/봉황당/성/묘당/어전 표기의 분류를 보완했다.
영문 복합 이름이 건물 유형으로 끝나면 상위 경내 이름보다 건물 자체를 우선한다.
한국어의 성 명칭은 제목에서만 판별하고 설명의 ‘완성’ 같은 일반 단어는 성곽으로 분류하지 않는다.
정상 연결 25개의 수집 제목·대상 문장 기반 유형이 등록된 핵심 유형과 일치함을 확인했다.
등록 26개 전체에 대해 한글·영문명 대상 식별 회귀 검사를 추가했다.

별도 진단 DB에서 에든버러성 대연회장 → 해외 전각 후보 3곳 탐색 → 도다이지 대불전 선택 →
초급·구조/재료 비교 저장 → 근거 퀴즈 5문항 생성을 확인했다.
Gemini를 끈 경로이며, 분석은 `needs_review`로 유지한다. 역사적 의미 검증 완료를 뜻하지 않는다.

후속 전체 테스트는 Python 3.12·3.13에서 각각 389개 통과했다.
마지막 제목 한정 처리 보완 후에는 개별 자료·대상 판별 관련 75개 테스트를 별도로 재검사했다.
