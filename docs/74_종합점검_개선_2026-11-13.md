# 종합 점검 후 개선

2026년 11월 13일

## 목표 유지와 요청 제어

- 비교 기준은 ‘과·와·이랑·랑·하고·을/를 기준으로’ 등의 표현을 인식한다.
- 재료·구조 같은 항목 이름은 유산 이름으로 등록하지 않는다. 기존 도구 실행 직전의 대상 검사를 유지한다.
- 429·403·504는 재시도하지 않는다. 500·502·503과 연결 시간 초과만 한 번 재시도한다.
- 설명 초안은 최초와 수정 각 한 번으로 제한한다. 대화 계획·개인화 설명·용어 풀이의 SDK 호출 앞에서 중단, 남은 시간, 호출 예산을 확인한다. SDK 호출은 턴당 최대 12회이며 SDK 내부 통신 재시도는 별도로 최대 한 번이다. 비교 도구 내부의 별도 생성기는 기존 자체 제한을 유지한다.
- 실행 중인 통신을 강제로 끊지는 않는다. 진행 중 요청이 끝난 뒤 다음 모델 요청 전에 중단을 확인한다. 첫 질문에도 중단 버튼을 제공한다.

## 학생에게 보이는 설명

- 일반 용어 풀이, 공식 근거를 바탕으로 풀어 쓴 설명, 사전 원문, 기본 도움말을 구분한다.
- 설명의 성격은 펼쳐보는 안내로 제공하며 공급자 이름이나 내부 검증 실패 문구를 본문 머리말로 표시하지 않는다.
- 대기 표시와 오류 안내를 분리해 실패 안내가 사라지지 않도록 한다.
- 이전 기록의 원문은 보존한다. 한국어 읽기 도움말은 전체 번역이라고 표시하지 않으며 외국어 원문·답안은 펼쳐 확인할 수 있다.

## 학습 흐름과 화면

- 문화유산 찾기와 새 비교 링크는 통합 자료 검색으로 연결한다.
- 새 자료 학습과 코스에 사용할 기본 수준을 설정할 수 있다. 화면의 명시적 선택과 저장된 기록의 수준은 바꾸지 않는다.
- 내 학습 기록과 공유 기록을 별도 보기로 분리한다. 공개 모드의 소유권 제한은 그대로 유지한다.
- 빈 대화는 목록에서 숨기되 삭제하지 않는다. 제목은 대화 저장 시 고정해 최근 40개 메시지 제한 후에도 유지한다.
- 대화 목록에 짧은 미리보기를 제공하고, 모바일에서도 주요 메뉴를 먼저 배치한다. 본문과 목록의 글자 가독성을 높인다.
- 초급 재료 퀴즈의 마지막 문항은 단순 재료 연결의 반복 대신, 재료만으로 만드는 방법까지 단정할 수 있는지 확인하는 적용 문제로 구성한다.

## 확인 범위와 남는 한계

자동 회귀 검사와 브라우저 확인 결과는 작업 완료 시 별도로 기록한다. 자동 검사에서 실제 Gemini 요청은 하지 않는다. 실제 학생의 교육 효과나 전문가 승인을 의미하지 않는다.

실제 휴대전화 음성·설치와 200% 확대는 별도 확인 항목이다.

일반 대화와 용어 풀이의 로컬 모델은 `gemini-3.1-flash-lite`로 설정돼 있다. `.env`와 API 키는 Git에 포함하지 않는다.

## 11월 16일 마무리 확인

- 이어지는 항목 변경에서도 기준 유산을 유지한다. ‘시대는 빼고 구조와 재료를 비교’는 시대를 제외하며, 같은 유산에서 이미 요청한 퀴즈는 명시적으로 취소하기 전까지 유지한다.
- 11월 13일 전체 검사 918개 통과를 확인했다. 11월 16일 항목 변경 회귀 검사 추가 후 전체 검사 919개가 통과했다(310.90초). 사진 추가는 이 전체 검사의 시작 후 진행했으므로, 사진을 포함한 최종 관련 검사 50개를 별도로 실행해 모두 통과했다. 두 숫자는 중복을 포함하며 합산하지 않는다.
- 브라우저에서 모바일 주요 메뉴 위치, 대화 미리보기, 일반 용어 풀이의 안내, 개인·공유 기록 분리, 기본 수준 설정, 코스의 검색 이동을 확인했다. 개인 설정·기록을 변경하거나 실제 AI 요청을 보내지 않았다.
- 다보탑과 도지 오층탑의 실제 사진 두 장을 대표 탑 코스와 관련 비교 화면에 추가했다. 파일별 출처·촬영자·촬영연도·이용 조건·해시를 [사진 출처 기록](../src/culturebridge/data/photos/README.md)에 남겼다. 사진은 서버에서 제공하며 외부 이미지 서버에 학습자의 접속 정보를 보내지 않는다.
- 다보탑은 CC0, 도지 사진은 저작권자의 퍼블릭 도메인 공개 선언을 파일 설명에서 확인했다. 사진 자체의 조건만 적용하며 다른 기관 자료의 AI·번역 권한으로 확대하지 않는다. 사진은 AI 입력이나 건립 연도·재료의 검증 근거로 사용하지 않는다.
- 실제 사진 확인 후 관련 검사 50개 통과. 다른 코스의 기존 창작 삽화와 공식 출처 링크도 유지한다.
- 최종 Ruff 검사와 282개 Python 파일의 서식 검사 통과. `git diff --check`에서 공백 오류 없음. Windows 줄바꿈 변환 안내는 오류로 계산하지 않았다. 실제 Gemini 응답이나 실제 학생의 교육 효과를 확인한 결과는 아니다.
- 수정은 현재 로컬 작업본과 8081 서버에 적용했다. 이 작업에서 GitHub 업로드, 키 변경, WBS 변경, 사용자 기록 삭제는 하지 않았다.
