# 개인·수업용 이용 조건과 기능 유지 보완

기준일: 2026-10-19.

## 작업 범위

상용 서비스가 아닌 비상업 개인·수업 프로젝트와 팀원·교수님 시연을 검토 맥락으로
추가했다. 기존 검색·해외/국내 추천·비교·수준별 설명·질문·퀴즈·복습·학습 코스·
기록·내보내기 기능과 25개 대상은 제거하지 않았다. 국가나 유산 수를 임의로 바꾸지 않았다.
기존 저장본·원문·성적과 권한 DB를 승인 또는 삭제로 일괄 변경하지 않았다.

## 구현

1. 25개 검토표에 네 가지 목적별 수업용 판단을 추가했다.
   - 서버 저장·화면 표시
   - 한국어 번역·쉬운 설명 가공
   - 외부 AI 전송
   - 학습 결과 다운로드·재배포
2. CMN의 교육 목적 예외는 별도로 표시하고, 예외를 번역·외부 AI 전송의 일괄
   허가로 바꾸지 않았다. 허가 조건과 적용 미확정을 구분한다.
3. 검토표 JSON·다운로드 문서와 `/sources`의 펼쳐보기에서 확인할 수 있다.
   상태 문구도 '검토 전' 대신 '이용 허용 범위 확인 중'으로 고쳤다.
4. 로컬 관리자 권한 기록 함수에 저장·표시 목적을 별도로 추가했다. 다른 목적의
   승인으로 AI·번역을 허용하지 않는다. 실제 자료의 승인을 새로 입력하지 않았다.
5. 같은 나라·같은 대상의 추가 공식 공개 기록 두 개를 연결했다.

## 추가한 공식 공개 기록

프랑스 문화부의 데이터셋
[Immeubles protégés au titre des Monuments Historiques](https://culture.data.gouv.fr/datasets/5af120e5b595087cfabcde81)를 사용한다.
데이터셋 메타데이터의 라이선스 `lov2`, 문화부 발행자 ID, 리소스 ID를 실제 요청마다
검증한다. 다른 사이트의 안내문이나 기관 홈페이지만 보고 라이선스를 추정하지 않는다.

| 대상 | 공식 기록 | 연결 화면 | 실제 조회 |
|---|---|---|---|
| 몽생미셸 수도원과 부속 시설 | [PA00110460](https://pop.culture.gouv.fr/notice/merimee/PA00110460) | `/sources/open/mont-saint-michel-abbey` | 성공 |
| 파리 생트샤펠 건물 | [PA00086001](https://pop.culture.gouv.fr/notice/merimee/PA00086001) | `/sources/open/sainte-chapelle` | 성공 |

[Licence Ouverte 2.0](https://www.data.gouv.fr/pages/legal/licences/etalab-2.0)는 출처와
데이터 최종 수정일 표시 등을 조건으로 복제·변형·재배포를 허용한다.
해당 데이터셋 텍스트만 사용하며 사진·로고·외부 문서를 끌어오지 않는다.
원문의 마지막 수정일 2026-03-04와 발행 기관을 함께 표시한다.
한국어 항목명·세기 읽기 도움말을 공식 번역 또는 기관 인증으로 표시하지 않는다.

제목·지역·참조번호가 모두 일치해야 연결한다. 파리의 생트샤펠과 다른 도시의 동명
예배당을 혼동하지 않는다. 세기 목록을 단일 건립 연도나 연속 공사 기간으로 변환하지
않는다. 새 데이터셋의 라이선스가 변경되거나 대상이 불일치하면 추가 조회만 실패로
안내하고 기존 학습 기능은 유지한다. 외부 AI 호출·실제 학습 DB 변경은 없다.

이 추가 기록은 기존 근거의 자동 대체물이 아니다. 특히 생트샤펠 공개 기록은
시기·명칭 중심으로 내용이 짧아 기존 설명·비교·퀴즈 전체를 대신할 수 없다.
기존 출처와 보충 자료를 나란히 유지한다.

## 아직 완료로 바꿀 수 없는 범위

- 원래 25개 출처의 이용 권한이 모두 확보되었다는 뜻이 아니다.
- 교육 예외가 명시된 기관도 개별 사이트와 실제 이용 방식의 적용 확인은 남아 있다.
- 기존 기관 원문을 새 데이터셋의 라이선스로 승인하지 않았다.
- 추가 기록을 모든 비교·추천·퀴즈의 대체 근거로 자동 사용하는 연결은 하지 않았다.
- 영국 Historic England 등 다른 공식 개별 기록도 조사했지만, 해당 본문·대상의
  라이선스와 서비스 연결을 확정하지 않아 이번 연결 수에 포함하지 않았다.
- 외부 기관 문의·이메일 발송, 권리자 명의의 허가, 공개 배포·GitHub 업로드는 하지 않았다.

따라서 WBS 14행은 진행 중이다. 기능을 유지하면서 허용 출처의 충분한 개별 근거를
더 확보하거나 실제 허가를 받아야 전체 조치 완료로 정리할 수 있다.

## 검증

추가 검사는 네 목적 분리, 25개 대상 유지, 교육 예외의 범위, 유사 도메인 불신,
정확한 참조번호·제목·지역·수정일 확인, 라이선스·발행자 변경 실패 처리,
응답 크기 제한, 네트워크 실패 시 기존 기능 유지 안내를 포함한다.
몽생미셸·생트샤펠 두 기록은 구현한 연결 함수를 이용한 실제 조회도 성공했다.
실제 Gemini 전송이나 권한 미확인 원문의 추가 AI 처리는 수행하지 않았다.

- Python 3.13 전체 회귀: 492개 통과(138.99초).
- Python 3.12 전체 회귀: 492개 통과(143.42초).
- 변경 파일 Ruff 검사 통과.
- 실행 서버 `/api/material-review`: 25개 모두 네 목적과 수업용 맥락을 포함함을 확인.
- `/sources`와 두 추가 기록 화면 HTTP 200. 생트샤펠 화면에서 공식 참조번호,
  라이선스 링크, 데이터 최종 수정일 표시를 확인했다.
- 실제 휴대전화·키보드·화면 확대를 통한 사용자 검증을 대신하는 결과는 아니다.
