# 범용 대상·탐색·학습 품질 보완

확인일: 2026-10-14

## 적용 범위

1. 대상 문장: 사찰·궁궐·고분·석굴·전각·문 등으로 명시적 주어 선별 확장. 특정 다보탑 주변 이름 제거. 구성 건물·소장품 목록·인물 사망일 제외. 원문과 인용은 변경하지 않는다.
2. 유형: 층수만으로 탑이라 판단하지 않는다. 한국어 구성 대상의 마지막 이름을 우선한다. 석탑/목탑과 2개 이상의 구성 요소 표현을 선별한다.
3. 탐색: 상위 3개 탈락 후 뒤의 후보도 확인한다. 한 라운드 원문 최대 8개, 검색어 변경·다음 페이지 1회, 총 후보 최대 16개. 선정 모델이 실패해도 실제 공식 후보만 사용한다.
4. 목표: 양쪽에 공통 근거 2항목 이상 필요. 관찰 목표는 구조·재료, 종교 목표는 종교, 자유 목표의 명시 항목도 필요하다. 동적 퀴즈 생성 시 재검사한다.
5. 학습: 재건/공통점/차이점/교류 목표에 맞는 활동을 추가한다. 규칙 퀴즈는 확보한 내용의 최대 3문항과 근거 판단 문항을 결합한다. 오답 문항별 정답·원문 복습을 제공한다.
6. 한국어: 기본 안내명을 확대하고 ID·공식 영문명에 묶인 로컬 이름/별칭 레지스트리를 추가한다. 안내명·AI 후보·검토 이름 상태를 구분한다. 미등록 한국어 검색은 설정된 Gemini로 영어 검색어 후보를 만들고 실제 공식 목록에서만 찾는다.

## 추가 수집과 문맥 검사

UNESCO 공식 상세 페이지의 `Brief synthesis` 영문 설명 범위를 제한해 추가 수집한다.
등록 ID에서 고정 WHC URL을 구성하며 사용자/모델 URL을 직접 열지 않는다.
페이지 대상명·설명 범위를 확인하지 못하면 실패 처리한다. 유산군 설명은 개별 대상의 근거로 사용하지 않는다.
같은 UNESCO의 자료 보완이지 독립 기관의 교차 검증은 아니다.

이 환경의 직접 상세 페이지 요청은 403이다. 접근 제한을 우회하지 않으며 실패를 캐시해 반복 요청을 막는다.
성공 수집·본문 범위는 모의 HTTP 테스트로 검사한다. 실제 성공 수집은 확인되지 않았다.
기존 DataHub/API 경로는 유지한다.

공통점은 부정·추정·모방 표현을 먼저 제외한다. AI 사용 시 이미 인용이 연결된 후보 쌍만 문맥을 검토한다.
없는 인덱스·중복/누락 판단은 거부하며 새로운 출처/인용을 생성하지 않는다.
문맥 검토 결과도 `needs_review`이고 독립 사실 검증은 아니다.

## 검증

한국어/영어 대상·주변 건물 구분, 소장 석탑의 재료 오적용 방지, 왕의 사망일 제외,
건립/재건 구분, 소규모 유산군, 4번째 후보 선택, 검색어 변경 1회, 목표 근거 검사,
이름 상태·별칭 검색·자동완성·번역 실패 캐시, 유산 내용 퀴즈·오답 복습,
공통점 문맥 검토 및 명칭 가져오기 입력 검사를 회귀 테스트한다.

국가유산청 실제 검색으로 경복궁·합천 해인사·경주 무열왕릉의 개별 원문을 확인했다.
처음 5건의 검색 결과에는 본 유산 대신 구성 건물·유물이 나타날 수 있어, 본 유산명을 확인한 뒤 점검했다.
천마총 검색에서는 유물 이름을 고분 자체로 대신 사용하지 않았다.

Python 3.13.15: 233개 통과(58.16초), Python 3.12.14: 233개 통과(59.20초).
두 환경 모두 Ruff/포맷 검사 통과. 자동 검사에서는 실제 Gemini 호출을 하지 않았다.
마지막 유형 주제 연결 보완 후 Python 3.13 관련 회귀 테스트 50개도 통과(13.54초).

## 남아 있는 한계

- 명시적 주어/표현 규칙은 완전한 한국어 의미 분석이 아니며, 임의 유산에서 추가 예외가 있을 수 있다.
- 자동 커리큘럼은 여전히 공식 자료의 네 항목 안에서 목표·활동을 조정한다. 제한 없는 임의 주제 생성은 아니다.
- 근거가 짧거나 부족하면 내용 문항 수를 줄이고 근거 읽기 문항으로 보완하거나 퀴즈를 보류한다.
- 모든 해외 문화유산을 수록하지 않으며 UNESCO 등재 범위를 유지한다. AI 번역은 공식 한국어 명칭이 아니다.
- 실제 Gemini 성공 경로는 사용량 제한 해제 후 검증 필요. 모의 성공을 실제 호출 성공으로 보고하지 않는다.
- 실제 브라우저 클릭·모바일 시각·교육자 검토는 이번 자동 검사와 별도다.
- 기존 저장본·로컬 DB·API 키를 삭제하거나 GitHub에 올리지 않는다.
