# 학습 화면·콘텐츠 품질 개선

작업일: 2026-10-18. 10월 17일의 종합 점검과 '정확한 저장·조회 시각은 일반 사용자에게 불필요하다'는 요청을 반영한다.

## 구현 변경

- 일반 화면에서 원문 수집·조회 시각, 저장본 구성 버전, 내부 연결 오류 코드를 제거했다. 학습 기록·학습지는 한국 시간 기준의 간단한 학습 날짜만 표시한다. JSON의 관리용 메타데이터와 내부 로그는 보존한다.
- 홈 소개 영역을 줄이고 설정을 접어 검색 진입을 단축했다. 해외 개별 자료 결과를 부분 일치 국내 검색 결과보다 먼저 배치한다.
- 같은 기준인지 모호한 봉분·평면·탑신의 모양은 차이로 단정하지 않는다. 사건 미확인은 서로 다른 사건의 증거로 처리하지 않는다.
- 다보탑의 십자·팔각·네모 표현을 보존한다. 설명에 근거한 단순 도식을 제공하며 실제 비율·복원도가 아님을 명시한다. 기관 사진을 새로 가져오거나 이용 승인을 가정하지 않았다.
- 혼합 부정 문장은 절 단위로 제한적으로 처리한다. 긍정 절에 실제로 있는 돌과 부정 절의 설치되지 않은 둘레돌을 함께 부정하지 않는다. 복잡한 부정의 의미를 모두 해결한 것은 아니다.
- 코스·추천의 항목 검사에 읽을 수 있는 특징을 반영하고, 후보 검사 시 상위 세 건에서 바로 멈추지 않도록 했다. 3개 후보 표시 한도는 유지한다.
- 질문의 기본 답변을 한국어 읽기 도움말로 정리하고 같은 원문 반복을 없앴다. 영어 원문과 인용 검증은 별도로 유지한다.
- 퀴즈의 모양 질문에 부분을 붙이고 둥근 아치가 있는 원문에서 '둥근 모양'을 모순된 오답으로 쓰지 않는다. 좌우 기억 대신 유산명을 사용한다. 수준별 질문 표현과 고급 해석 문항을 구분한다.
- 정답 위치를 무작위·균형 배치하고 같은 퀴즈 재개 시에는 저장된 순서를 사용한다. 생성 진단은 학습 목표에서 분리해 내부 메타데이터로 보존한다.
- 선택한 오답과 정답에 맞는 보충 질문을 표시한다. 독립적인 적응형 재시험 엔진 전체를 새로 구현한 것은 아니다.
- 비교 기록 관리·다시 탐구·내보내기 형식을 접힌 영역으로 옮겼다. 비교 화면의 보조 버튼을 구분하고 공식 유산의 추천 복귀 경로에서 불필요한 중간 페이지를 줄였다.
- 모든 한국 공식 상세에 비교 후보 진입 버튼을 추가했다. 홈의 '더 찾기'는 학습 설정을 보존한 범위별 검색으로 연결한다.
- '나의 학습'에서 양쪽 유산명을 함께 표시한다. 최근 20건 이후 페이지와 수준 필터를 추가하고 오답 설명을 접었다.
- 공유 모드의 기록 읽기와 소유자 전용 내보내기의 차이를 안내하고, 소유자가 아닌 기록에는 내보내기 버튼을 노출하지 않는다.
- 코스 활동·성찰 질문을 비교 화면에 연결하고, '내가 정리한 배움'을 소유자별 저장·수정·내보내기한다. 원문·퀴즈 전문 재배포 제한은 유지한다.
- 제목 접근성 역할, 본문 바로가기, 미응답 문항 포커스와 채점 결과 이동을 보완한다. 실제 모바일 화면과 스크린리더의 완전한 검증을 대신하지 않는다.

## 자료 처리 권한

기관의 원문 소개 페이지와 정책 링크를 분리했다. 기존 검토표는 승인으로 승격하지 않는다. 알려진 해외 개별 자료는 **외부 AI 처리에 대한 별도 확인 기록이 없으면 외부 전송을 하지 않고 기본 읽기 기능을 사용**한다. 한국어 AI 풀이에는 번역과 AI 처리 확인이 모두 필요하다. 기존 저장본도 이 검사를 거친다.

관리자는 실제 허가 문서나 해당 이용 목적의 정책을 확인한 뒤 로컬 명령으로 기록할 수 있다. 승인 근거 없이 실행해서는 안 된다.

```powershell
python -m culturebridge.manage_sources permission <등록ID> --purpose ai --status approved --note "실제로 확인한 문서·이용 범위"
```

`translation`과 `redistribution`은 별도 목적이다. `reviewed`는 검토 기록이지 이용 허가가 아니다. 관리자가 `restricted`로 표시하면 기존 승인보다 제한을 우선한다. 이 작업에서 실제 기관 허가를 받은 자료는 없다. 원문 열람·인용·저장의 적법성이나 재배포 허가까지 자동으로 판단한 것이 아니다.

## 기존 기록과 확인 범위

학습 구성 버전을 5로 올렸다. 기존 결과는 덮어쓰지 않으며 이전 방식의 결과에는 다시 탐구 안내를 제공한다. DB에는 메모·퀴즈 진단용 테이블을 추가한다. 메모는 비교 삭제 시 함께 삭제되고 퀴즈 진단은 퀴즈 삭제 시 정리한다.

외부 AI 없이 5코스×3수준의 15개 모의 경로에서 문항 수·서로 다른 문항·정답/오답 채점·복습·학습지·원문 보존을 확인했다. 실제 학습 효과, 역사 해석의 최종 승인, 전체 해외 유산의 한국어 검수, 이용 권한 승인은 완료로 간주하지 않는다.

별도 점검 DB에서 정리 저장 후 새로고침을 해도 내용이 유지되는 것을 브라우저로 확인했다. 실제 사용자 DB에는 모의 학습 답안이나 점수를 넣지 않았다. GitHub 업로드는 수행하지 않는다.

검증: Python 3.13 전체 445개 통과(158.27초), Python 3.12 전체 445개 통과(156.33초), Ruff 통과.
이는 외부 Gemini 실제 응답과 인간 학습자의 이해도를 보증하지 않는다. 정상 서비스 DB는 변경 적용 전 `backups/culturebridge-before-learner-polish-20261018.db`로 비덮어쓰기 백업하고 무결성을 확인했다.
