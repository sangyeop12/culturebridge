# 실제 호출·응답 근거 측정 결과

점검일: 2026-10-25, 한국 시간. 실제 Gemini와 공식 자료를 사용했고 운영 학습 기록과
분리된 DB에 저장했다. API 한도·키·모델·과금 설정은 변경하지 않았다.

## 이번 실제 실행

국내 유산 설명·해외 비교·역사 자료 검색을 각각 2회씩 수행하도록 6개 실행을 계획했다.
첫 설명 흐름에서 모델이 국가유산청 검색 → 개별 원문 읽기 → 재료 설명 행동을 선택했다.
이후 설명 문장 생성 호출에서 일일 무료 요청 한도 초과 429가 반환됐다.
서비스는 원문 근거의 기본 풀이와 확인 질문을 제공했고, 점검기는 추가 호출을 중단했다.
후속 턴과 나머지 5개 실행은 진행하지 못했다.

| 실제 관찰 | 결과 |
|---|---|
| SDK 요청 | 4회: 계획 응답 3회, 설명 생성 한도 초과 1회 |
| 사용자 턴 처리 시간 | 10.36초, 표본 1개 |
| 선택 대상·항목 | 경주 불국사 다보탑·재료 |
| 실제 자료 작업 | 국가유산청 검색·개별 원문 읽기 성공 |
| 설명 방식 | 새 AI 문장 생성은 실패, 근거 기반 기본 풀이 제공 |
| 원문과 연결된 확인 질문 | 제공됨, 실제 학습자의 답변·평가는 없음 |
| 비교 → 퀴즈 → 복습 연속 성공 | 미확인 |

3/4는 **SDK 응답 성공 비율**이지 사용자 과제 성공률이 아니다.
턴 하나의 시간으로 서비스 응답 속도의 평균·p95를 일반화하지 않는다.
이번 원시 기록에는 설명 과제의 완주 기준이 등록돼 있지 않아 과제 성공률을 소급 산정하지 않았다.
이후 실행을 위해 설명의 기준 대상·개념·최소 턴 수·확인 질문 조건을 사전에 등록하도록 보완했다.

## 토큰·비용

성공한 3회 응답에서 수집한 사용량은 다음과 같다.

- 입력 7,609토큰. 이 중 공급자가 보고한 캐시 입력 640토큰 포함.
- 출력 293토큰. 별도 사고 토큰은 보고되지 않았고 이번 계획 호출은 사고 예산을 0으로 지정했다.
- 실패한 요청에는 사용량 정보가 없어 전체 실행 비용을 확정하지 않는다.

2026-10-25 확인한 [Google 공식 가격표](https://ai.google.dev/gemini-api/docs/pricing)의
Gemini 2.5 Flash Standard 텍스트 유료 단가(입력 $0.30/백만 토큰, 출력 $2.50/백만 토큰)로
성공 요청만 단순 환산하면 **US$0.0030152**다. 캐시 할인·추가 도구 비용·세금은 적용하지 않은
비교용 값이며, 무료 계정의 실제 청구액이나 전체 실행 비용을 의미하지 않는다.
측정기는 전체 비용과 관찰된 요청의 부분 사용량을 구분한다.

## 실제 응답 근거 검토

이번 응답의 사실 문장 1개와 이전 실제 AI 응답의 사실 문장 2개를 검토했다.
인용 부분은 원문과 연결해 확인하되 생성 문장 수로 중복 집계하지 않았다.
각 실행 DB의 원문, 실제 답변에 포함된 문장, 출처 URL과 원문 해시를 연결했다.

| 구분 | 검토한 내용 | 근거 판단 | 질문 직접성 |
|---|---|---|---|
| 이번 기본 풀이 | 석탑이라는 공식 설명을 돌 재료로 풀이 | 원문으로 뒷받침됨 | 재료 질문에 직접 답함 |
| 이전 AI 설명 | 다보탑이 대표적인 석탑이라는 서술 | 원문으로 뒷받침됨 | 재료에 간접 관련, 쉬운 재료 풀이 부족 |
| 이전 AI 설명 | 높이 10.29m와 석가탑과의 유사 높이 | 원문으로 뒷받침됨 | 재료 질문과 무관 |

검토한 3개 문장에서는 근거 없는 사실을 발견하지 않았다. 이는 **AI의 제한된 표본 검토**이며
전체 서비스의 근거 없는 주장 비율이 0%라는 뜻이 아니다. 두 실행은 서로 다른 버전이므로
현재 서비스의 통계로 혼합하지 않았다. 원문에 인용이 있다는 사실만으로 의미 적합성을
자동 승인하지 않으며, 판정과 이유는 검토자의 별도 판단이다.

## 실제 실행에서 발견해 수정한 오류

AI 계획은 성공했지만 설명 생성만 제한될 때 다음 문제가 있었다.

- 내부에는 `provider_rate_limit`이 남지만 화면의 안내는 빈 문자열이었다.
- 원래 요청을 완료한 것처럼 지워 후속 재개 시 누락될 수 있었다.

설명 단계의 부분 실패를 별도 기록하고, 공식 자료의 기본 풀이로 전환됐음을 화면에 표시한다.
원래 요청도 유지한다. 계획 자체를 규칙 기반이라고 바꾸거나 기본 풀이를 AI 생성 설명으로
기록하지 않는다. 동작을 재현한 회귀 검사에서 안내·요청 보존을 확인했다.

## 재현 자료와 도구

원시·검토 결과는 Git에서 제외되는 `outputs/`에 보관한다.

- `agent-measurement-20261025-r3.json` / 같은 이름의 DB: 실제 실행.
- `agent-measurement-20261025-r3-claim-grades.json`: 이번 응답의 문장별 검토.
- `agent-measurement-20261025-r3-reviewed-complete.json`: 원문 대조·부분 사용량·단계 실패 집계.
- `agent-initial-20261024-claim-grades.json`, `agent-initial-20261024-reviewed-final.json`: 이전 응답 검토.

`scripts/review_agent_evidence.py`는 실제 답변 문장, 해당 실행 DB의 인용 위치·원문 해시·출처
연결을 확인한다. 원문에 없는 인용이나 실행에 없는 자료는 거절한다. 의미 판정은 자동으로
추론하지 않고 명시된 검토 결과로 집계한다. API를 재호출하거나 원시 실행 기록을 덮어쓰지 않는다.

현재 확인하지 못한 반복 성공률·비교 목표 이탈률·실패 후 재계획 복구율은 미측정으로 남긴다.
이번 부분 실패 후 기본 풀이 제공과 원래 과제 완주는 서로 다른 결과다.

## 이전 목표 이탈 오류의 수량 확인

`agent-dialogues-recheck-20261024-02.json`의 사용자 요청은 다보탑 비교였다.
같은 이름의 격리 DB에서 실행 관찰에 기록된 저장 ID를 조회해 보니,
대안탑–산치 대탑, 대안탑–도지 오층탑, 대안탑–화이트 타워 비교 3건 모두 다보탑을 빠뜨렸다.
이 결과는 `agent-baseline-goal-drift-audit-20261025.json`에 기록했다.

이는 **방어 보완 전 한 대화 안에서 발생한 3건의 비교 결과**다. 독립된 요청 3회가 아니며,
현재 버전의 목표 이탈률로 사용하지 않는다. 현재 코드의 차단 검사는 통과했지만 실제 모델로
같은 요청을 반복했을 때의 성공률은 별도 검증이 필요하다.

## 추가 보호·검증

- 이해도 평가가 429를 반환하면 같은 턴에서 계획 모델을 추가 호출하지 않도록 했다.
- 실패한 설명 생성 후 기본 풀이 제공은 별도 단계 결과로 집계한다. 전체 과제 복구와 구분한다.
- 설명과 비교 등 여러 완료 조건을 가진 요청은 한 실행으로 집계하며 모든 조건을 확인한다.
- Python 3.13 전체 회귀 검사 764개 통과. 이후 보완을 포함한 관련 검사 45개도 통과했다.
- Python 3.12 관련 검사 45개 통과. 변경 코드 Ruff 검사·서식 검사 통과.
- 실제 API를 추가로 재호출하지 않고 실패 안내·요청 보존·후속 호출 차단을 재현 검사했다.
- 수정은 로컬에 반영했으며 이번 작업에서 GitHub 업로드는 하지 않았다.
