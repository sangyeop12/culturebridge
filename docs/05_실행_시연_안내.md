# 6. 수행 계획 및 시연 안내

□ 6.1 수업 전 실행 준비

- 프로젝트 폴더에서 PowerShell을 열고 다음 명령을 실행한다.
- 기존 서버가 8080 포트를 사용 중이면 해당 서버를 그대로 사용하거나 `-Port 8081`로 실행한다.
- 시작 스크립트는 자동 설치·기존 설정 덮어쓰기·브라우저 자동 실행을 하지 않는다.

```powershell
.\scripts\run.ps1 -CheckOnly -Offline
.\scripts\check.ps1
.\scripts\run.ps1 -Offline
```

- 실행 후 웹: http://127.0.0.1:8080/
- 키오스크: http://127.0.0.1:8080/kiosk
- 비교 기록: http://127.0.0.1:8080/comparisons
- API 문서: http://127.0.0.1:8080/docs
- 실행한 터미널을 유지하고 종료할 때 Ctrl+C를 누른다.
- 표준 환경은 Python 3.13.15이다. 3.12.14도 같은 잠금 패키지로 호환 검증했다.
- 이 기기의 별도 3.13 환경: `scripts/run.ps1 -Environment .venv313`, 검사는 `scripts/check.ps1 -Environment .venv313`.
- 초기 설치는 README의 가상환경·패키지 설치 순서를 따른다. 기존 `.env`는 유지한다.
- 기본 실행은 현재 컴퓨터의 루프백 주소에만 바인딩한다.

□ 6.2 5분 시연 순서

① 0:00~0:40 · 검색과 학습 수준 선택

- 웹 시작 화면에서 초급·종교적 배경 목표를 선택하고 `석굴암`을 검색한다.
- 선택 목표에 따른 비교 후보 보기 → 호류지 불교 건축물 → 공식 자료로 Agent 탐구를 선택한다.
- 설명: 하나의 문화유산에서 출발해 비교 대상을 추천한다.

② 0:40~1:30 · 비교와 공식 출처

- 시대·구조·재료·종교적 배경 및 출처 요약을 확인한다.
- 고급 화면은 `/compare/seokguram/horyuji?level=advanced`로 연다.
- 설명: 사실 데이터는 유지하고 수준에 맞춰 관찰·비교·근거 판단 과제를 바꾼다.

③ 1:30~2:30 · 질문과 역사적 주장 검증

- 자유 질문: `두 유산의 재료는 어떻게 다른가요?`
- 주장: `석굴암의 재료는 화강암이다` → 원문 근거와 지지 후보를 확인한다.
- 주장: `석굴암의 재료는 목재이다` → 반박 후보 또는 근거 부족을 확인한다.
- 주장: `호류지가 석굴암에 직접 영향을 주었다` → 근거 부족.
- 설명: 공식 탐구는 저장된 개별 원문과 대조한다. 후보는 최종 참·거짓 판정이 아니며, 영향 관계는 자료 없이 확정하지 않는다.

④ 2:30~3:40 · 학습 확인 퀴즈

- 학습 확인 퀴즈 → 다섯 문항 응답 → 채점하고 해설 보기.
- 설명: 수준별 문항을 제공하고 제출 뒤 정답·해설과 점수를 표시한다.
- 초급·중급·고급 문항은 각각 관찰·비교·근거 판단을 중심으로 구성한다.

⑤ 3:40~4:20 · 저장한 비교 다시 열기

- 웹 시작 화면의 저장된 비교 보기에서 방금 생성한 비교를 다시 연다.
- 설명: 생성 시점의 비교 내용과 출처 메타데이터를 SQLite에 보관한다.
- 재조회는 새 비교 기록을 생성하지 않는다. 질문과 주장은 비교 기록에 포함하지 않는다.

⑥ 4:20~5:00 · 키오스크와 Agent 구성

- `/kiosk`에서 큰 버튼으로 문화유산을 선택하고 처음으로 버튼을 누른다.
- 설명: 5분 미사용 시 시작 화면으로 초기화한다.
- API 문서의 `/api/explorations`로 다음 요청을 실행하면 탐구 흐름도 확인할 수 있다.

```json
{"heritage_id":"seokguram","comparison_id":"horyuji","level":"advanced","goal":"religion","goal_text":"불교 배경과 구조를 비교"}
```

- LangGraph는 커리큘럼 → 추천·수집 → 추출 → 검증 → 필요 시 1회 재검색 → 비교 저장 → 퀴즈 생성 순으로 실행한다.
- 화면의 실행 기록과 재검색 횟수를 확인한다. 퀴즈 화면은 탐구에서 생성된 퀴즈를 재사용한다.
- 공식 출처가 미리 정해진 제한적 조건 분기이며, 무제한 웹 탐색 Agent는 아니다.

□ 6.3 시연 중 설명할 현재 범위

- Gemini 없이 검색·비교·등록 데이터 기반 질문·검증·퀴즈를 실행할 수 있다.
- 공식 수집과 Gemini에는 인터넷이 필요하다. 기본 비교는 로컬 자료로 실행할 수 있다.
- 등록 비교 유산은 3건이다. 대안탑은 재검색 시 시안시 개별 원문을 수집하며 부족한 항목은 보류한다.
- 기기 공용 기록이며 계정별 분리 기능은 없다.
- 주장 검토는 개별 주장별 인용 후보와 원문 일치를 검사한다. 역사 문장 전체의 진위를 최종 확정하는 기능은 아니다.
- 실제 Gemini 추출과 공식 출처 연결은 확인했다. 계정별 모델 권한·과금·지연은 환경에 따라 달라진다.
- 모바일 실측·키보드 전체 이동·화면 읽기 프로그램 확인은 별도 검증이 남아 있다.
