# CultureBridge 발표·시연 대본

작성 기준: 2026-10-23. 발표 준비용 초안이며 실제 발표·최종 제출 완료를 뜻하지 않는다.

## 발표 흐름 (약 7분)

1. 목적 (40초): 문화유산을 읽는 데서 끝내지 않고 서로 비교하고 설명해 보는 학습 서비스다.
2. 화면 (50초): 홈 검색, 비교, 대화, 나의 학습, 설정을 짧게 소개한다.
3. 자료 (50초): 국가유산청·UNESCO와 해외 개별 자료의 역할, 이용 조건별 제한을 설명한다.
4. Agent (70초): 질문에 따라 검색·읽기·재탐색을 선택하고 근거가 없으면 보류하는 과정을 보여준다.
5. 개인화 (50초): 관심 변경과 이유가 부족한 답에 대한 보충 학습을 설명한다.
6. 검증 (60초): 자동 검사와 실제 Gemini 표본 확인을 구분하고 복구 검사 결과를 소개한다.
7. 한계 (40초): 권한 회신·실제 기기·학생 경험·다른 PC 확인을 남은 항목으로 밝힌다.

## 정상 시연 (약 5분)

시연 전 로컬 서버를 실행하고 `/api/health` 응답과 홈 연결을 확인한다.
개인 기록이 없는 체험용 세션을 사용한다. 키·DB·개인 질문을 화면에 노출하지 않는다.

| 순서 | 행동 | 설명할 내용 | 확인할 결과 |
|---|---|---|---|
| 1 | 홈에서 불국사 검색 | 한국어 검색에서 학습 시작 | 자동완성·공식 검색 결과 |
| 2 | 다보탑 상세 열기 | 같은 원문을 수준에 맞춰 읽기 | 초급·중급·고급과 원문·출처 |
| 3 | 해외 비교 시작 | 같은 종류와 학습 목표를 함께 판단 | 실제 추천 결과와 쉬운 이유 |
| 4 | 근거가 있는 후보 선택 | 사실과 분석을 구분 | 비교 기준·양쪽 근거·보류 항목 |
| 5 | 퀴즈에서 한 문제 오답 | 점수만 남기지 않고 복습 연결 | 해설과 관련 학습 내용 |
| 6 | 나의 학습 열기 | 학습 기록과 목표 확인 | 이번 세션의 결과와 복습 |
| 7 | 설정 열기 | 학습 중 조작과 개인 설정 분리 | 설명 방식 설정과 유지 |

비교 후보와 설명은 실제 확보한 자료에 따라 달라질 수 있다. 특정 후보가 항상
선정된다고 약속하지 않는다. 응답이 길어지면 이미 저장한 체험 결과로 전환하고
‘이 화면은 앞서 저장한 결과’라고 명확히 알린다.

## 실제 대화 시연 (호출 여유가 있을 때만)

`/learn`에서 “궁궐 건축에 관심이 있어. 구조를 이해하고 싶어”라고 입력한다.
관심·목표 반영을 확인하고 “궁궐 말고 석탑을 알아보고 싶어”로 변경한다.
자동 추정을 보여주되 매번 정확한 성향을 알아낸다고 설명하지 않는다.
이해 확인 질문에 이유 없이 답한 경우 추가 설명을 요청하는 흐름을 보여준다.

| 상황 | 조치 | 발표 문장 |
|---|---|---|
| Gemini 429·503 | 반복 호출을 중단하고 대체 경로·저장 결과 사용 | AI 응답 실패를 알리고 확보한 근거로 학습을 이어갑니다. |
| 비교 근거 부족 | 원문 읽기·목표 변경·다른 유산 선택 | 확인하지 못한 항목은 판단을 보류합니다. |
| 원문 AI 처리 제한 | 공식 링크와 허용된 읽기 경로 사용 | 연결 여부와 AI 이용 권한을 따로 관리합니다. |
| 사전 키 없음 | 키 미등록 안내 확인 | 사전 실연결은 키 등록 후 별도 확인할 항목입니다. |
| 해외 목록만 있음 | UNESCO 공식 링크 열기 | 목록 정보이며 이 본문으로 비교 분석하지 않습니다. |
| 일반 인물·사건 질문 | 공식 역사 포털 안내 | 현재는 포털 안내까지 지원하며 직접 원문 학습은 남은 범위입니다. |

## 예상 질문

**단순 챗봇과 다른 점은?** 질문에 따라 자료 검색·읽기 도구를 선택하고, 근거가
부족하면 제한된 범위에서 다시 탐색한다. 학습 상태에 따라 설명과 다음 활동을 선택한다.

**자료가 공식이면 AI 답변도 정확한가?** 그렇지는 않다. 인용·의미·대상 범위·추정
표현을 검사하지만 모든 오류를 제거했다고 보장하지 않는다. 원문 확인 경로를 제공한다.

**25개 자료를 모두 자유롭게 번역·재배포할 수 있는가?** 연결과 허가는 별개다.
원문별 조건을 적용하며 미확인 권한은 승인으로 바꾸지 않았다.

**교육 효과는 검증했는가?** 코스·채점·복습 연결은 검사했다. 실제 학생 수업과
학습 효과 측정은 아직 수행하지 않았다.

## 최종 제출 전

팀이 보고서와 발표의 범위·수치를 확인한다. 실제 휴대전화와 다른 PC의 결과를
추가한다. 제출 파일에서 키·개인 기록·미허가 원문을 제외하고 교수 제출은 사용자가 진행한다.
