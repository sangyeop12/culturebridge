# 주제 변경 실제 응답과 용어 풀이 보완

문구 수정·체험 링크 수정·WBS 갱신을 `5f75a82`로 main에 반영한 뒤 실제 AI 검증을 실행했다.
사용자 학습 DB와 분리된 새 DB, 합성 학습자 질문을 사용했다. API 키·모델·과금·한도는
바꾸지 않았다. 429 후 재시도하거나 다른 모델·키로 우회하지 않았다.

## 실제 실행

1. “경주 불국사 다보탑의 구조가 궁금해요. 공식 자료를 찾아 쉽게 설명해 주세요.”
   - AI가 다보탑 검색 → 해당 국가유산청 원문 읽기 → 구조 설명을 선택했다.
   - 원문에 있는 십자형 기단·사방 돌계단·팔각형 탑신·네모난 난간으로 설명했다.
   - 이 답변의 구조 설명과 연결 인용문을 수동 대조했으며 기준 대상의 이탈은 없었다.
   - 13.03초, 공식 인용 1개. 이 한 사례만으로 일반적인 정확성·성공률을 확정하지 않는다.
2. “다보탑 이야기는 그만하고 세종대왕의 한글 창제 자료를 찾아 주세요.”
   - AI가 `search_history`를 선택해 새 주제를 검색했다.
   - 국사편찬위원회 ‘신편 한국사’의 제목·링크를 반환했다. 본문을 AI가 읽거나 요약한
     결과는 아니며, 검색 결과 모두가 창제 사건을 직접 설명하는지는 추가 확인이 필요하다.
   - 후속 AI 요청에서 429가 발생했다. 제한된 안내로 전환하고 요청을 보존했다.
   - 4.19초. 새 주제에 대한 AI 설명까지 완주했다고 처리하지 않는다.

SDK 요청은 7회(정상 응답 6회·429 1회)였다. 오류에 보고된 제한은 모델별 프로젝트당
무료 분당 5회다. 이것으로 하루 한도나 전체 한도 복구를 판단하지 않는다.
추가 요청을 즉시 중단해 해외 비교와 쉬운 설명의 후속 시나리오는 실행하지 않았다.
비교 → 퀴즈 → 오답 복습 완주와 반복 성공률은 여전히 미측정이다.

성공 응답 6개의 보고 사용량은 입력 11,611토큰, 출력 465토큰(입력 중 캐시 1,927토큰)이다.
오류 요청 사용량과 실제 청구 단가가 없어 실행 전체 비용은 확정하지 않는다.
원시 결과는 Git에서 제외되는 `outputs/agent-live-copy-20261025-06.json`과 동명 DB에 보존한다.

## 발견한 난도 문제와 보완

쉽게 설명해 달라는 요청에도 기단·탑신·난간이 풀이 없이 한 문장에 남아 있었다.
대화의 학습 설명에 기존 유산 설명용 용어 풀이를 펼쳐 볼 수 있게 연결했다.
원문·답변·저장 기록은 바꾸지 않고 추가 API 요청도 하지 않는다.

- AI 학습 설명에서 실제로 쓰인 단어만 최대 5개 표시한다.
- 사용자 입력·사전 원문에는 적용하지 않는다.
- 인용 원문에만 있고 답변에 없는 단어는 추가하지 않는다.
- 역사적 사실을 새로 생성하거나 모델 판단·학습 점수를 바꾸는 기능이 아니다.

용어 풀이의 표시 조건·원문 보존 검사 5개를 추가했다. 이 보완은 AI 문장 전체를
어린 학습자에게 알맞게 재구성했거나 교육 효과를 입증했다는 뜻이 아니다.
WBS의 실제 AI 품질·목표 변경·복습 완주 항목은 진행 중으로 유지한다.

## 후속 자동 검사와 WBS

- Python 3.13: 전체 801개 검사, Ruff 린트·250개 파일 서식 검사 통과(278.67초).
- Python 3.12: 화면 문구·체험 이동·검색 복귀 관련 66개 검사 통과.
- 최종 WBS는 E228·E229의 검사 수만 801개·66개로 갱신했다. 5분 초기화 확인 문구,
  완료 246개·진행 중 17개·예정 4개, 담당자·일정·서식·주말 날짜 색상은 유지했다.
- 실제 AI 호출은 앞의 7회에서 끝났다. 후속 검사는 Gemini를 끈 자동 검사다.
