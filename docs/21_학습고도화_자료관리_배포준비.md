# 학습 내용 고도화·자료 관리·배포 준비

후속 배포 요청: `render.yaml`의 RETENTION_ENABLED는 true로 변경했다. 운영에서는 90일 경과 기록을 백업 후 정리하며, 로컬 기본값은 false로 유지한다. 아래 실행 기록의 ‘배포/업로드 미실행’은 준비 작업 완료 시점의 기록이며, 실제 배포 성공 여부와 URL은 별도로 확인해야 한다.

## 1. 한국어 학습 설명

- 초급 기본 도움말에 사암·석회암·금박·색유리, 반구형·돔·아치·기둥·지붕·성벽 등 원문 표현을 추가했다.
- 중급은 원문 해설과 함께 연대 사건, 건물/구성 부분, 재료의 사용 위치, 종교와 쓰임의 읽기 기준을 제공한다.
- 고급은 수집 원문을 그대로 유지한다. 초급도 항목별 인용과 원문 전체를 펼쳐 볼 수 있다.
- 영문 자료의 ‘한국어 풀이로 읽기’는 사용자 클릭 후 Gemini를 한 번 호출한다. 키 없음·연결 실패·검사 실패 시 기본 도움말로 돌아간다.
- AI 초안은 정확한 원문 인용, 지원 항목, 숫자, 기원전·추정·부정·재건 표현, 알려진 특징을 검사한다. 이 검사는 번역 의미의 완전한 검증이 아니며, 결과는 **공식 번역이 아닌 검토가 필요한 초안**으로 표시한다.
- 원문 ID·URL·내용 해시·수준·모델·풀이 버전으로 성공 초안을 캐시한다. 원문이 바뀌면 다시 생성하며, 오래된 원문은 AI 풀이에 쓰지 않는다.

## 2. 추천과 비교 분석

- 양쪽 자료에서 확인한 항목과 선택 목표의 근거를 추천 이유에 표시한다.
- 개별 출처는 최대 6개를 확인하고, 근거 항목의 충실도를 반영해 상위 3개를 고른다. 찾은 순서대로 3개에서 중단하던 방식은 보완했다.
- 복수 재료는 하나만 골라 주재료로 단정하지 않고 함께 언급된 재료·각 부분의 쓰임을 대조한다.
- 설명에 없는 특징은 실제로 없다는 뜻으로 바꾸지 않는다. 기원전/기원후 연도는 양수로 단순 차감하지 않는다.
- 공통점과 항목별 분석은 같은 읽기 표현 집합을 사용한다. 원문 양쪽의 인용을 연결하고 의미 상태는 검토 후보로 유지한다.
- 새 저장본의 학습 구성 버전은 3이다. 기존 결과를 덮어쓰지 않고 최신 근거로 재탐구하도록 안내한다.

## 3. Gemini 퀴즈 부분 수정

- 초안이 로컬 문항 검사에서 실패하면 최대 1회 수정한다. 정상 개별 문항은 보존하고 오류 문항을 수정하도록 요청한다.
- 중복·양쪽 유산 배분·목표 항목 배분처럼 전체 구성이 잘못되면 전체 배분을 다시 요청할 수 있다.
- 수정 후에도 정답 원문 일치·대상·보기·수준·양쪽 배분·목표 검사를 동일하게 적용한다. 실패하면 규칙 퀴즈를 제공한다.
- 429·연결 실패는 반복 호출하지 않는다. 첫 응답의 JSON 파싱 자체가 실패한 경우도 즉시 대체 경로를 쓴다.
- `CULTUREBRIDGE_QUIZ_REPAIR_ATTEMPTS=0`으로 수정 호출을 끌 수 있다. 최대 호출 수는 2회, 호출별 제한시간은 기존 QUIZ_TIMEOUT_MS다.

## 4. 공식 자료 관리

공개 화면 `/sources`, 읽기 전용 API `GET /api/sources`에서 다음을 제공한다.

- 기관 링크, 국가, 개별 대상/경내 범위, 한국어 이름·별칭, 포함 관계.
- 마지막 연결 시도·마지막 성공·캐시 시각·실패 코드. ‘미확인’은 현재 서버의 수집 이력이 없다는 뜻이다.
- 이름의 안내/팀 검토 상태, 이용 조건의 검토 전/검토 기록 있음/이용 제한 상태.

외부에서 수정할 수 있는 관리자 API는 만들지 않았다. 서버에 접근할 수 있는 관리자가 로컬 CLI를 사용한다.

```powershell
python -m culturebridge.manage_sources list
python -m culturebridge.manage_sources review sanchi-great-stupa --korean-name "산치 대탑" --alias "산치 제1탑" --name-status reviewed --note "팀에서 이름을 검토함"
python -m culturebridge.check_individual_sources --all --workers 3
```

이용 조건을 실제로 확인한 다음에만 `--usage-status reviewed`와 검토 범위·링크를 메모한다.
검토 표시 자체가 이용 허가나 재배포 권리의 취득을 뜻하지 않는다. 이미지 이용 권한은 별도 확인한다.
`restricted`는 새 검색·수집·동적 재사용을 막는다. 기존 저장 비교·백업은 자동 삭제하지 않는다.
문단 선택자·고정 URL 변경은 코드 검토 후 반영한다. CLI로 임의 URL을 추가하지 않는다.
일반 이용자에게 보여도 되는 메모만 입력한다. 비밀·내부 개인 정보는 메모에 넣지 않는다.

## 5. 기록과 운영

`/data-policy`에서 익명 세션, Gemini 전송 가능 내용, 현재 보관·백업 설정과 삭제 범위를 안내한다.
이 문구는 기술 운영 안내이며 실제 운영기관 정보·동의 절차·관련 정책 검토를 대신하지 않는다.
POST `/api/learning-data/delete`는 확인 문구 ‘이 세션의 학습 기록 삭제’가 필요하며,
서명된 현재 브라우저 세션의 비교·퀴즈·성적을 삭제한다. 다른 소유자·공용 원문은 유지한다.
진행 중인 학습 작업과 충돌하면 삭제를 보류하며, 삭제 후 결과 캐시를 비워 기록이 되살아나지 않게 한다.

자동 운영 기본값은 비활성이다. 실제 `.env`와 기존 사용자 기록은 이번 작업에서 바꾸지 않았다.

| 설정 | 기본값 | 의미 |
|---|---|---|
| MAINTENANCE_ENABLED | false | 활성화 시 시작 시점과 이후 지정 간격에 백업 |
| MAINTENANCE_INTERVAL_HOURS | 24 | 재시작하면 간격 기준이 다시 시작됨 |
| BACKUP_DIR | backups | 운영에서는 영구 디스크 아래 경로 사용 |
| BACKUP_KEEP | 14 | 자동 명명 백업 중 최근 14개 유지; 수동 백업은 제외 |
| RETENTION_ENABLED | false | 자동 학습 기록 삭제는 별도 활성화 필요 |
| RECORD_RETENTION_DAYS | 90 | 생성 이후 이 기간을 넘긴 소유 학습 자료가 정리 대상 |

환경 변수에는 `CULTUREBRIDGE_` 접두어를 붙인다. 이전 자료는 마이그레이션 시점부터 보관 시계를 시작한다.
새 퀴즈가 참조하는 비교는 외래 키 보호를 위해 남겨 둘 수 있다. 소유자를 알 수 없는 과거 기록은 자동 삭제하지 않는다.
유산·원문 캐시·한국어 풀이 캐시는 공용 교육 자료로서 학습 기록 보관 정리 대상이 아니다.

```powershell
python -m culturebridge.maintenance
python -m culturebridge.maintenance --apply
python -m culturebridge.restore_db --backup backups/선택한백업.db --output data/복원한새파일.db
```

첫 명령은 미리보기다. `--apply`는 무결성을 확인한 백업을 먼저 만들고 자동 백업 보관 수를 적용한다.
학습 자료 삭제는 RETENTION_ENABLED가 true일 때만 한다. 백업이 실패하면 기록 정리를 진행하지 않는다.
오래된 자동 백업 파일의 정리는 되돌릴 수 없다. 수동 백업은 자동 정리하지 않는다.
학습 기록 삭제 후에도 기존 백업 사본은 백업 보관 주기에 따라 만료된다.
복원 명령은 원본 백업의 무결성·외래 키를 확인하고 **새 파일에만 복원**한다.
복구하려면 서버 중지 → 현재 DB 별도 백업 → 새 파일 복원 → DB_PATH 변경 → 서버 시작 순서로 한다.
별도 외부 저장소에 암호화한 백업 사본을 두는 절차는 운영자가 추가로 정해야 한다.

## 6. Render 배포 템플릿

루트 `render.yaml`은 실행하지 않은 준비 파일이다. 자동 배포는 껐고 단일 인스턴스·단일 worker를 명시했다.
영구 디스크 아래에 SQLite·NiceGUI 저장소·백업을 두고, 운영 비밀은 별도로 생성하며 Gemini 키는 비밀 설정에 입력한다.
HTTPS 운영용 `CULTUREBRIDGE_SECURE_COOKIES=true`를 지정해 프록시 뒤에서도 익명 세션 쿠키의 Secure 속성을 유지한다.
템플릿은 **유료 컴퓨팅·영구 디스크** 구성을 포함한다. 비용과 사양을 확인하고 사용자가 생성하기 전에는 배포되지 않는다.

Render의 [Blueprint 명세](https://render.com/docs/blueprint-spec)와
[영구 디스크 제약](https://render.com/docs/disks)을 참고했다.
영구 디스크는 빌드 단계에서 접근할 수 없으므로 초기화·자동 백업은 앱 런타임에 실행한다.
디스크가 연결된 서비스는 여러 인스턴스로 수평 확장할 수 없다. 현재 요청 제한·작업 캐시는 단일 프로세스용이다.
다중 서버 확장은 별도의 공유 DB·세션/요청 제한·작업 저장소·백업 설계가 필요하며 이번 템플릿으로 지원한다고 주장하지 않는다.
동일 디스크의 백업은 디스크 자체 손실에 대비한 독립 백업이 아니다. 운영 전 별도 보관 위치를 결정한다.
이 파일만으로 Linux 실배포·요금·운영 정책 승인이 완료된 것은 아니다.

## 7. 실행 확인과 미완료 구분

- Python 3.12·3.13에서 전체 자동 테스트 각각 408개 통과. 신규 19개는 한국어 초안·퀴즈 수정 한도·이름/이용 제한·세션 삭제·백업/복원을 다룬다.
- Windows 백업 연결이 닫히지 않아 파일 보관 정리가 실패하던 문제를 수정하고 자동 백업 보관 수와 수동 백업 보존을 확인했다.
- Render YAML 구문, 단일 인스턴스와 자동 배포 꺼짐 설정을 확인했다. Render에서의 실제 서비스 생성이나 Linux 실행 확인은 하지 않았다.
- 별도 진단 DB의 실제 대연회장 원문으로 Gemini 초급 한국어 풀이가 인용·숫자·항목 검사를 통과했다. 왕호 로마 숫자 IV와 한글 표기 4세의 대응을 원문 숫자 검사에 반영했다. 숫자 I라는 일반 대명사를 숫자로 취급하지 않는다.
- 같은 진단 DB의 저장 비교로 실제 Gemini 퀴즈 5문항이 원문 정답·대상·양쪽 배분 검사를 통과했다. 실제 문항은 첫 초안에서 통과했고, 부분 수정 경로는 별도 모의 검증으로 확인했다.
- 이는 전체 유산·모든 난도의 번역 의미나 실제 모델의 전체 검색 계획부터 학습 종료까지를 검증한 것은 아니다.
- 원문 이용 조건 확인·한국어 풀이 교육자 검토·운영기관 연락처와 최종 정책 확정은 사람의 검토가 필요하다.
- 로컬 `.env`·사용자의 실제 DB·학습 기록·제출 WBS는 수정하지 않았다. 자동 정리·유료 서비스 생성·GitHub 업로드는 실행하지 않았다.
