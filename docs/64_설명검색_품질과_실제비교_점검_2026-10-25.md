# 설명·검색 품질과 실제 비교 점검

## 서버와 데이터

기존 학습 DB를 SQLite 백업 기능으로 복사하고 무결성 검사 `ok`를 확인한 뒤
로컬 8081 서버를 재시작했다. 백업은 `backups/culturebridge-before-restart-64f5410-20261025.db`다.
홈·설정·대화·코스·역사 검색·학습 기록은 모두 HTTP 200이며 최신 설정 문구도 확인했다.
키·과금·모델·한도·개인 설정은 바꾸지 않았다. 품질 점검 DB와 브라우저는 별도로 사용했다.

## 설명·검색 보완

1. 쉬운 AI 설명은 문장별 65자 이하·최대 3개 문장인지 확인한다. 한 항목에 여러 문장을
   합쳐 보내거나 지나치게 길면 추가 모델 검토 요청 전에 기존 읽기 도움말로 전환한다.
   원문과 인용은 자르거나 바꾸지 않는다. 자세한 설명 기준은 유지한다.
   이 길이 기준은 이해도 측정이나 어린 학습자에게 적합하다는 보증이 아니다.
2. 역사 검색은 제목에 질문의 어떤 표현이 있는지 표시하고, 관련 표현이 많은 결과를
   앞에 둔다. 세종·세종대왕, 한글·훈민정음·언문은 제목 탐색용 명칭 묶음으로 처리한다.
   실제 제목에 있는 표현만 보여 주며, 부분 일치와 확인하지 못한 경우를 구분한다.
   불확실한 결과를 숨기거나 본문까지 검토했다고 표시하지 않는다.
3. 브라우저의 ‘세종대왕 한글 창제’ 검색에서 관련 표현 ‘언문’이 있는 결과와 제목만으로
   관련성을 확인하지 못한 결과가 나뉘어 보임을 확인했다. 공식 제목·링크만 사용하며,
   신편 한국사 본문을 수집·AI 전송·요약하는 기능으로 확대하지 않았다.

## 실제 AI 실행

원시 기록은 `outputs/agent-live-quality-20261025-07.json`과 동명 DB다.
합성 학습자 질문을 사용했으며 실제 학습자의 교육 효과 점검이 아니다.

- 요청: 다보탑을 기준으로 해외 탑을 골라 시대·재료를 비교하고 퀴즈 준비.
- AI 선택: 다보탑 검색 → 해외 후보 탐구 → 다보탑과 도지 오층탑 비교 → 퀴즈 준비.
- 다보탑 기준 대상과 시대·재료 목표가 유지됐고 비교 1개·퀴즈 5문항이 생성됐다.
- 저장된 특징의 근거 인용 7곳이 각각 수집 원문에 실제로 존재함을 대조했다.
  인용 일치가 역사 해석 전체의 정확성을 보증하지는 않는다.
- 다보탑 연대의 추정 표현을 유지했고, 한쪽 근거가 없는 종교적 배경은 비교를 보류했다.
- 고정된 시험용 답안을 제출해 1/5점으로 채점됐고, 오답 근거 조회까지 진행했다.
- 이후 AI 복습 설명을 만들기 전에 429가 발생했다. 모든 추가 모델 호출을 중단했다.
- 비교·퀴즈 준비 28.68초, 답안 제출·오답 근거 조회 3.88초. 이 두 표본을 일반적인
  응답 시간이나 반복 성능으로 확대하지 않는다.
- SDK 요청 7회 중 응답 6회·429 1회. 보고된 제한은 무료 프로젝트 모델별 분당 5회다.
  응답 6회 사용량은 입력 16,645·출력 662토큰이며 입력 중 캐시 1,338토큰이다.
  실패 요청의 사용량과 청구 단가가 없어 전체 비용을 확정하지 않는다.
- 주제 변경과 쉬운 설명의 후속 실제 시나리오는 호출하지 않았다.

## 평가 기준의 과대 판정 수정

기존 보고에서는 `quiz_review` 값이 있으면 오답 복습을 완료한 것으로 계산했다.
이번 실행은 오답 근거만 조회했고 복습 설명은 없었으므로 이 기준이 성공을 과대 평가했다.

- 근거를 불러온 실행 수와 근거에 연결된 실제 복습 설명이 있는 실행 수를 구분한다.
- 복습을 요구한 평가에서는 설명·인용이 있어야 완료로 인정한다. 전부 맞혀 오답이 없는
  경우는 예외로 두되, 이를 이해·숙달의 확정으로 해석하지 않는다.
- 새 기록은 제공자 한도 중단 여부를 명시한다. 과거 기록도 마지막 429와 제한 안내
  전환이 함께 확인되면 중단으로 집계한다.
- 실제 호출 없이 기존 원시 기록을 다시 계산하면, 비교·퀴즈·근거 조회는 확인되지만
  요청한 복습 설명까지 포함한 과제 완료는 0/1이다. 다보탑 기준 이탈은 이 표본에서 0/1.
  이는 서비스의 일반적인 성공률·이탈률이나 교육 효과를 뜻하지 않는다.

WBS의 실제 AI 품질·반복 검증·복습 완주·비용 확인 항목은 진행 중으로 유지한다.
기능·검토 절차·자료 이용 제한을 제거하거나 임의로 허가 상태를 바꾸지 않았다.
