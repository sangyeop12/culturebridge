# 공식 용어 자료 연동

기준일: 2026-10-20. 담당자: 김상엽.

## 자료별 역할

표준국어대사전은 단어의 사전적 뜻을 조회하고, 기존 국가유산청 도구는 특정 유산의
공식 설명과 역사적 맥락을 확인한다. 대화 Agent는 필요에 따라 `define`, `search`,
`read`를 선택하며 매번 두 기관을 호출하지 않는다. 사전 뜻을 특정 유산의 연대나
용도에 대한 증거로 사용하지 않는다. 국가유산 용어사전의 전용 공개 API는 아직 확인되지
않았으며 이번 코드에서 임의의 비공개 인터페이스나 웹 스크래핑으로 대체하지 않았다.

## 표준국어대사전 계약과 설정

공식 안내: https://stdict.korean.go.kr/openapi/openApiInfo.do

검색 URL은 `https://stdict.korean.go.kr/api/search.do`이며 인증키가 필요하다.
`.env`에 `STDICT_API_KEY`를 설정한다. 실제 키는 코드·GitHub·화면·로그에 넣지 않는다.
설정 객체는 SecretStr로 보관하고 HTTP 요청 로그의 해당 키도 마스킹한다.

`GET /api/learning/terms?q=기단` 또는 대화의 "기단이 뭐야?"로 조회한다.
정확한 표제어 검색만 하며 최대 5개 뜻풀이를 원문 그대로 표시한다.
동음이의어와 여러 의미를 첫 번째 결과 하나로 확정하지 않는다. 용례·사진·발음·음성·
그 밖의 멀티미디어는 수집하지 않는다. 제공 응답의 임의 링크 대신 공식 단어 ID를
검사해 표준국어대사전 원문 링크를 만든다.

인증키가 없으면 `not_configured`, 미등록·중지된 키는 `invalid_key`, 검색 결과가 없으면
`not_found`로 구분한다. 연결 장애·잘못된 응답·너무 큰 응답에는 뜻을 만들어 채우지 않는다.
키가 없어도 국가유산청 검색과 기존 서비스는 계속 사용할 수 있다.

메모리 캐시는 5분·최대 128개이다. 서버 전체 분당 20회라는 보수적인 로컬 제한을
추가했으며, 이는 제공 기관이 계정에 승인한 호출량이라는 뜻이 아니다. 실제 발급 계정의
이용 조건·한도·신청 조건은 사용자가 확인해야 한다. HTTP 리디렉션을 따라 키를 보내지 않는다.

## 출처와 이용 조건

저작권 정책: https://stdict.korean.go.kr/join/copyrightPolicy.do

정책은 별도 명시가 없는 자료에 CC BY-SA 2.0 대한민국을 적용하며, 출전 있는 용례와
멀티미디어는 별도 조건을 안내한다. 이번에는 단어 뜻풀이 텍스트만 원문으로 제공한다.
각 결과에 국립국어원 표준국어대사전의 명칭, 단어 원문 링크, 라이선스 링크와 원문
그대로라는 정보를 함께 저장·표시한다. 사전 자료를 가공하거나 별도로 배포한다면
해당 자료의 동일조건변경허락을 준수해야 한다. 애플리케이션 소프트웨어 전체의 라이선스와
사전 콘텐츠의 라이선스를 같은 것으로 처리하지 않는다.

사전 조회 결과는 `dictionary` 종류의 메시지로 구분하고, 후속 Gemini 계획 요청의
대화 이력에는 원문 뜻풀이를 자동으로 포함하지 않는다. 국가유산청의 역사 설명과
사전 정의를 합쳐 새로운 사실이라고 표시하지 않는다. 기존 25개 해외 자료에 대한
허가 문의·승인 상태는 이 사전 라이선스와 별개이며 이번 작업에서 변경하지 않는다.

## 남은 검증

실제 인증키를 받은 뒤 제공 기관의 정상 응답·계정 한도·오류를 확인해야 한다.
현재 자동 검증은 모의 HTTP 응답에 기반한다. 실제 키를 발급받거나 계정을 생성하는
행위는 이번 작업에서 수행하지 않았다. R04 전체와 역사적 의미 검증 전체가 완료됐다고
표시하지 않는다.

## 검증 기록

2026-10-20 Python 3.13에서 전체 회귀 543건 통과(229.16초), Python 3.12에서
543건 통과(220.92초). 이후 출처를 펼치지 않아도 표시하도록 수정하고 UI 검사 1건을
추가했으며, 관련 대화·사전 검사 31건을 양쪽 환경에서 다시 통과했다.
Ruff 검사와 변경 파일의 공백 오류 검사도 통과했다.

AI를 끈 별도 DB의 로컬 미리보기에서 자유 입력, 대화 이동, 중단, 새로고침 복원,
재개, 인증키 없는 사전 질문의 대체 안내를 브라우저로 확인했다. 이 결과를 실제 Gemini
정상 응답·사전 인증키 연결·역사 전문가 검수·실제 기기 PWA/STT 검증과 혼동하지 않는다.
