# 학습 화면의 내부 분석 문구 정리

## 적용 범위

- 비교·탐구·추천·주장 확인 화면에서 실행 기록, 추출 메모, 원시 판단 사유를 표시하지 않는다.
- 대화 학습에는 활동 이름과 결과만 남기며, 도구 선택의 내부 사유와 계획 메모는 표시하지 않는다.
- 공식 자료 안내에서 개발용 검토표·검토 메모를 제외하고 공식 출처와 이용 조건 링크를 유지한다.
- 오류 화면에 서비스의 예외 문자열을 직접 출력하지 않는다.
- 학습 단계의 개발·검수 중심 표현을 읽기·비교·생각해 보기 중심의 표현으로 바꾼다.

## 기존 저장 결과 처리

저장한 `explanation`, `scope_note`, `note`, `context_note`, `verification_note`를
그대로 화면에 출력하지 않는다. 표시용 모듈에서 인용문을 재검사해 학습 안내를 구성한다.
원문 근거가 없거나 오래된 자료이면 새 사실을 보충하지 않는다.

데이터베이스의 기존 기록이나 공식 인용문은 수정하지 않는다. 내부 실행·검증 데이터와
자료 이용 제한도 유지한다. 날짜의 추정 여부와 자료가 부족하다는 안내는 역사적 사실을
단정하지 않기 위해 학습자에게 이해하기 쉬운 표현으로 제공한다.

## 확인

- 기존 다보탑–도지 오층탑 비교를 실제 브라우저에서 다시 열어 분석 문구 제거 확인.
- 공식 원문 펼쳐보기와 출처 링크 유지 확인.
- 저장 결과에 진단용 문자열을 넣은 회귀 검사에서 화면에 노출되지 않으며 기록도 변경되지 않음 확인.
- 대화의 내부 계획 사유는 숨기고 학습 활동은 유지되는 회귀 검사 추가.
- 원시 오류와 추천 규칙 문자열을 그대로 출력하지 않는 검사 추가.
- Python 3.13 관련 화면·이동·체험·학습 검사 80개 통과.
- Python 3.13 최종 통합 검사: 린트·서식 정상, 전체 테스트 822개 통과.
- Python 3.12 관련 검사 89개 통과(화면·이동·체험·학습 80개, 대상 구분 9개).
- Gemini 실호출·키 변경·과금 설정 변경은 하지 않음.
