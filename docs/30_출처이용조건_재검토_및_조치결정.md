# 출처 이용 조건 재검토 및 조치 결정

기준일: 2026-10-19. 공식 약관을 다시 조회한 사전 검토 기록이다. 법률 의견이나
권리자의 이용 허가가 아니다. 소프트웨어의 허용 설정을 변경한 기록도 아니다.

## 결론

25개 해외 개별 유산의 현재 출처에 대해 서비스용 저장·표시, 번역·가공,
외부 AI 전송, 결과 재배포를 모두 포괄하는 허용 근거를 확보하지 못했다.
이는 네 행위가 모두 불법이라는 판정이 아니라, 현재 방식 그대로를 승인할
자료가 없다는 뜻이다. 교육 목적·비상업·출처 표기만으로 허가를 추정하지 않는다.

약관 확인은 아래와 같이 기록했으나, 실제 서비스 사용 범위의 승인·대체·제한
반영이 남았으므로 WBS 14행은 진행 중을 유지한다. 기존 제출본과 실제 진행본을
이 문서 작성만으로 완료로 변경하지 않는다.

## 네 가지 이용 범위

| 범위 | 이번 판단 | 완료 조건 |
|---|---|---|
| 서버 저장·화면 표시 | 개인 열람 허용을 공용 서비스 저장·표시 허용으로 확대하지 않음 | 적용 가능한 공개 라이선스나 서면 허가 확인, 또는 원문 미사용으로 전환 |
| 한국어 번역·쉬운 설명 가공 | 번역·변형 허용 범위 미확정. 원문의 표현을 바꾼 것만으로 해결하지 않음 | 변형 허용 근거 확인, 또는 허용 출처를 근거로 새로 집필 |
| Gemini 등 외부 AI 전송 | 현재 승인하지 않음. 기존 외부 AI 제한 유지 | 제3자 처리·전송과 실제 공급자 조건까지 검토한 근거 기록 |
| 다운로드·재배포 | 원문·인용·번역이 포함된 HTML/MD/JSON 결과의 범위 미확정 | 재배포 허용 근거 확인, 또는 결과에서 해당 내용을 제외·대체 |

## 코드 확인 결과와 주의점

- `source_permission_service.external_ai_allowed`는 해외 개별 출처의 AI 처리 승인
  기록이 없으면 거부한다. 권한 미확인 원문을 확인 목적으로 Gemini에 보내지 않았다.
- 현재 `fetch_individual`은 관리자 제한 상태를 확인하지만 별도의 저장·표시 권한
  승인을 필수로 요구하지 않는다. 따라서 AI 차단만으로 네 범위가 모두 해결되지 않는다.
- `material_review_service`의 번역·AI·재배포 미확인 표시는 유지한다.
- `/api/comparisons/{record_id}/export`는 세션 소유권을 검사하지만 이것이 콘텐츠
  재배포 허가 검사는 아니다. 기존 저장본·비교·퀴즈·내보내기까지 일관된 처리가 필요하다.
- 실제 DB의 권한 승인, 원문 삭제, 자료 비활성화, 기존 결과 수정은 수행하지 않았다.
  부분 차단 후 전체 해결로 표시하지 않는다.

## 사용자 결정이 필요한 이유

1. **기능 유지 우선:** 같은 국가·같은 개별 대상의 공개 라이선스 공식 자료를 찾고,
   범위·원문·인용·수준별 설명·추천·퀴즈를 대체한다. 대체 자료가 실제로 확보되기
   전에는 25개 유지나 전체 허용을 보장하지 않는다. UNESCO 유산군 설명을 개별 건물
   설명으로 대신하면서 같은 대상이라고 표시하지 않는다.
2. **우선 사용 제한:** 승인되지 않은 원문은 수집·표시·가공·AI·내보내기에서 제외하고
   기관 정책이 허용하는 링크·안내로 전환한다. 여러 대표 코스와 해외 비교가 중단될 수 있다.
   기존 저장본도 삭제하지 않고 보존하면서 표시·내보내기를 별도 제한해야 한다.
3. **기관 허가:** 프로젝트·신청자 정보와 실제 사용 범위를 확정하고 기관에 문의한다.
   초안 작성과 발송은 구분하며 사용자 승인 없이 기관에 연락하지 않는다.

다수의 해외 학습 기능을 없애는 변경이나 대외 허가 신청을 사용자 선택 없이 진행하지 않는다.
이번 결과는 약관 재확인과 조치안 정리이며, 완료 상태를 만들기 위한 형식적 승인이 아니다.
