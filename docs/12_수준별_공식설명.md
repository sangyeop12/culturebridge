# 수준별 공식 설명

확인일: 2026-10-14

## 변경

국가유산청 공식 상세 화면에 수준 전환을 추가했다. 기존 주소는 초급을 기본값으로 사용한다.
홈 선택 수준은 공식 상세 링크에 전달된다. 탐구·비교의 수집 원문과 근거 카드에도 해당 수준을 적용한다.

- 초급: 원문 직접 근거를 항목별로 찾고 핵심 연대·쉬운 용어 풀이를 표시한다. 연대 숫자·추측·전승·부정·재건 사건을 유지한다.
- 중급: 네 항목의 근거를 분리하고 용어 풀이·사건별 연대·해당 항목 원문을 제공한다.
- 고급: 수집·저장한 공식 설명 본문 전체를 수정 없이 표시한다. 분석·검토 후보는 원문과 분리한다.
- 초급·중급에는 원문 전체 펼쳐보기, 모든 수준에는 공식 출처 링크를 제공한다.
- 원문 DB·기존 저장본·기존 상세 API 본문을 변경하지 않는다. 학습 설명은 읽기 전용 표시 변환이다.
- 원문이 오래됐거나 수집에 실패하면 새 설명을 보류한다. 항목이 없으면 근거 부족으로 남긴다.

한국어 원문은 용어 풀이와 핵심 문장·연대 안내를 사용한다. 자유 생성형 요약이나 역사적 의미 확정이 아니다.
영문 원문은 검출된 원문 표현의 한국어 읽기 안내이며 전체 번역문으로 표시하지 않는다.
고급의 ‘원문’은 국가유산청 XML의 마크업을 제거해 이미 수집된 설명 본문을 뜻한다. 원문 XML은 출처 링크에서 확인한다.

## API

`GET /api/official/heritages/{kind}/{number}/{region}/lesson?level=beginner|intermediate|advanced`.
반환에는 수준·안내·항목 설명·원문 인용·원문 전체·출처·용어 풀이가 포함된다.
기존 상세 API는 기존 형식과 `content`를 유지한다. 알 수 없는 API 수준은 422로 거부한다.

## 검증

새 테스트: 세 수준 본문 차이, 추정 표현 보존, 고급 원문 동일성, 입력 객체 무변경,
없는 재료를 화강암으로 채우지 않음, 오래된 자료 보류, 재건·부정 안내,
영문 읽기 도움말과 번역문 구분, 수준별 API/UI, 잘못된 수준 거부.

Python 3.13.15: 242개 통과(58.65초), Python 3.12.14: 242개 통과(59.98초).
두 환경 모두 Ruff·포맷 검사 통과. 자동 검사에서는 실제 Gemini를 호출하지 않았다.
마지막 영문 중급 읽기 안내·용어 풀이 보완 후 수준별 테스트 9개 통과(2.99초).
재시작한 서버의 실제 다보탑 자료로 세 수준 API와 고급 상세 페이지 HTTP 200 확인.
세 수준 모두 원문 전체가 기존 상세 API 본문(1111자)과 동일함을 확인했다.
초급의 751년 추정 안내, 중급의 네 항목, 고급의 원문 표시를 확인했다.
실제 브라우저 클릭/모바일 시각 검토는 별도다.
