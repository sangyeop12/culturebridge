# 대화 초점과 학습 흐름 보완

2026-10-24 실제 대화 점검에서 발견한 문제를 사용자 요청에 따라 수정했다.
API 키·과금·모델·요청 한도·타임아웃·재시도 설정은 변경하지 않았다.

## 1. 질문에 맞는 설명

- 설명 생성과 독립 의미 검토 양쪽에 학습 항목과 현재 질문을 전달한다.
- 재료 설명에 높이·건립 연도처럼 명백히 다른 항목이 섞이면 추가 의미 검사 호출 전에 거절한다.
- 원문의 재료 표현을 쉬운 말로 읽는 기존 도움말로 전환한다. 예를 들어 석탑의 재료 질문에는
  높이 대신 원문에서 확인되는 돌 재료를 안내한다. 돌의 구체적 종류를 추측하지 않는다.
- 공식 원문과 인용은 수정하지 않는다. 재료 설명 이외 항목도 독립 검토에서 질문 적합성을 확인한다.

규칙 검사는 모든 의미·맥락의 정확성을 증명하지 않는다. 모호한 문장의 판별과 역사적 의미 검토는
여전히 별도 검토 대상이다. 적합한 AI 설명까지 보수적으로 읽기 도움말로 전환될 수 있다.

## 2. 오류 이후 이어가기

- 실패한 사용자 요청을 대화 소유 기록의 `pending_request`에 남기고 다음 계획에 전달한다.
- `좀 더 쉽게`, `조금 더 쉬운 말로`, `제가 이해했는지 확인` 등의 명시적 후속 요청은 현재 출처와
  직전 학습 항목을 활용한다. AI 실패 시에도 새 관심사를 묻는 대신 원문 기반 도움말·확인 질문을 제공한다.
- 비교·퀴즈 진행 요청을 단순 설명으로 바꾸어 완료한 것처럼 처리하지 않는다. 연결이 복구되면
  이어갈 수 있도록 자료·요청을 유지하고 현재 상태를 안내한다.
- 429는 요청 한도 안내로 구분한다. 자동 대기·추가 재시도·유료 전환은 하지 않는다.
- 주제 변경·건너뛰기·정정 요청은 이전 대기 요청을 지운다. 성공적으로 설명·퀴즈·정리를 제공하면
  해당 대기 요청을 비운다. 제한 안내를 AI의 이해도 평가라고 표시하지 않는다.

## 3. 실행 가능한 도구와 ID만 계획에 제공

- 현재 관찰한 대상이 없으면 후보 탐색·읽기를 실행 가능한 목록에 넣지 않는다.
- 개별 대상 둘을 확보해야 비교 도구, 목표 근거가 충분한 비교를 확보해야 퀴즈 도구를 제공한다.
- 실제 제출 기록이 있어야 오답 근거 조회를 제공한다. 제출 전 퀴즈를 교체하지 않는다.
- 모델 응답 스키마의 도구 선택과 대상 ID도 현재 관찰한 값으로 제한한다. 미확인 이름을 ID로
  만들어 호출하는 낭비를 줄인다. 기존 서버의 미확인 ID·권한·비교 범위 검사도 계속 유지한다.
- UNESCO·역사 검색의 링크 메타데이터는 개별 원문 ID로 제공하지 않는다.

이는 고정 실행 순서를 강제하는 변경이 아니다. 현재 실행 가능한 도구 중 무엇을 언제 쓸지는
AI가 선택하고, 실행 후 새로운 결과에 맞춰 선택 가능한 도구 목록을 다시 구성한다.

## 4. 검색 결과 안내

- 검색 결과가 없으면 ‘이번 국가유산청/해외 자료/신편 한국사 검색에서 결과를 찾지 못함’으로 안내한다.
  해당 유산이 세계 어디에도 없다고 단정하지 않는다.
- 신편 한국사 결과는 제목·공식 링크를 찾은 것으로 안내하고, 공식 사이트로 이동해 원문을 읽는다고
  명시한다. AI가 해당 본문을 수집하거나 요약했다는 표현은 사용하지 않는다.

## 검증과 남은 한계

`tests/test_learning_continuity.py`는 실제 점검에서 발견한 발화와 결과 유형을 재현하는 회귀 검사다.
모델·자료 응답은 통제하므로 실제 Gemini 연속 대화 검증을 통과한 것으로 계산하지 않는다.
현재 API 제한에서 해외 비교 → 퀴즈 → 복습을 실제 모델로 완주하는 항목은 여전히 미검증이다.
이번 수정 후에는 추가 실시간 Gemini 호출을 하지 않았다.

자동 검증 결과:

- Python 3.13 전체 729개 통과.
- Python 3.12 관련 79개 통과.
- 이번 문제의 회귀 검사 10개 통과. 429 모의 응답 후 추가 계획 호출 없이 출처·요청·학습 항목을
  유지하는지 확인했다. 실제 서비스의 API 한도를 늘려 검증한 것은 아니다.
- Ruff 및 공백 오류 검사 통과. 최신 로컬 서버 `/learn` 응답 200.
