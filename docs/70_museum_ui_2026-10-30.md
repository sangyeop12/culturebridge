# 어린이·청소년을 위한 전시관형 UI

- 홈: 창작 전시관 삽화, 질문/발견/탐험의 세 그림 카드, 질문 및 코스 바로가기.
- 공통: 밝은 바탕, 청록 중심 색상, 살구·보라 강조색, 읽기 쉬운 고딕 제목, 큰 버튼과 입력창, 일관된 둥근 카드.
- 학습: 대화 발화자 구분, 비교 대상의 시각적 구분, 퀴즈 선택지 경계와 다음 행동 강조.
- 코스: 기존 다섯 주제 삽화와 코스 링크를 유지하면서 전시 카드 스타일 적용.
- 모바일: 390px 화면 가로 넘침 없음 확인. 홈 삽화와 시작 버튼 유지, 그림 카드는 세로 배치. 실제 기기 검증을 대신하지 않음.
- 접근성: 키보드 초점 윤곽, 기존 메뉴/음성/설정/학습 기능 유지, 동작 감소 설정 존중.
- 이미지: 로컬 SVG 창작 삽화만 추가. 실제 문화유산 사진이나 복원도가 아님을 표시. 외부 이미지 전송·다운로드와 AI 호출 없음.
- 브라우저에서 홈과 코스 화면 확인. 홈 시작점과 기존 검색·설정·대화 메뉴 접근 유지 확인. 이번 변경은 디자인 개선이며 상용화 인증이나 아동 대상 사용성 검증 완료를 뜻하지 않는다.
