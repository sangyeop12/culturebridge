# 대화에서 알아가는 관심사와 목표

기준일: 2026-10-21. 담당자: 김상엽.

## 사용자 요청에 따른 변경

관심사와 목표를 매번 ‘저장할까요?’라고 확인하는 방식은 사용하지 않는다.
대화에서 학습 주제·의도를 자동으로 파악해 다음 학습 계획에 반영한다. 직접 입력 기능은
필수 단계가 아니라 수정·명시적 지정 수단으로 유지한다. 자동 파악은 기본으로 켜져 있다.

## 구현

기존 Gemini 계획 응답에 `intent_signals`를 추가했다. 별도 모델 호출 없이 한 발화당
최대 2개 관심 주제·학습 목표 단서를 받는다. 현재 사용자 발화의 인용이 정확히 일치해야
추가할 수 있고, 관심 주제명도 인용에 실제 포함되어야 한다. 검색 문서나 AI가 한 말만으로
사용자 관심사를 만들지 않는다. 연락처·URL·일반적인 비밀 문자열 형태가 포함된 발화는
자동 기록에서 제외하지만, 이는 모든 개인정보를 탐지하는 보장을 뜻하지 않는다.

관심사·목표는 `inferred_learning_intents`에 익명 소유 세션별로 보관한다. 원 발화의
짧은 인용과 추정 방식을 함께 기록하며 최대 8개 관심사와 현재 목표 하나만 유지한다.
목표는 새 단서에 따라 갱신하고, 명시적으로 부정한 관심사·취소한 목표를 제거할 수 있다.
현재 질문이 최우선이고 직접 지정한 설정이 추정보다 우선한다. 한 번의 질문을 확정적인
성향으로 표시하지 않는다. 능력·성격·신념·개인 신상을 추정하는 기능이 아니다.

추정 결과는 `dialogue_inferred_intent`, 직접 지정한 내용은 `learner_confirmed_intent`,
이해도 관찰은 `concepts`로 분리한다. 관심사 자동 기록만으로 이해도를 갱신하지 않는다.
기존 시간·도구 횟수·토큰 제한을 유지한다. 모델 계획 응답이 없으면 짧고 명시적인
‘궁궐에 관심이 있어요’, ‘…배우고 싶어요’ 같은 표현만 제한적으로 기록하며,
이 경로를 일반적인 의미 추론이나 AI 계획 완료라고 표시하지 않는다.

대화와 추정 갱신은 같은 트랜잭션으로 저장한다. 중복 요청은 기존 응답을 재사용해 언급 횟수를
중복 집계하지 않는다. 중단된 발화와 버튼 제어 동작은 새 관심사 단서를 확정 저장하지 않는다.
추정의 자동 갱신은 직접 편집 설정의 개정 번호를 바꾸지 않아 편집 중인 필드를 덮어쓰지 않는다.

## 화면과 사용자 통제

‘내 관심사와 학습 목표’에서 최근 파악한 주제와 목표, 어떤 발화에서 파악했는지 볼 수 있다.
대화 응답 뒤 이 요약을 갱신하되 작성 중인 직접 입력은 그대로 유지한다.
저장 승인 팝업이나 확인 질문을 추가하지 않았다.

- 자동 파악 설정을 끄고 적용하면 다음 발화부터 추가 기록과 추정의 계획 전달을 중단한다.
- ‘자동 파악 끄고 기록 비우기’는 추정만 비우고 기능을 끈다. 직접 지정한 목표와 기존 대화는 유지한다.
- 기존 세션 전체 삭제와 기한 정리에 추정 기록도 포함한다. 다른 세션 기록을 삭제하지 않는다.
- 이전 대화와 이미 전송된 모델 입력은 소급 삭제되지 않는다. 기존 대화의 문맥은 계속 참고될 수 있다.

`GET /api/learning/intent/automatic`으로 자기 세션의 추정과 켜짐 상태를 확인하고,
`POST /api/learning/intent/automatic/reset`으로 추정 비우기·끄기를 실행한다.

## 검증 한계

자동 검사는 인용 일치, 민감 문자열 제외, 중복 방지, 끄기·비우기, 소유권·기한 정리,
새 대화로 전달, 직접 설정·이해도와의 분리를 다룬다. 실제 Gemini의 관심사·목표 추론 정확성은
별도 검토가 필요하다. 저장 승인 단계를 생략하는 것은 추정을 사실로 확정한다는 뜻이 아니다.
전체 회귀 검사: Python 3.12·3.13 각각 604개 통과. 마지막 방어 처리 보완 뒤 관심사 자동
파악·대화 관련 검사 32개도 각 환경에서 통과했다. 화면에서는 별도 승인 없이 관심사와
목표가 자동 표시·갱신되는 흐름을 확인했다. 브라우저 점검은 AI를 끈 명시적 표현 경로이며,
실제 Gemini 의미 추론 정확성을 검증한 것은 아니다. 부가 추정값의 형식이 잘못돼도 기존
검색·설명 계획을 무효화하지 않도록 잘못된 선택적 단서만 제외한다.
실제 사전 키 등록·GitHub 업로드·외부 배포는 하지 않았다.
