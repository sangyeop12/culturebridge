# 학습 내용·복습·재탐구 보완

## 적용 범위

1. 초급은 원문에서 확인한 재료·모양·부분·위치·종교 표현을 짧은 한국어 문장으로 안내한다. 부정·모방 표현은 긍정 사실로 바꾸지 않는다. 중급의 근거와 고급의 전체 원문은 보존한다. 영어 설명은 공식 번역문이 아닌 제한된 학습용 풀이이다.
2. 비교는 같은 기준에서 확인된 공통 특징과 설명의 차이를 구분한다. 연도 비교는 건립 사건과 단일 연도 근거가 양쪽에 있는 경우만 사용한다. 추정 표현은 보존한다. 석재/화강암처럼 설명의 구체성이 다른 경우 실제 재료 차이라고 단정하지 않는다. 한쪽에만 나온 특징은 다른 쪽에 없다는 증거가 아니다.
3. 대체 퀴즈는 목표 항목 안에서 양쪽 유산의 근거를 교대로 다루며, 기본적으로 내용 문항 최대 4개와 근거 확인 문항을 구성한다. 유효한 짧은 근거가 적으면 일반 문항으로 대체한다. 초급의 긴 영어 원문은 지원하는 한국어 특징 보기로 바꾸며, 모호하면 내용 문항을 보류한다. AI 정답은 확인된 표현의 enum에서 선택하고, 해당 항목의 정답·출처·대상을 다시 검사한다. 양쪽에 읽을 수 있는 근거가 있으면 각 유산 최소 2문항을 요구하며 미충족 시 균형 잡힌 대체 퀴즈로 전환한다.
4. 채점과 학습 기록은 같은 복습 구성 요소를 사용한다. 내 답·정답·항목별 보충 활동을 먼저 보여주고 개별 원문은 펼쳐본다. 전체 문항 해설과 근거 카드는 별도 접기 영역으로 묶는다. 짧게 풀어 쓴 정답도 해당 유산의 정확한 원문에 연결한다.
5. 신규 비교에 학습 구성 버전 2를 저장한다. 버전이 없는 과거 JSON은 0으로 읽는다. 이전 저장본에는 재검토 안내를 표시하고, `최신 근거로 다시 탐구하기`는 소유권 검사→공식 자료 재조회→현재 추출/비교→새 저장본 순서로 실행한다. 기존 기록은 수정하지 않는다. 목표·세부 목표·분량·수준·비교 범위는 유지한다. 같은 기록의 반복 클릭은 기존 세션별 요청 재사용 제한을 따른다.
6. 개별 공식 자료를 탑에서 묘당·궁전까지 확장한다. 등록 기관 URL과 대상 문단 시작 문자열만 수집한다. 추천은 핵심 유형·양쪽 목표 근거·국가 범위 검사를 유지한다. 모든 해외 자료를 임의 수집하는 범용 검색기는 아니다.

## 해외 개별 자료

- `official:taj-mahal-mausoleum`: [우타르프라데시 관광부 공식 소개](https://www.tajmahal.gov.in/overview.aspx), 타지마할 묘당, UNESCO 252와 포함 관계.
- `official:grand-trianon`: [베르사유 운영기관 공식 소개](https://en.chateauversailles.fr/discover/estate/estate-trianon/grand-trianon), 그랑 트리아농 궁전, UNESCO 83과 포함 관계.
- 기존 대안탑·호류지 오층탑은 유지한다. 유산군과 개별 대상은 같은 식별자로 합치지 않는다.

두 신규 기관 페이지의 실제 HTTPS 수집과 유효한 항목 추출을 확인했다. 호류지는 현재 연결/인증서 오류로 수집 보류 상태이며 검증을 해제하지 않았다. 새 어댑터가 모든 학습 목표의 근거를 확보한다는 뜻은 아니다.

직접 점검:

```powershell
.\.venv313\Scripts\python.exe -m culturebridge.check_individual_sources taj-mahal-mausoleum grand-trianon horyuji-pagoda
```

상태·글자 수·유효 항목만 출력하며 비밀키나 SDK 요청 내용은 출력하지 않는다. 하나라도 수집 불가/오래된 자료이면 종료 코드 1이다.

## 검증과 남은 한계

- Python 3.12.14/3.13.15에서 Ruff·형식 검사 및 테스트 각각 323개 통과. 학습 수준·양쪽 퀴즈·정답 인용 연결·이전 기록 보존·재탐구 소유권을 검사했다.
- 브라우저에서 이전 다보탑/대안탑 저장본의 버전 0 안내→재탐구→새 버전 2 저장본→양쪽 유산의 5문항 퀴즈→채점과 개별 원문 펼쳐보기를 확인했다. 새 한국어 위치 보기의 근거는 대안탑 원문과 연결되었다. 이전 기록은 보존했다.
- 2026-10-14 Gemini 질문 직접 호출은 정상 응답과 인용 검사를 통과했다(`used_ai=true`, 의미 상태는 `needs_review`). 이전 429만으로 연결 불가라고 단정하지 않는다. 반면 실제 AI 퀴즈 초안은 정답 표현·대상 표기·양쪽 문항 수 검사에서 탈락하는 사례가 있었고, 검사 기준을 낮추지 않고 대체 퀴즈로 전환했다. 전체 AI 흐름을 실증 완료한 것은 아니다.
- 한국어 풀이와 비교 분석은 지원하는 특징 규칙 범위이다. 새로운 표현·복합 문맥·역사적 영향 관계는 여전히 교육자 검토가 필요하다.
- 기존 비교와 퀴즈의 내용은 자동으로 교정하거나 삭제하지 않는다. 이전 저장본의 잘못된 내용을 계속 학습하지 않도록 재탐구 안내를 확인해야 한다.
