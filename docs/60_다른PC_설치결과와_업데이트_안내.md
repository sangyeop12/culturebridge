# 다른 PC 설치 결과와 업데이트 안내

작성일: 2026-10-25.

## 개인 노트북에서 확인한 범위

아래는 사용자가 전달한 다른 PC의 점검 보고를 반영한 내용이다.
이 작업을 수행한 PC에서 노트북을 직접 원격 조작하거나 원시 로그를 재검증한 것은 아니다.

- 환경: Windows 11 Home 25H2 x64, Python 3.13.15, Git 2.55.0.
- 저장소: `main`, `71244ef7c632a436383933286bb411ea2c26665a`.
- 전용 `.venv`에서 잠금 의존성 설치, 환경 버전·의존성 검사 정상.
- Gemini 호출을 끈 서버를 `http://127.0.0.1:8080/`에서 실행.
- 기능 검사 766개 통과. 이 숫자는 해당 커밋의 노트북 보고이며 최신 코드 검사 수와 구분한다.
- 홈 → 석굴암 → 호류지 기본 비교 → 퀴즈 제출 → 4/5점과 해설 표시 확인.
- 설정 저장·유지, 학습 기록, 비교 재열기와 체험 수동 초기화 확인.
- 첫 가상환경 생성의 ensurepip 실패는 별도 `.venv` 생성으로 해결했다고 보고했다.
  미완성 `.venv313`은 보존했으며 소스 수정은 없었다.
- `.env` 준비만 완료. Gemini·사전 키는 미등록이며 실제 AI 호출은 하지 않았다.

WBS의 ‘다른 PC 기본 기능 실행’은 이 보고를 근거로 완료 처리한다.
‘새 Clone·환경·키 설정’은 복제·환경·설정 파일 준비까지만 확인했으므로 진행 중이다.
이 결과는 다른 팀원의 설치 성공이나 최신 수정본·실제 AI 연결의 검증을 의미하지 않는다.

## 이번 수정본에서 달라진 부분

- 체험과 일반 학습 세션 분리, 이전 체험의 비교·퀴즈·성적 재접근 차단.
- 체험 초기화 상태 안내, 공식 자료로 이동할 때 체험 모드와 복귀 동작 유지.
- 학습 수준 버튼의 터치 크기, 체험 머리글 줄바꿈·제목 계층 보완.
- 일부 재료 설명·퀴즈의 조사 오류 수정.
- 실제 AI 실행에서 원래 목표·대기 요청 보존 상태를 기록하는 점검 도구 보완.
- 국가유산청 원문 기반 이해도 사례 10개와 AI 처리 권한을 구분하는 사전 점검 추가.
- 노트북의 통합 검사 진행을 막았던 소스·테스트·점검 스크립트 서식 정리.
  노트북 보고는 기존 12개 파일이었고 이 PC에서는 앞선 수정으로 한 파일이 이미 정리돼
  남은 11개 파일을 포맷했다. 서식 정리로 동작을 바꾸지는 않았다.

## 노트북 업데이트

프로젝트 폴더에서 먼저 실행 중인 서버 터미널에 `Ctrl+C`를 눌러 종료한다.
GitHub Desktop에서 `main`을 선택하고 `Fetch origin` → `Pull origin`으로 갱신한다.
로컬 변경사항 때문에 업데이트가 막히면 강제 초기화하지 않고 변경 내용을 먼저 확인한다.
Clone·가상환경 생성을 반복하거나 `.env`·로컬 DB를 덮어쓸 필요는 없다.

직접 Git 명령을 쓸 경우:

```powershell
git status --short
git pull --ff-only origin main
.\.venv\Scripts\python.exe -m culturebridge.check_environment
.\scripts\check.ps1
.\scripts\run.ps1 -Offline -Port 8080
```

환경 검사가 의존성 불일치를 보고할 때만 같은 `.venv`에 다시 설치한다.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt -e ".[dev]"
```

통합 검사는 자동 Gemini 호출을 끈다. `-Offline`은 AI 호출을 끄는 옵션이며,
공식 기관의 실시간 자료 조회까지 인터넷 없이 가능하다는 뜻은 아니다.

## 업데이트 후 다시 확인할 부분

1. 통합 검사가 린트·서식 단계에서 중단되지 않고 기능 검사까지 통과하는지 확인.
2. 개인 설정 하나를 저장하고 체험에 들어가 수준을 바꾼 뒤 ‘처음으로’를 눌러
   체험 설정은 기본값으로 돌아오고 개인 설정은 유지되는지 확인.
3. 체험에서 비교·퀴즈·공식 자료를 오갈 때 체험 머리글·초기화 버튼이 유지되는지 확인.
4. 체험 초기화 후 이전 체험의 저장 비교가 다른 체험에서 다시 열리지 않는지 확인.
5. 가능하면 실제 브라우저 메뉴로 확대율을 200%로 바꿔 메뉴·입력·버튼 겹침을 확인하고
   점검 후 원래 확대율로 되돌린다. 작은 뷰포트만으로 확대 확인을 완료 처리하지 않는다.

실제 200% 확대, 노트북의 5분 자동 초기화, Gemini·사전 키 등록·실제 연결,
외부 기관 실시간 수집과 LAN 접속은 기존 보고에서 미확인이다.
사용하지 않은 LAN 접속이나 클라우드 배포를 기본 실행 완료의 필수 조건으로 추가하지 않는다.
키·과금·한도는 임의 변경하지 않으며 실제 AI 점검은 별도 승인 범위에서 진행한다.

WBS 일정·담당자·기존 양식과 10월 27일 계획 기준 제출본은 변경하지 않는다.

## 이번 PC의 최종 통합 검사

Python 3.13 환경에서 `scripts/check.ps1 -Environment .venv313` 전체를 실행해
린트·서식 검사와 기능 테스트 777개가 모두 통과했다. 실제 Gemini 호출은 하지 않았다.
이 결과는 위 노트북의 기존 커밋 검사 766개와 구분한다. 노트북 최신 버전 재검사는
업데이트 후 별도로 수행해야 한다.
