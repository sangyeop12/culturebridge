# CultureBridge

한국·중국·일본의 문화유산을 공식 자료에 근거해 비교하고, 학습 수준에 맞는 설명과 퀴즈를 제공하는 AI Agent 기반 교육 플랫폼입니다.

## 1. 현재 구현 범위

- 문화유산 목록·상세 조회 API
- 홈 통합 검색: 국가유산청 한국 유산 + UNESCO 세계유산, 검색 범위·페이지 이동·자동완성
- 국가유산청 실제 목록·상세 API 검색, 원문·출처·조회 시각 수집과 SQLite 캐시
- 선택 문화유산을 기준으로 한 비교 후보 추천
- 두 문화유산의 구조·재료·시대·종교적 배경 비교
- 초급·중급·고급 학습 수준 선택
- 수준별 비교 해설·학습 목표·퀴즈: 초급 관찰, 중급 비교, 고급 근거 판단
- 목표 입력·맞춤 커리큘럼과 네 역할의 조건 분기 Agent
- 4개 Agent의 탐구 실행 API
- 검색 결과의 공식 ID에서 시작하는 동적 탐구: 모델 검색 계획·후보 선정 → 원문 → 근거 비교·질문·퀴즈
- 공식 출처 범위 안에서 답하는 자유 질문 화면과 API
- 역사적 주장 검증 화면·API: 재료·시대·구조의 단일 사실 대조와 근거 표시
- 비교 결과·출처 스냅샷 SQLite 저장, 저장된 비교 목록과 다시 열기
- 5문항 퀴즈 화면·채점·해설과 SQLite 학습 기록
- NiceGUI 기반 웹 화면과 전용 키오스크 체험 흐름
- 키오스크용 대형 터치 버튼·수동 초기화·5분 미사용 자동 초기화
- 잘못된 비교·퀴즈 주소의 복귀 안내, DB 실패 안내 및 API 503 응답
- 키보드 선택 버튼·포커스 표시·입력 이름·결과 알림 영역·모바일 세로 비교 배치
- 공식 출처와 검증 상태를 포함한 샘플 데이터

## 2. 실행 방법

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-lock.txt -e ".[dev]"
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
python -m culturebridge.main
```

브라우저에서 `http://127.0.0.1:8080`을 열면 됩니다. API 문서는 `/docs`에서 확인할 수 있습니다.
표준 검증 환경은 Windows/Python 3.13.15이며, 3.12.14도 호환 검증했습니다.
3.13이 없다면 첫 명령을 `py -3.12 -m venv .venv`로 바꿉니다. Python 3.14는 지원 범위 밖입니다.
기존 가상환경을 지우거나 덮어쓰지 말고, 별도 3.13 환경은 `.venv313`으로 만들 수 있습니다.
실행·검사 시 `-Environment .venv313`을 지정하면 됩니다.
패키지 버전 확인: `python -m culturebridge.check_environment`.
설치 버전이 잠금 파일과 다르면 같은 환경에서 위 `pip install` 명령을 다시 실행합니다.
박물관형 터치 체험은 `http://127.0.0.1:8080/kiosk`에서 시작합니다.
저장된 비교는 `http://127.0.0.1:8080/comparisons`에서 확인합니다.
목록은 계정별 기록이 아닌 이 기기의 공용 비교 결과입니다. 질문 입력은 저장하지 않습니다.

이미 설치된 프로젝트는 다음 명령으로 점검하고 시연할 수 있습니다.

```powershell
.\scripts\run.ps1 -CheckOnly -Offline
.\scripts\check.ps1
.\scripts\run.ps1 -Offline
```

`-Offline`은 키 설정 여부와 관계없이 앱의 자동 Gemini 호출을 끕니다.
다른 포트는 `-Port 8081`로 지정합니다. 서버 실행 중에는 터미널을 유지합니다.
자세한 순서는 [실행·5분 시연 안내](docs/05_실행_시연_안내.md)를 참고하세요.

## 4. 데이터 원칙

- 공식 기관 자료를 우선합니다.
- 출처 제목·기관·URL·조회일을 함께 저장합니다.
- 기본 예제는 유산 3건·출처 4건입니다. 검색에서 선택한 공식 대상은 별도 동적 테이블에 저장합니다.
- 확인되지 않은 내용은 사실처럼 단정하지 않습니다.
- 생성형 AI는 초안 작성에만 사용하며, 검증 상태를 별도로 표시합니다.
- 기본 비교의 주장 검증은 등록 요약과 대조하고, 공식 탐구의 주장 검토는 저장된 개별 원문과 대조합니다.
- 예: `석굴암의 재료는 화강암이다`. 일치하면 확인됨, 불일치하면 추가 확인 필요,
  지원하지 않는 문장이나 영향·인과 관계는 근거 부족으로 표시합니다.

## 5. Gemini 연동 점검

로컬 `.env`의 `GEMINI_API_KEY`와 `GEMINI_MODEL`을 설정한 뒤 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m culturebridge.check_gemini
```

`success`는 실제 AI 응답 수신, `failed`는 호출 실패, `not_configured`는 키 미설정입니다.
실제 호출은 설정한 계정의 API를 사용합니다. AI 결과는 추가 확인 필요로 표시합니다.
앱은 호출 실패·빈 응답 시 로컬 답변으로 전환하며 요청 제한시간 기본값은 15초입니다.
실제 연결 검증과 자동 테스트 결과는 [통합·품질 검증](docs/06_통합_품질_검증.md)을 참고하세요.

출처 확인: [석굴암 UNESCO](https://whc.unesco.org/en/list/736/),
[호류지 UNESCO](https://whc.unesco.org/en/list/660/),
[실크로드 UNESCO](https://whc.unesco.org/en/list/1442/),
[Google SDK](https://googleapis.github.io/python-genai/).

## 6. 국가유산청 공식 자료 연결

시작 화면의 **국가유산청 공식 자료 검색** 또는 `/official`에서 이름을 검색합니다.
목록에서 **공식 설명 보기**를 누르면 상세 원문을 수집·저장합니다. 별도 API 키는 없습니다.

- 목록: `GET /api/official/heritages?q=석굴암&page=1&page_size=10`
- 상세: `GET /api/official/heritages/11/0000240000000/37`
- 외부 API: `https://www.khs.go.kr/cha/SearchKindOpenapiList.do` 및 `SearchKindOpenapiDt.do`
- 상세 XML·정규화 본문·URL·조회 시각은 로컬 `official_documents` 테이블에 보관합니다.
- 상세 캐시는 기본 24시간, 외부 요청 제한시간은 10초입니다. 오래된 캐시로 대체할 때는
  갱신 필요와 연결 실패를 표시합니다. 검색 실패는 오류 안내 후 재시도할 수 있습니다.
- 석굴암 원문을 수집한 뒤 자유 질문을 하면, 유효한 캐시 본문을 Gemini에 함께 전달합니다.
  오래된 본문은 AI 근거에서 제외합니다. AI 응답의 출처 링크에 API 원문이 표시됩니다.
- 검색 전체를 검증된 사실로 일괄 변환하지 않습니다. 선택한 공식 대상만 원문을 수집하고
  항목별 인용 검사·부족한 근거 보류 후 비교·퀴즈로 연결합니다. 기존 예제는 유지합니다.
- 외부 자료는 지시가 아닌 근거 데이터로 전달하고 AI 답변은 추가 확인 필요로 유지합니다.
- 이미지 다운로드·재배포 기능은 포함하지 않습니다. 원문 활용 시 해당 기관 이용 조건을 확인합니다.

설정 변경이 필요하면 `.env`에 `CULTUREBRIDGE_HERITAGE_TIMEOUT_SECONDS=10`,
`CULTUREBRIDGE_HERITAGE_CACHE_HOURS=24`를 지정할 수 있습니다.

## 7. 공식 위치정보 연결

공식 설명 화면에서 **공식 위치정보 불러오기**를 누르면 국가유산공간정보 API
`https://gis-heritage.go.kr/openapi/xmlService/spca.do?ccbaKdcd=11` 등을 조회합니다.
별도 키 없이 서버에서 요청하며 유산명·지정종목·시군구가 일치하는 위치만 표시합니다.

- 앱 API: `GET /api/official/heritages/{kind}/{number}/{region}/location`
- 공간정보 API의 cnX·cnY는 UTM-K 원좌표로 표시하며 위도·경도로 임의 해석하지 않습니다.
- 위도·경도는 국가유산청 상세 API의 latitude·longitude를 사용하고 출처를 따로 표시합니다.
- 유효한 위도·경도가 있으면 외부 OpenStreetMap 지도 링크를 제공합니다.
- 좌표계 변환·지정구역·보호구역 경계 레이어는 이번 연결에 포함하지 않습니다.
- 종목별 원문 XML은 official_location_feeds 테이블에 24시간 캐시합니다.
  외부 장애로 이전 좌표를 사용할 때는 갱신 필요를 표시합니다.
- 좌표 미제공, 이름 불일치, 같은 이름의 중복 후보는 위치를 확정하지 않습니다.

좌표 체계와 지도 서비스 안내: [국가유산공간정보 Open API](https://gis-heritage.go.kr/helpAPI.do).

## 8. UNESCO 영문 XML 연결

`/unesco`에서 이름·국가·등재 ID를 검색합니다. 서버는 UNESCO DataHub의 공식
세계유산 데이터셋 `whc001` JSON API를 요청하고 받은 자료를 24시간 캐시합니다.
API는 `GET /api/unesco/heritages?q=Japan&limit=20&offset=0`입니다.

기존 `whc.unesco.org/en/list/xml`은 Cloudflare 확인 페이지로 HTTP 403을 반환하지만,
공식 DataHub API는 정상 수집됩니다. 화면의 **공식 데이터 새로고침**으로 즉시 갱신할 수
있으며 캐시 만료 후 조회 시에도 자동 갱신합니다. 별도 API 키는 필요하지 않습니다.
API 장애 시 기존 자료를 유지하고 갱신 실패를 표시합니다.
대체 자료로 공식 사이트에서 직접 내려받은 영문 XML도 다음 명령으로 가져올 수 있습니다.

```powershell
.\.venv\Scripts\python.exe -m culturebridge.import_unesco "C:\Users\sun\Downloads\unesco.xml"
```

위 경로는 예시이므로 실제 다운로드한 파일 경로로 바꿉니다. 가져오기 전에 XML 형식을
검증하고, 잘못된 파일은 기존 데이터를 덮어쓰지 않습니다. 원문은 로컬 SQLite에만
보관하며 GitHub에는 업로드하지 않습니다. 검색 UI는 처음 20건을 표시합니다.

목록 검색 화면은 이름·국가·등재연도·공식 링크를 표시하며 자체적으로 Gemini를 호출하지 않습니다.
등재연도는 건립연도가 아닙니다. DataHub와 XML은 각기 출처·형식·이용 조건을 저장합니다.
[공식 DataHub 데이터셋](https://data.unesco.org/explore/dataset/whc001/information/)은
CC BY-SA 4.0으로 안내됩니다. 수집 API·데이터셋·개별 유산·이용 조건 링크를 표시합니다.
직접 가져온 XML에는 [XML 배포 이용 조건](https://whc.unesco.org/en/syndication)이 적용됩니다.

### 한글 매칭과 자동완성

UNESCO 화면에서 한글 별칭과 국가명을 검색할 수 있습니다. 석굴암·불국사는 ID 736,
호류지·법륭사는 660, 실크로드·대안탑은 1442로 연결합니다. 대안탑은 독립 등재 항목이
아니므로 실크로드 등재 유산군을 표시합니다. 한국·대한민국·일본·중국은 국가 필터로
연결합니다. 공식 원문 이름을 번역하거나 바꾸지 않습니다.

입력 중 최대 8개 제안을 표시하며 클릭하거나 Tab 자동완성 후 Enter로 검색할 수 있습니다.
자동완성은 로컬 캐시에서 구성하므로 입력할 때마다 외부 API·Gemini를 호출하지 않습니다.
공식 영문 이름은 전체 목록에 대해 제안합니다. 한글은 기본 안내명과 로컬 이름 레지스트리의 별칭을 사용합니다.
미등록 한국어 검색어는 Gemini가 활성화된 경우 검색 버튼을 누를 때만 영문 검색어로 옮겨 공식 목록 안에서 찾습니다.
AI 검색어 변환·이름 번역은 검토 후보이며 모든 해외 유산의 한국어 검색 성공을 보장하지 않습니다.
추천 API는 `GET /api/unesco/suggestions?q=호&limit=8`입니다.

### 홈에서 국내·세계 공식 자료 검색

홈 입력 시 지원 비교 유산과 로컬 자동완성 제안이 즉시 갱신됩니다.
검색 버튼·Enter·제안 선택 시 국가유산청/UNESCO를 병렬 조회합니다. 한 기관이 실패해도
다른 결과는 유지합니다. 한국·세계 검색 범위를 선택하고 10건씩 이전/다음 결과를 볼 수 있습니다.

- 검색 API: `GET /api/search?q=불국사&scope=all&page=1`.
- 자동완성 API: `GET /api/search/suggestions?q=불국&limit=8&scope=all`.
- scope는 all/korea/world. 한국 국가명은 국가유산청 전체 목록, 해외 국가명은 UNESCO 국가 검색에 연결합니다.
- 새 설치에도 기본 검색어 제안을 제공합니다. 이후 조회한 한국 공식 이름과 캐시된 UNESCO 공식 영문 이름을 자동완성에 추가합니다.
- 해외 한글은 검토한 별칭(예: 만리장성·타지마할·마추픽추·후지산 등)을 지원합니다. 전체 유산명을 자동 번역하는 기능은 아닙니다.
- 한국은 국가유산청 공개 목록, 해외는 UNESCO 등재 목록 범위입니다. 모든 나라의 모든 문화유산을 수록한 검색은 아닙니다.
- 공식 검색 결과의 Agent 탐구 버튼으로 새 유산을 선택할 수 있습니다. 개별 원문/등재 단위와 자료 부족을 구분합니다.
- 홈 입력에는 Gemini·외부 API를 호출하지 않습니다. 첫 공식 검색에는 인터넷이 필요합니다.
- 상세 검증은 [홈 통합 검색 기록](docs/08_홈_통합검색_검증.md)을 참고하세요.

## 9. Agent 공식 자료 탐구

문화유산 선택 → 비교 후보 → **공식 자료로 Agent 탐구**를 누릅니다.
`/research/seokguram/horyuji` 또는 기존 `POST /api/explorations`에서도 실행할 수 있습니다.

- 역사 탐구 Agent가 선택한 양쪽 유산의 공식 자료를 수집합니다.
- 석굴암: 국가유산청 상세 원문과 UNESCO 등재 메타데이터.
- 호류지: 공식 DataHub 영문 소개. 대안탑: 실크로드 유산군 메타데이터와 재검색 시 시안시 개별 설명.
- 비교 결과에 수집 본문·자료 조회 시각·출처·이용 조건·수집 상태를 함께 저장합니다.
- 일부 자료가 없거나 오래되면 탐구 결과에 추가 확인 필요를 표시합니다.
- 수집했다는 사실은 내용 전체가 검증됐다는 뜻이 아닙니다. 새 공식 탐구의 비교·퀴즈는
  유효한 개별 원문 인용에 연결된 추출 후보로 구성하며, 근거 없는 항목은 보류합니다.

## 10. 시대·구조·재료·종교적 배경 추출과 근거 연결

Agent 탐구에서 국가유산청 개별 원문과 DataHub 개별 소개 등을 사용해 네 항목을 추출합니다.
Gemini 키가 활성화돼 있으면 구조화된 JSON으로 추출하고, 호출 실패 또는 키 미설정 시
항목 관련 원문 문장을 찾는 로컬 방식으로 전환합니다. 두 유산 × 네 항목의 결과를 저장합니다.

- 추출 값·출처 ID·원문 인용·출처 URL·추출 방식·검증 상태를 표시합니다.
- 인용 문장이 해당 유산의 실제 수집 본문에 정확히 존재하는지 검사합니다.
- 존재하지 않는 인용·다른 유산 출처·메타데이터·유산군 설명·오래된 자료는 제외합니다.
- 근거가 없으면 값을 추측하지 않고 근거 부족으로 표시합니다.
- 원문 일치는 의미 검증이 아니므로 근거가 있는 추출도 추가 확인 필요로 유지합니다.
- 기존 저장 결과는 재조회 시 다시 추출하지 않습니다.
- 새 탐구의 비교·퀴즈에 반영하며, 기존 저장본은 덮어쓰지 않습니다.

## 11. 공식 근거 기반 비교·퀴즈

새 Agent 탐구 결과는 basis=extracted로 저장합니다. 시대·구조·재료·종교적 배경의 추출 후보를
항목별로 나란히 표시하고, 근거가 없는 값은 근거 부족으로 남깁니다. 양쪽 인용에 같은
불교 배경·재료·구조 특징이 있을 때 공통점 후보와 두 근거를 표시합니다. 영향 관계는
자동 확정하지 않으며 원문 일치와 의미 검증을 구분합니다.

탐구의 퀴즈 Agent가 5문항을 미리 만들며 화면에서는 같은 퀴즈를 다시 엽니다. 초급은 쉬운
재료 관찰·근거 카드 읽기, 중급은 같은 항목 대조, 고급은 원문 범위와 해석의 한계 판단을
다루는 5문항을 구성합니다. 원문 없이 새 역사적 사실을 생성하지 않습니다.

- POST /api/quizzes에 comparison_id를 전달하면 근거 기반 퀴즈를 생성합니다.
- 정답·해설은 답안 제출 전에 응답에서 제외합니다. 제출 후 저장된 원문 근거를 제공합니다.
- 유효한 근거가 하나도 없거나 비교 대상이 다르면 422로 안내합니다.
- 새 공식 근거 퀴즈 생성은 이제 Gemini 초안을 사용합니다. 재조회는 기존 문항을 재사용합니다.
- comparison_id가 없는 기존 퀴즈는 검토된 기본 데이터를 사용합니다.
- 기존 저장본은 당시 내용을 유지합니다. 새 비교 방식은 새 Agent 탐구에서 적용합니다.

## 12. 저장된 공식 원문으로 주장 검토

공식 자료가 포함된 비교 화면의 주장 검증은 같은 비교 저장본을 사용합니다.
요청은 `POST /api/claims/verify`에 `comparison_id`를 추가합니다. 다른 비교 대상이나
존재하지 않는 저장본은 거부합니다. 초기 대조에서 근거가 부족하면 공식 자료를 최대 1회
추가 조회하고 재검토합니다. 기존 비교 저장본은 변경하지 않으며 추출 후보를 사실로 간주하지 않습니다.

- Gemini는 전체 문장을 개별 주장으로 나눠 지지·반박 후보의 원문 인용을 제안합니다.
- 코드가 출처 ID·유산 ID·본문 문장 일치를 재검사합니다.
- 허위 인용·다른 유산 출처·메타데이터·유산군 설명·오래된 자료는 제외합니다.
- 지지·반박·혼합 후보는 모두 추가 확인 필요이며 거짓/참의 최종 판정이 아닙니다.
- 인용이 없는 주장 부분은 근거 부족으로 안내합니다.
- 원문 한 문장과 완전히 동일한 입력만 원문 일치로 확인됨을 표시하며 독립 사실 검증을 뜻하지 않습니다.
- 키 미설정·오프라인·호출 실패 시 단일 항목의 관련 근거만 표시하거나 근거 부족으로 남깁니다.
- 사용자 주장과 검토 답변은 DB에 추가 저장하지 않습니다.
- 추가 조회된 공식 자료는 기관별 캐시에 보관하며 응답에 조회 상태·출처·실행 기록을 표시합니다.
- comparison_id가 없는 기존 API는 등록 요약의 제한된 문장 대조 방식을 유지합니다.

## 13. 맞춤 목표·추천·조건부 재검색

- 시작 화면에서 관찰·비교·종교적 배경·근거 검토 목표와 선택적 자유 목표(최대 200자)를 입력합니다.
- 목표의 시대·구조·재료·종교 키워드 순서로 학습 초점을 조정합니다. 임의 주제의 완전한 생성형 커리큘럼은 아닙니다.
- 기본 예제 추천과 공식 검색에서 시작하는 동적 후보 탐색을 구분합니다. 동적 탐색은 아래 14절 참고.
- 실행: 커리큘럼 → 추천·수집 → 추출 → 근거 점검 → 필요 시 공식 재조회·추가 출처 1회 → 재점검 → 비교 저장 → 퀴즈.
- 대안탑 개별 근거 부족 시 시안시 공식 설명을 추가 조회합니다. 다른 건물 연대·인물 생몰년은 건립연대로 쓰지 않습니다.
- 반복은 최대 1회입니다. 계속 부족하면 판단을 보류하고, 유효한 근거가 전혀 없으면 퀴즈 생성을 보류합니다.
- 모든 추출·공통점은 검토 후보입니다. 자동으로 역사적 사실의 최종 검증 상태로 승격하지 않습니다.
- UNESCO 전체 목록을 자동으로 검증 완료 처리하지 않습니다. 선택·수집한 공식 대상만 해당 원문 범위에서 탐구합니다.

### 연결 보완 및 학습 분량

- 공식 Agent 탐구는 짧게(핵심 2항목)·기본(목표 항목)·깊게(원문 범위 대조)를 선택합니다.
- 비교 항목과 문항의 우선순위가 같은 목표를 따릅니다. 부족한 목표는 출처 확인 활동과 판단 보류 안내를 제공합니다.
- 퀴즈 개수는 제안서대로 모든 분량에서 5개입니다. 학습 단계·설명량만 달라집니다.
- Gemini 문항 초안의 유산·항목·선택지 4개·5문항·정답과 저장 후보/인용 일치·목표 반영을 검사합니다.
- 생성 해설은 그대로 공개하지 않고 코드가 근거 인용을 붙입니다. 의미적 타당성은 사람의 검토가 필요합니다.
- 키 없음·시간 초과·사용량 제한·형식/근거 검사 실패 시 규칙 기반 퀴즈로 전환합니다.
- 퀴즈 호출 제한시간은 `CULTUREBRIDGE_QUIZ_TIMEOUT_MS=30000`(최대 60000)이며 자동 재호출하지 않습니다.
- 기본 자료 비교는 등록 요약 학습이고 맞춤 Agent 탐구와 구분됩니다.
- 확정된 버전과 검증 범위는 [실행 환경 확정 기록](docs/07_실행환경_연결보완.md)을 참고하세요.

## 14. 검색 결과에서 시작하는 동적 Agent

홈 검색 → 결과의 **이 유산/등재 유산으로 Agent 탐구** → 원문·검색 계획·후보 탐색 → Agent가 고른 비교 → 질문·퀴즈.
새 유산마다 개발자가 목록 코드를 수정할 필요가 없습니다. 공식 식별자는 서버가 확인해 SQLite에 저장합니다.

- API: `POST /api/autonomous-explorations`, target.provider=khs/unesco와 해당 기관의 식별 ID를 전달합니다.
- Gemini는 제공 원문·목표에 따라 검색어를 계획하고 실제 조회된 후보의 인덱스 안에서 선택합니다.
- 키 없음·호출 실패 시 원문 키워드/유형·국가 적합성에 따른 대체 탐색으로 전환하고 화면에 방식 차이를 표시합니다.
- 첫 탐색은 UNESCO 최대 3개 검색어와 국가유산청 1개 검색어입니다. 탈락한 후보 뒤의 원문도 최대 8개까지 확인합니다.
- 후보가 없고 선택 대상 근거가 충분하면 검색어·다음 페이지를 바꿔 1회 더 탐색합니다. 총 UNESCO 최대 6회, 국가유산청 최대 2회, 후보 원문 최대 16개입니다.
- 이후 기존 LangGraph의 추출 → 검증 → 필요 시 1회 공식 재조회 → 비교 저장 → 퀴즈 실행으로 연결합니다.
- 공식 대상은 `khs:종목:번호:지역`, `unesco:등재ID` 네임스페이스를 사용합니다. 모델이 URL을 지어내거나 임의 서버를 조회하지 못합니다.
- UNESCO 묶음 기록은 공식 등재명 전체가 탐구 대상입니다. 콜로세움 같은 별칭을 로마 전체 기록의 단일 건물 사실로 바꾸지 않습니다.
- 후보/근거가 부족하면 보류합니다. 등록·출처 연결·인용 일치는 역사적 의미의 검증 완료가 아닙니다.
- 동적 대상의 기본 요약 필드는 추출 전 '근거 부족'입니다. 퀴즈는 반드시 공식 비교 저장본을 사용합니다.
- 동적 탐구는 공식 자료 조회 범위 안에서 동작하며 모든 유산의 충분한 근거·후보·문항을 보장하지 않습니다.
- 실제 Gemini 계획/선정 성공의 연결 확인은 현재 API 사용량 제한 해제 후 필요합니다. 대체 탐색의 실제 공식 연결 및 모델 경로의 모의 검증은 완료했습니다.
- [동적 탐구 검증 기록](docs/09_동적_Agent_검증.md)을 참고하세요.

### 한국어 학습 화면과 추천 품질 보완

유산명은 등록된 한국어 안내명(공식 영문명)으로 표시하고, 미확인 한국어 명칭은 확인 필요로 표시합니다.
기술적 실행 기록과 긴 주의 문구는 펼쳐보기 안에 두며 초급 안내와 추천 이유를 쉬운 한국어로 제공합니다.
핵심 유형·자료 단위·직접 근거를 점검한 뒤 자동 비교합니다. 키워드가 많이 겹치는 유산군을
개별 탑의 비교 대상으로 자동 선택하지 않습니다. 조건에 맞는 해외 근거가 부족하면 비교를 보류하며 국내 후보로 자동 전환하지 않습니다.
다보탑의 사찰 배경 연대와 탑의 직접 근거를 구분하고, 추측 표현을 유지하며 석재를 화강암으로 단정하지 않습니다.
이는 일차적인 규칙 검사이며 범용 의미 검증·교육자 검토를 대체하지 않습니다.
[화면·추천 품질 기록](docs/10_한국어_화면_추천품질.md)을 참고하세요.

## 15. 범용 대상 구분·목표별 근거·한국어 이름 보완

- 특정 주변 유산 이름에 의존하지 않고 탑·사찰·궁궐·고분·석굴·전각·문 등의 명시적 주어와 문맥을 선별합니다.
- 부모 이름이 포함된 제목은 마지막 구성 대상을 우선합니다. ‘경복궁 근정전’과 ‘천마총 금관’을 궁궐·고분 자체로 취급하지 않습니다.
- 창건·건립과 재건·복원을 구분해 표시합니다. 주변 건물의 건립·소장품 목록·인물 사망 연대는 해당 유산의 직접 근거로 쓰지 않습니다.
- 석탑/목탑의 명시적 세부 유형과 소규모 구성 유산을 구분합니다. 규칙 기반 선별은 완전한 의미 분석이 아닙니다.
- 자동 선택은 양쪽의 공통 근거 2항목 이상을 요구합니다. 관찰은 구조·재료, 종교 목표는 종교 근거, 자유 목표의 명시 항목도 양쪽에 필요합니다.
- 부족한 동적 UNESCO 대상은 공식 상세 페이지의 영문 설명 추가 수집을 시도합니다. 403·형식 오류는 실패로 보관하며 우회하거나 근거로 사용하지 않습니다.
- 공통점은 부정·추정·모방 표현을 제외하고, Gemini 활성화 시 같은 의미·대상 범위인지 추가 검토합니다. AI 검토도 최종 역사적 검증은 아닙니다.
- 규칙 퀴즈는 확보한 목표 근거에 따라 최대 3개의 유산별 내용 문항을 포함하며, 틀린 문항마다 정답·인용을 다시 읽는 복습을 제공합니다.
- 기존 저장본은 보존합니다. 새 동적 퀴즈도 목표의 양쪽 근거를 다시 검사합니다.
- 한국어 이름은 기본 안내명, AI 번역 후보, 팀 검토 이름을 구분합니다. 새 탐구의 선택 대상·최종 후보 이름만 번역하고 실패를 24시간 캐시합니다.
- 자동완성은 여전히 로컬 자료만 사용합니다. 공식 영어 이름·ID·인용 원문은 이름 표시와 별개로 보존합니다.

팀이 검토한 이름 JSON을 등록하려면 다음 명령을 사용합니다. 별도 공개 관리자 API는 없습니다.

```powershell
.\.venv313\Scripts\python.exe -m culturebridge.import_names "C:\Users\sun\Downloads\heritage-names.json"
```

JSON 형식: `[{"id":"252","official_name":"Taj Mahal","korean_name":"타지마할","aliases":["타지 마할"]}]`.
모든 ID·영문명이 실제 공식 목록과 일치해야 합니다. 등록은 로컬 DB에 보관되므로 팀원이 공유하려면 같은 검토 파일을 가져옵니다.

## 16. 수준별 공식 설명

공식 상세 화면에서 초급/중급/고급을 전환할 수 있습니다. 홈에서 고른 수준도 공식 상세 링크에 전달합니다.

- 초급: 직접 근거가 있는 핵심 항목을 쉬운 제목·짧은 연대 안내·용어 풀이로 읽습니다. 추정·전승·부정과 재건 표시는 유지합니다.
- 중급: 시대·구조·재료·종교적 배경을 항목별로 읽고 사건별 연대와 용어·인용 근거를 확인합니다.
- 고급: 저장된 공식 API 설명 본문을 수정 없이 기본 본문으로 표시합니다. 추출 후보·비교 분석은 원문과 구분합니다.
- 모든 수준에서 공식 원문 전체·출처를 확인할 수 있습니다. 내용은 표시할 때만 가공하며 기존 원문·저장 비교를 덮어쓰지 않습니다.
- 영어 자료의 한국어 안내는 확인한 원문 표현을 설명하는 읽기 도움말이며 전체 번역문이 아닙니다. 고급은 원래 언어의 본문을 유지합니다.
- 오래된/수집 실패 자료는 새 학습 설명을 보류합니다. 근거 없는 항목을 기존 요약이나 추측으로 채우지 않습니다.

예: `/official/11/0000200000000/37?level=advanced`.
수준별 API: `GET /api/official/heritages/{kind}/{number}/{region}/lesson?level=beginner|intermediate|advanced`.
기존 공식 상세 API의 `content`는 원문 그대로 유지합니다.
[검증 기록](docs/12_수준별_공식설명.md)을 참고하세요.

## 18. 검색·학습 화면으로 돌아가기

상세·추천·탐구·비교 화면 상단에 ‘검색 결과로’ 또는 ‘추천 화면으로’ 버튼을 제공합니다.
퀴즈 상단의 ‘비교 화면으로’는 같은 비교 대상·학습 수준·저장본으로 돌아갑니다.
‘처음으로’는 별도 버튼으로 유지합니다.

- 홈 검색어·검색 범위·결과 페이지·학습 수준·학습 목표·분량을 URL의 반환 문맥으로 유지합니다.
- 검색 화면으로 돌아오면 조건을 복원하고, 브라우저 연결 뒤 같은 결과 페이지를 다시 조회합니다.
- 상세 화면에서 수준을 바꾸면 돌아갈 검색 화면의 수준도 바뀝니다.
- 기본 퀴즈도 직전 비교 저장본을 유지합니다. 다른 비교 대상의 저장본은 반환에 사용하지 않습니다.
- 비교 기록에서 열면 ‘비교 기록으로’, 직접 상세 주소로 들어오면 해당 유산 검색으로 안내합니다.
- 반환 주소는 홈·한국/세계 검색·비교 기록·키오스크의 내부 경로만 허용합니다. 외부 주소·스크립트·제어문자·중첩 반환 주소를 거부/제거합니다.
- 검색 조건은 유지하지만 외부 기관 데이터가 갱신되면 결과 내용은 달라질 수 있습니다. 검색 결과의 영구 저장 스냅샷은 아닙니다.

[이동 검증 기록](docs/14_검색_학습_돌아가기.md)을 참고하세요.

## 19. 해외 비교 기본 · 국내 비교 부가 기능

- 기본 홈(`/`)은 **해외 문화유산과 비교**입니다. 비교 후보는 한국 밖의 유산만 탐색합니다.
- **국내 문화유산과 비교**를 펼쳐 별도 화면(`/domestic`)으로 들어가면 한국의 유산만 추천합니다.
- 국내/해외는 시작 유산과 같은 국가인지가 아니라 대한민국 기준입니다. 시작 유산이 해외 유산이어도 국내 비교 후보는 한국입니다.
- 검색 범위(전체/한국/세계)와 비교 범위는 별개입니다. 한국 유산을 검색해서 해외 유산과 비교할 수 있습니다.
- 선택한 범위에 적합한 근거가 부족하면 보류하고, 다른 범위로 자동 전환하지 않습니다.
- 검색어·학습 수준·목표·분량과 비교 범위를 상세·추천·비교 이동에 전달합니다. 기존 저장 비교는 보존합니다.
- API의 `comparison_scope`는 `overseas`(기본)/`domestic`입니다. 상세 국가와 비교 범위를 서버에서도 검사합니다.
- 해외 탐색은 UNESCO 등재 자료와 아래에 명시한 개별 공식 자료 어댑터 범위입니다. 모든 개별 해외 유산에 적합한 비교 후보가 있다는 뜻은 아닙니다.

[비교 범위 검증 기록](docs/15_해외기본_국내부가기능.md)을 참고하세요.

## 21. 연결 오류 수정과 학습·운영 보완

- 기본 비교도 학습 목표·세부 목표·분량·학습 순서를 보존합니다. 같은 내용의 기본 비교는 새로고침해도 중복 저장하지 않습니다.
- 탐구·퀴즈·동일 답안 채점은 같은 익명 세션에서 기본 5분 동안 결과를 재사용합니다. 과거 저장본은 변경하지 않습니다.
- 탑의 석재/목재 차이를 일괄 제외하지 않고, 같은 핵심 유형의 비교 축으로 안내합니다.
- 개별 해외 공식 자료는 5개국 26개 대상을 등록했고, 그중 25개는 실제 연결을 확인했습니다. 전체 목록과 연결 검증은 아래 23절을 참고하세요. 고정 기관 URL만 조회하며 유산군과 개별 대상을 구분합니다.
- 호류지/대안탑은 각각 UNESCO 660/1442 유산군의 구성 대상입니다. 같은 대상의 별칭과 포함 관계는 `/api/heritages/{id}/identity`에서 구분합니다.
- 초급 읽기 도움말·생각해 보기, 항목별 비교 기준, 내용 중심 퀴즈 보기와 오답별 보충 활동을 제공합니다. 영어 안내는 전체 번역이 아닙니다.
- 키워드로 해석되지 않는 자유 목표는 Gemini로 지원 학습 항목을 해석하며, 해당 목표의 양쪽 근거를 검사합니다. 해석 실패 시 기본 순서로 안내하고 역사적 사실을 생성하지 않습니다.
- 자유 질문은 최근 6개 메시지를 질문 맥락으로만 사용합니다. AI 답변은 문장별 출처 ID·원문 인용을 검사하며, 실패 시 기존 근거 안내로 전환합니다. 인용 검사와 역사적 의미 검증은 다릅니다.
- `/learning-history` 또는 비교 기록의 ‘퀴즈 결과와 오답 복습’에서 채점 결과와 보충 활동을 확인합니다.
- 자료 부족 시 설명 먼저 읽기·목표 변경, 검색 결과 없음 시 유사한 검색어를 안내합니다. 제안 검색어는 실제 검색 결과가 아닙니다.

### 공개 운영 설정

기본은 로컬 공유 모드입니다. 외부에 공개하기 전 `.env`에서 `CULTUREBRIDGE_PUBLIC_MODE=true`와
별도의 **32자 이상 무작위 STORAGE_SECRET**을 설정하세요. 개발용 값을 사용하면 공개 모드 시작을 거부합니다.
공개 모드는 서명된 HttpOnly/SameSite 익명 세션으로 기록을 분리하고, 다른 세션의 비교·퀴즈·오답 접근을 막습니다.
키오스크 처음으로/미사용 초기화는 익명 세션도 교체합니다. 운영은 HTTPS를 사용하세요.
세션 쿠키 삭제/브라우저 종료 후 기록을 복구할 계정 기능은 제공하지 않습니다.

동시 학습 작업은 기본 3개, 공개 모드 POST/IP 및 학습 요청/세션은 기본 분당 30개로 제한합니다.
제한 시 429와 재시도 안내를 제공합니다. 재사용 캐시와 제한은 단일 서버 프로세스 기준이며,
여러 서버/worker 운영은 공유 제한 저장소가 추가로 필요합니다.

### 백업과 자료 보관

```powershell
.\.venv313\Scripts\python.exe -m culturebridge.backup_db --output backups/culturebridge-20261014.db
```

SQLite 백업 API와 무결성 검사를 사용하며 기존 파일은 덮어쓰지 않습니다. `.env`는 백업에 포함되지 않습니다.
백업 폴더는 Git에서 제외됩니다. 현재 기록은 자동 삭제하지 않으며, 팀 운영자가 보관 기간·백업 접근권한을 정한 후
백업을 확인하고 별도 정리해야 합니다. 공개 서버의 과거 소유자 없는 기록은 익명 사용자에게 공개하지 않습니다.

실제 Gemini 점검에서 429가 반환됐으며, 호류지 페이지는 현재 인증서 검증 실패로 수집을 보류합니다.
실제 다보탑→시안시 정부 대안탑 원문→비교 저장→5문항 퀴즈의 대체 경로는 확인했습니다.
기관 원문 수집 실패를 정상 AI 탐구나 검증된 사실로 표시하지 않습니다.

## 22. 설명·퀴즈·저장본 재탐구

초급은 지원하는 원문 특징을 짧은 한국어 문장으로 읽고, 비교는 공통 기준과 설명 범위의 차이를 구분합니다.
대체 퀴즈는 양쪽 유산의 근거를 교대로 사용합니다. 채점 화면의 원문·전체 해설은 펼쳐보기로 묶었습니다.
새 비교는 학습 구성 버전 2이며, 과거 기록에는 `최신 근거로 다시 탐구하기`를 제공합니다.
기존 기록은 보존하고, 같은 목표·수준·분량으로 원문을 재조회해 새 저장본을 만듭니다.
API: `POST /api/comparisons/{record_id}/relearn` (기존 세션 소유권·동시/요청 제한 적용).
신규 타지마할 묘당과 그랑 트리아농 궁전의 기관 원문 수집을 실제 확인했습니다.
범용 번역·모든 국가의 개별 유산·역사적 영향 검증을 완료했다는 뜻은 아닙니다.
[적용 내용과 검증 범위](docs/18_학습내용_복습_재탐구.md)를 참고하세요.

## 23. 해외 개별 문화유산 25개 정상 연결·1개 보류

자동완성은 입력 중 외부 기관이나 Gemini를 호출하지 않습니다.

2026-10-16 실제 연결 점검에서 25개의 원문 수집과 유효 항목 2개 이상 추출을 확인했습니다.
성 마거릿 예배당을 추가해 정상 연결 대상 25개를 확보했으며, 보류 대상을 포함한 등록 수는 26개입니다.
호류지 오층탑 1개는 연결/인증서 오류로 보류하며 검증을 끄지 않습니다.
확보한 항목이 학습 목표에 맞지 않으면 자동 비교를 보류합니다. 모든 조합이 비교되는 것은 아닙니다.
추천의 개별 공식 자료 확인은 한 번에 최대 6개, 결과는 최대 3개로 제한합니다.

```powershell
.\.venv313\Scripts\python.exe -m culturebridge.check_individual_sources --all --workers 3
```

이 명령은 실제 기관 원문을 새로 조회하고 로컬 캐시를 갱신합니다. Gemini는 호출하지 않습니다.
연결 실패·오래된 원문·유효 항목 부족이 하나라도 있으면 종료 코드 1이며,
상태·항목·글자 수만 출력합니다. [기존 21개 목록](docs/19_해외개별유산_21개_확장.md)과 [25개 확장·검증·한계](docs/20_해외개별유산_25개_확장.md)를 참고하세요.

## 24. 한국어 풀이·자료 관리·운영 준비

- 영문 원문 카드에서 **한국어 풀이로 읽기**를 누르면 근거 인용에 연결된 수준별 AI 초안을 생성합니다. 공식 번역이 아니며, 고급 원문은 바꾸지 않습니다. 키 없음·실패 시 기본 도움말을 유지합니다.
- 추천에 양쪽 근거 항목을 표시하고, 복수 재료·모양·부분을 같은 기준으로 비교합니다. 새 학습 구성 버전은 3입니다.
- AI 퀴즈는 문항 검사 실패 시 최대 1회 부분 수정하고 동일 기준으로 재검사합니다. 429·통신 오류는 반복 호출하지 않습니다.
- `/sources`: 공식 출처·연결 이력·한국어 이름·이용 조건 검토 상태를 확인합니다. 이름·별칭·이용 제한 변경은 관리자 로컬 CLI만 허용합니다.
- `/data-policy`: 익명 세션과 보관 설정을 안내하고, 현재 세션의 학습 기록을 확인 후 삭제합니다.
- 자동 백업·보관 정리·새 파일 복원 명령을 추가했습니다. 로컬 자동 운영과 자동 기록 삭제는 기본 비활성입니다.
- 배포 요청에 따라 `render.yaml`의 운영 환경은 자동 백업과 **90일 경과 기록 정리**를 활성화했습니다. 로컬 `.env` 설정은 바꾸지 않았습니다. 삭제 전 검증된 백업을 생성하고 최근 자동 백업 14개를 유지합니다.
- `render.yaml`은 유료 영구 디스크를 사용하는 단일 인스턴스 배포 **준비 파일**입니다. 실제 생성·과금·배포는 수행하지 않았습니다.

실행 방법·이용 조건·보관 정책·배포 전 선택 사항은 [운영 준비 안내](docs/21_학습고도화_자료관리_배포준비.md)를 참고하세요.

## 25. 대표 학습 코스와 학습지

`/courses`에서 탑·전각·궁전·고분·성당의 대표 코스 5개를 제공합니다.
목표와 활동을 확인하고 수준을 선택하면 기존 공식 자료 비교 → 퀴즈 → 오답 복습으로 이어집니다.
양쪽 목표 근거가 부족하면 시작을 보류하며, 전체 25개 자료의 자유 검색·탐구는 유지합니다.

`/sources`에 한국어 이름·풀이·대상 범위·기관 이용 조건의 검토 사항을 추가했습니다.
[25개 자료 검토표](docs/22_해외문화유산_25개_검토표.md)는 연결과 내용·권한 검토를 구분합니다.
기관 자료의 이용 허가나 한국어 번역 검토를 완료했다는 뜻은 아닙니다.

비교·채점·학습 기록에서 **인쇄·PDF 저장**, **학습지(.md)**, **학습 데이터(.json)**를 이용합니다.
내보내기는 현재 세션의 비교·제출된 점수·복습 활동·출처를 담으며 원문 전체와 문항·정답은 제외합니다.
PDF는 브라우저 인쇄에서 저장합니다. [수업 구성·사용법·검증 범위](docs/23_대표코스_검토표_학습결과.md)를 참고하세요.

## 26. 자료 사전 검토와 모의 학습 보완

25개 자료에 이름·대상 범위·기관 이용 조건의 AI 사전 점검 기록을 추가했습니다.
정책을 찾았다는 것이 번역·AI 전송·재배포 허가를 확보했다는 뜻은 아닙니다.
[최신 사전 검토 결과](docs/24_공식자료_25개_사전검토_결과.md)를 확인하세요.

구조는 구체적인 특징 문장을 우선하고, 재료는 건물·지붕·장식의 사용 범위를 구분합니다.
규칙 기반 퀴즈는 짧은 특징 문항과 수준별 비교·검토 활동으로 구성합니다.
학습 구성 버전은 6이며 이전 저장본의 ‘최신 근거로 다시 탐구하기’를 이용할 수 있습니다.
5코스×3수준의 AI-off 모의 학습 결과와 한계는 [점검·수정 기록](docs/25_모의수업_점검과_수정.md)에 정리했습니다.
실제 팀원 수업의 교육 효과나 기관 허가 획득을 입증한 것은 아닙니다.

### 학습 화면 개선

정확한 저장·수집 시각과 내부 버전은 일반 학습 화면에서 표시하지 않습니다.
나의 학습에는 간단한 학습 날짜·양쪽 유산·점수를 표시하고 이전 기록과 수준 필터를 제공합니다.
코스 활동과 '내가 정리한 배움'은 비교 화면에서 작성·저장하고 학습지에 담을 수 있습니다.
공유 모드에서 다른 세션의 기록을 열람하더라도 그 기록의 메모 수정·내보내기는 허용하지 않습니다.

해외 개별 원문의 외부 AI 전송은 목적별 이용 조건 확인 기록이 필요합니다.
권한 미확인 상태에서는 원문 읽기와 기본 학습 기능을 유지하며 외부 전송은 보류합니다.
`manage_sources review --usage-status reviewed`는 이용 허가를 대신하지 않습니다.
실제 확인 근거를 기록하는 관리 명령과 남은 검토 범위는
[학습 화면·품질 개선 기록](docs/26_학습화면_품질개선_반영.md)을 참고하세요.

### 자료·AI·교육·학습 경로 점검

25개 공식 자료 재수집, 75개 수준별 읽기 구성, 15개 모의 학습과 실제 Gemini 예제의
성공·대체 처리·사용량 제한을 [최신 점검 기록](docs/27_WBS_자료_AI_교육_학습경로_점검.md)에
구분했습니다. 기관 허가와 실제 학습자 평가를 완료한 것으로 간주하지 않습니다.
일반 회귀 테스트는 실제 API를 호출하지 않으며 실호출은 별도 명시적 점검으로 실행합니다.

### 교육 내용 추가 검수

연대의 '약'·세기 구분·기간을 설명과 퀴즈에서 함께 보존하고, 여러 사건을 단일 건립연도로
바꾸지 않습니다. 재료의 사용 부분을 표시하며 고급 퀴즈의 반복적인 해석 문항을 줄였습니다.
25개 자료의 대조 결과와 실제 진행 상태 판정 기준은
[추가 검수 기록](docs/29_교육내용_추가검수_WBS_실제진행.md)에 정리했습니다.

### 개인·수업용 자료 이용 조건

공식 자료 목록(`/sources`)의 검토 항목에서 개인·수업용 네 가지 이용 범위를 확인합니다.
교육 목적 예외와 실제 이용 허가는 별개로 표시하며 기존 학습 기능을 제거하지 않습니다.
몽생미셸 수도원·생트샤펠에는 프랑스 문화부 공개 기록을 함께 읽는 기능을 추가했습니다.
추가 기록의 이용 조건을 원래 기관의 설명문에 확대 적용하지 않습니다.
[기능 유지·공개 기록 연결](docs/31_수업용_이용조건_기능유지_보완.md)에 범위와 한계를 정리했습니다.
실제 확인 근거의 등록·철회·출처 변경 재확인은
[관리 연결과 잔여 범위](docs/32_이용근거_관리연결_및_잔여범위.md)를 참고하세요.
`python -m culturebridge.manage_sources permissions`로 네 목적별 현재 기록을 확인할 수 있습니다.
이는 기관 허가나 역사 전문가·학습자의 최종 승인을 뜻하지 않습니다.
